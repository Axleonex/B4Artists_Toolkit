What this comparison shows

One fixed interval is shown from each of all 96 validation groups. The control is chosen from linear, Hermite and shape-preserving interpolation using the lowest measured error for that whole group. It is an after-evaluation diagnostic control, not an automatic inference method.

Group errors summarize all original sampled intervals, not only the interval on screen. The reference plane helps orientation; it is not a tested contact surface. Both learned candidates still fail motion-quality safeguards.

All confirmation clips remain sealed. This viewer does not constitute an independent animator assessment.
