Review protocol

Watch each case at least twice and inspect front, side and oblique views. Judge motion naturalness, planted-contact stability, transition continuity and preservation of the stated task intent. Scores run from 1 (unacceptable) to 5 (excellent).

Correction and interaction estimates are the number you believe each result would require before production use. Use failure tags for visible defects. Locking is deliberately one-way for this review session so the reveal cannot influence the rating.

The display uses actual evaluated 17-joint centers from the saved BoneForge, Rigify and imported-rig scenes. It cannot show skin deformation, axial twist or mesh collisions. For a hands-on workflow check, open the source scene shown after lock and record a separate timed animator pass.

Nothing is uploaded. Progress remains in this browser; Export creates a local checksum-bound JSON file only after all 32 cases are locked.
