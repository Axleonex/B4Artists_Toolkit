# CATS 도구

[← 목차](index.md)

CATS 도구는 오른쪽 사이드바의 **CATS** 탭(**N** 누르기),**CATS** 섹션 및 기본 설정 → 탭 → 장면 속성 → 표시가 켜져 있는 동안**Properties** 편집기의**Scene** 탭에 있습니다. CATS 뷰포트 스위치와 장면 속성 스위치는 자체 복사본을 독립적으로 제어합니다. 이는 [CATS 파이프라인](04-cats-pipeline.md) 에 설명된 파이프라인을 따릅니다. 섹션 상단에서 작업 중인 뼈대를 선택하세요.

9.1에서는 여러 패널에서 작업 버튼 아래 접힌 부분에 옵션 설정을 배치했습니다. 도구를 실행하기 전에 필요한 입력이 여전히 먼저 옵니다. 모델 수정의 정리 스위치, 뼈 이름 번역의 소스 언어, 입 모양 또는 눈 뼈. 마지막 작업 조정을 제공하는 뼈대 도구는 즉시 실행되며 나중에 옵션을 조정할 수 있습니다. 도구 설명을 읽으려면 버튼이나 옵션에 마우스를 올리세요.

---

## 모델 수정

**파이프라인 단계:** 1(항상 먼저)

**기능:** 다른 CATS 작업 전에 원클릭 정리입니다. 이후 단계마다 조용히 중단될 숨겨진 문제를 제거합니다.

**옵션(각각 끌 수 있음):**
- 수정자 적용
- 복식 제거 — 동일한 위치에서 중복된 정점을 병합합니다.
- 법선 다시 계산 - 내부 표면 수정
- 느슨한 형상 제거 - 몸체에 부착되지 않은 면
- 빈 정점 그룹 제거
- 가중치가 없는 뼈 제거 - 정점이 움직이지 않는 뼈
- 제약 조건 및 강체 제거 VRChat 는 사용할 수 없습니다.

**Fix Model** 를 클릭하면 선택한 메시에서 한 번에 실행됩니다.

---

## 본 이름 번역

**기능:** 골격의 뼈 이름을 영어 VRChat 이름으로 변환합니다. 알려진 뼈 이름이 포함된 내장 사전을 통해 오프라인으로 작동합니다.

**지원되는 언어:** 일본어(일본어, 가장 일반적인 언어, MMD 및 많은 커뮤니티 모델에서 사용), 중국어(中文), 한국어(한국어), 포르투갈어(Português), 스페인어(Español) 및 프랑스어(Français).

**주요 컨트롤:** 소스 이름의**Language** 및 번역 버튼(**Translate Bone Names** ).

이는 인터페이스 언어가 아닌 모델의 뼈대 이름 언어에 관한 것입니다. 일본어 MMD 모델의 경우 Bforartists 가 설정된 언어를 사용하십시오.

---

## 메시 합치기

**기능:** 아바타의 메시 개체를 하나의 메시로 결합합니다. VRChat 는 아바타당 하나의 메시를 사용할 때 가장 잘 작동합니다. 메쉬에 다른 모양 키가 있는 경우 CATS 는 누락된 키를 중립 모양으로 채워 결합된 메쉬가 하나의 일관된 세트를 갖도록 합니다.

**주요 컨트롤:** 메시 목록(옆에 있는 버튼으로 새로 고침),**Join Meshes**.

**사용시점:** 모든 의류 및 액세서리를 부착하고 무게를 잰 후, 모델을 고정한 후. Fix Model 이전에 결합하면 한 객체에서 다른 객체로 중복 정점 문제가 확산됩니다. 그런 다음 결합된 메시는 모든 원본 개체의 팬텀 정점을 유지하고 생성된 비짐은 이음새에서 이를 찢습니다.

---

## 머티리얼 아틀라스 결합

**파이프라인 단계:** 2(선택 사항)

**기능:** 여러 재질을 하나의 텍스처 시트(아틀라스)로 굽습니다. 재료가 적을수록 VRChat 성능 순위가 더 좋아집니다.

**주요 컨트롤:**
- **Analyze** — 진단, 중복 그룹 및 크기 재정의와 함께 재료 및 텍스처를 나열합니다. 포함할 재료와 질감을 선택하고 그대로 유지하려는 항목을 선택 취소합니다.
- **Smart Combine Materials** — 권장 경로: 아틀라스를 굽고 각 메시를 이를 가리킵니다. 아틀라스 UV는 내보내기를 위해 UV0이 됩니다.
- **Bake Atlas** — 일반 베이킹;**Add Group** 및**Remove Group** 는 재료 그룹을 별도로 베이킹합니다.
- 상속된 설정 재정의 - 아틀라스 크기, UV 방법 및 시드, 패킹 사전 설정, 베이킹 패딩, 아일랜드 회전 단계 및 베이킹 패스(기본적으로 알베도, 법선, 방출 및 거칠기는 별도의 출력으로 베이킹될 수 있음)
- **Preserve Backup Duplicate** — 원본의 사본을 보관합니다.
- **Accept — Delete Backup** — 결과를 유지하고 백업을 삭제합니다.
- **Revert — Restore Originals** — 원래 자료로 돌아갑니다.
- **Copy Debug Report** — 버그 보고서를 위해 진단 내용을 클립보드에 복사합니다.

VRM / MToon 재질은 투명성을 유지합니다. 알파 모드가 존중되고 실제 텍스처 알파와 비교하여 확인되며 방출이 터지지 않으며 문제 타일은 베이킹 후 자홍색으로 표시됩니다.

**계보 크레딧:** 이 워크플로는 CATS 통합 계보를 이어가고, 원본 Cats Blender 플러그인을 제공하고, Material Combiner 계보에 대한 Grim-es/material-combiner-addon을 제공하며, Alexander Belyakov의 UV Toolkit과 UV 워크플로 영감을 위한 oRazeD/UVToolkit 아카이브 저장소를 제공합니다. BoneCraft 는 UVToolkit 소스를 포함하는 대신 자체 아틀라스 UV 도우미를 구현합니다.

## 비세임

**파이프라인 단계:** 3

**기능:** 세 가지 기본 입 모양에서 15개의 VRChat 비짐을 만듭니다.

**주요 컨트롤:** **A Shape**,**O Shape** 및**CH Shape** (선택 또는**Auto-Detect** ),**Generate Visemes**. 버튼 아래의 옵션을 확장하여 생성하기 전에 기존 비짐을 덮어쓸지 여부를 선택합니다. [가이드 13, 2단계](03-guides-b.md#단계-2--비세임-생성) 를 참조하세요.

## 아이 트래킹

**파이프라인 단계:** 4(모델 수정 후 실행)

먼저 모델 수정이 없으면 눈 감지가 실제 눈 대신 남은 중복 형상에 고정되어 빈 공간에 제약 조건을 적용할 수 있습니다. 아바타는 바닥을 바라보며 VRChat 에 도착합니다.

**기능:** 아바타의 눈 뼈대를 찾아서 이름을 VRChat 에 필요한 대로 지정하고(`LeftEye` 및 `RightEye` ) VRChat 에서 눈을 자연스럽게 움직이는 회전 제약 조건을 만듭니다.

**주요 컨트롤:**
- **Auto-Detect** — 눈 뼈 이름 및 위치와 일치하는 뼈를 찾습니다.
- **Left Eye** 및**Right Eye** — 눈 뼈(직접 선택하는 경우)
- **Up Limit**,**Down Limit** 및**Side Limit** — 눈이 얼마나 멀리 회전할 수 있는지
- **Create Eye Tracking** — 뼈의 이름을 바꾸고 제약 조건을 만듭니다.

## 포즈 & 셰이프 키

**파이프라인 단계:** 5(선택 사항)

### 포즈를 셰이프 키로

사용자 정의 표현식 또는 수정된 레스트 모양을 위해 현재 포즈를 새로운 모양 키로 바꿉니다. 포즈 모드에서 뼈대의 포즈를 취하고 개체 모드로 돌아온 다음 **Pose to Shape Key** 를 클릭하고 모양 키의 이름을 지정합니다.

### 셰이프 키를 Basis로

그 반대: 모양 키를 메시의 중립 나머지 모양으로 굽습니다. 이를 사용하여 올바른 휴식 자세를 영원히 유지하세요. Fix Model 이후에도 실행하세요.

---

## 트랜스폼 & FBT

**파이프라인 단계:** 6(마지막)

### 모든 트랜스폼 적용

메시와 뼈대에 위치, 회전, 배율을 함께 적용하여 모든 것이 깨끗한 값으로 읽힙니다. VRChat SDK에는 다음이 필요합니다. 적용되지 않은 배율로 인해 VRChat 에서 아바타의 크기가 잘못됩니다.

### FBT 수정

전신 추적 설정에 대한 변환 수정: 루트 뼈대를 바닥 수준으로 이동합니다.

### FBT 제거

FBT 수정 수정을 다시 제거합니다.

## 본 도구

- **Create Root Bone** — 계층 구조의 맨 아래에 루트 뼈대(**Root Name** 로 이름 지정)를 추가합니다.
- **Merge Bones** —**Merge Threshold** 보다 짧은 뼈를 상위 뼈로 병합합니다.
- **Duplicate Bones** — 선택한 뼈를 복제합니다.

---

## 아마추어 도구

**기능:** 하나의 뼈대를 다른 뼈대로 병합합니다. 예를 들어 의상의 뼈대를 신체의 뼈대에 병합합니다.

**주요 컨트롤:**
- **Base / Root** — 유지되는 뼈대(결과는 이름을 유지함)
- **Incoming** — 병합되는 뼈대; 같은 이름의 뼈가 베이스로 접혀집니다.
- Naming Prep — 병합하기 전에 두 리그의 뼈대 이름을 일치시킵니다. Mixamo 가져오기뿐만 아니라 모든 리그에서 작동합니다. Mixamo Prefixed를 선택하고 **Normalize Merge Names** 를 클릭한 다음 Mixamo Stripped를 선택하고 다시 정규화합니다. 두 리그 모두 같은 이름으로 끝납니다.
- 뼈를 자동으로 부모로 설정하고 나중에 메시를 결합하는 옵션
- **Merge Incoming Into Base** — 병합

미리보기가 포함된 단계적 병합의 경우 Bone Merge를 사용하세요([리그 빌더](06-rig-builder.md#본-병합) 참조).

---

## 메시 도구

- **Separate by Materials** — 재료당 메시 1개
- **Separate by Loose Parts** — 연결된 조각당 메시 1개
- **Separate by Shape Keys** — 모양 키가 움직이는 부분을 분할합니다.

## Smart Automatic Weights(스마트 자동 웨이트)

**Smart Automatic Weights** 는 대화상자를 엽니다. 대상 메시와 뼈대를 확인한 다음 Body를 선택하여 기존 리그에서 다시 계산하거나 Clothing을 선택하여 가중치가 적용된 소스 메시에서 전송할 수 있습니다. 대화 상자는 스마트 기본값을 사용하고 숨겨진 백업을 유지합니다.**Advanced Recalculation** 는 BoneCraft → 스킨 → 웨이트 도구의 전체 컨트롤에 대한 위치 힌트를 확장합니다. 여기서는 해당 컨트롤이 열리지 않습니다. [리그 도구](05-rig-tools.md#본-웨이트-자동-재계산) 를 참조하세요.

## 파이프라인 상태와 작업 장부

파이프라인 상태는 6개 단계 중 어느 단계가 완료되었는지 보여줍니다. Operation Ledger에는 모든 CATS 작업이 시간 및 결과(Changed, Clean 또는 Failed)와 함께 나열됩니다. **Copy** 는 이를 클립보드에 넣고**Clear** 는 이를 비웁니다. [CATS 파이프라인](04-cats-pipeline.md) 를 참조하세요.
