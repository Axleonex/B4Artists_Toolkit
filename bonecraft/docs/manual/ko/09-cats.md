# CATS 도구

[← 목차](index.md)

CATS 도구는 오른쪽 사이드바(**N** 키)의 **CATS** 탭 안 **CATS** 섹션에 있으며, **속성** 에디터의 **장면** 탭에도  있습니다. [CATS 파이프라인](04-cats-pipeline.md)에서 설명한 순서를 따릅니다. 작업할 아마추어는 섹션 맨 위에서 고릅니다. 장면 패널은 Preferences → Tabs → Scene Properties → Show가 켜져 있을 때 표시됩니다. 뷰포트 탭을 숨겨도 이 복사본은 숨겨지지 않습니다.

---

## 모델 수정

**파이프라인 단계:** 1(항상 먼저)

**하는 일:** 다른 CATS 작업 전에 하는 한 번의 클릭 정리입니다. 그대로 두면 뒤의 모든 단계를 말없이 망가뜨릴 숨은 문제를 없앱니다.

**옵션(각각 끌 수 있습니다):**
- 모디파이어 적용
- 중복 제거 — 같은 위치의 중복 정점을 병합합니다
- 노멀 다시 계산 — 안팎이 뒤집힌 면을 고칩니다
- 떨어진 지오메트리 제거 — 몸에 붙어 있지 않은 면
- 빈 정점 그룹 제거
- 웨이트가 0인 본 제거 — 어떤 정점도 움직이지 않는 본
- VRChat이 쓸 수 없는 컨스트레인트와 리지드 바디 제거

**모델 수정**을 클릭하면 선택한 메시에 이것들을 한 번에 실행합니다.

## 본 이름 번역

**하는 일:** 스켈레톤의 본 이름을 VRChat의 영어 이름으로 번역합니다. 알려진 본 이름의 내장 사전을 쓰므로 오프라인으로 작동합니다.

**지원 언어:** 일본어(日本語. 가장 흔하며 MMD와 많은 커뮤니티 모델에서 옵니다), 중국어(中文), 한국어, 포르투갈어(Português), 스페인어(Español), 프랑스어(Français).

**주요 컨트롤:** 원래 이름의 **언어**와 번역 버튼(**본 이름 번역**).

이것은 모델의 본 이름 언어에 관한 것이지 인터페이스 언어가 아닙니다: 일본어 MMD 모델이라면 Bforartists가 어떤 언어로 설정되어 있든 이것을 쓰세요.

## 메시 합치기

**하는 일:** 아바타의 메시 오브젝트를 하나의 메시로 합칩니다. VRChat에서는 아바타당 메시가 하나일 때 성능이 가장 좋습니다. 메시마다 셰이프 키가 다르면 CATS가 빠진 것을 중립 모양으로 채우므로, 합쳐진 메시에는 일관된 셰이프 키 한 벌이 생깁니다.

**주요 컨트롤:** 메시 목록(옆의 버튼으로 새로 고침)과 **메시 합치기**.

**쓰는 때:** 의상과 액세서리를 모두 붙이고 웨이트를 준 뒤, 그리고 모델 수정 뒤. 모델 수정 전에 합치면 중복 정점 문제가 한 오브젝트에서 다른 오브젝트로 퍼집니다. 합쳐진 메시에는 원래 모든 오브젝트의 유령 정점이 남고, 생성된 비세임이 이음매에서 메시를 찢습니다.

## 머티리얼 아틀라스 결합

**파이프라인 단계:** 2(선택)

**하는 일:** 여러 머티리얼을 하나의 텍스처 시트(아틀라스)로 베이크합니다. 머티리얼이 적을수록 VRChat 성능 등급이 좋아집니다.

**주요 컨트롤:**
- **Analyze**(분석) — 머티리얼과 텍스처를 진단, 중복 그룹, 크기 재정의와 함께 나열합니다. 포함할 머티리얼과 텍스처를 고르세요: 그대로 두고 싶은 것은 체크를 해제합니다.
- **Smart Combine Materials**(머티리얼 스마트 합치기) — 권장 방법: 아틀라스를 베이크하고 각 메시가 그것을 쓰게 합니다. 아틀라스 UV는 내보내기용 UV0이 됩니다
- **아틀라스 베이크** — 단순 베이크. **Add Group**(그룹 추가)과 **Remove Group**(그룹 제거)으로 머티리얼 그룹을 따로 베이크합니다
- 상속된 설정 재정의 — 아틀라스 크기, UV 방식과 시드, 패킹 프리셋, 베이크 여백, 아일랜드 회전 단계, 베이크 패스(기본은 Albedo. Normal, Emission, Roughness는 별도 출력으로 베이크할 수 있습니다)
- **Preserve Backup Duplicate**(백업 사본 유지) — 원본의 사본을 남깁니다
- **적용 — 백업 삭제** — 결과를 남기고 백업을 삭제합니다
- **되돌리기 — 원본 복원** — 원래 머티리얼로 돌아갑니다
- **Copy Debug Report**(디버그 보고서 복사) — 버그 보고용으로 진단을 클립보드에 복사합니다

VRM / MToon 머티리얼은 투명도를 유지합니다: 알파 모드를 따르고 실제 텍스처 알파와 대조해 확인하며, 이미션이 하얗게 날아가지 않고, 문제가 있는 타일은 베이크 후 마젠타로 표시됩니다.

**계보와 크레딧:** 이 워크플로는 CATS 통합의 계보를 잇고, 원래의 Cats Blender Plugin에 크레딧을 돌리며, Material Combiner 계보로서 Grim-es/material-combiner-addon에, UV 워크플로의 영감으로서 Alexander Belyakov의 UV Toolkit과 oRazeD/UVToolkit 보관 저장소에 크레딧을 돌립니다. BoneCraft는 UVToolkit 소스를 포함하지 않고 자체 아틀라스 UV 도우미를 구현합니다.

## 비세임

**파이프라인 단계:** 3

**하는 일:** 기본 입 모양 세 개로 VRChat 비세임 15개를 만듭니다.

**주요 컨트롤:** **A 셰이프**, **O 셰이프**, **CH 셰이프**(직접 고르거나 **자동 감지**), 기존 비세임을 덮어쓰는 옵션, **비세임 생성**. [가이드 13, 단계 2](03-guides-b.md#단계-2--비세임-생성)를 보세요.

## 아이 트래킹

**파이프라인 단계:** 4(모델 수정 후에 실행)

먼저 모델 수정을 하지 않으면 눈 감지가 진짜 눈이 아니라 남은 중복 지오메트리에 걸려 빈 공간에 컨스트레인트를 둘 수 있습니다. 그러면 VRChat에서 아바타가 바닥을 바라보게 됩니다.

**하는 일:** 아바타의 눈 본을 찾아 VRChat이 요구하는 이름(`LeftEye`와 `RightEye`)을 붙이고, VRChat에서 눈을 자연스럽게 움직이는 회전 컨스트레인트를 만듭니다.

**주요 컨트롤:**
- **자동 감지** — 눈 본의 이름과 위치에 맞는 본을 찾습니다
- **왼쪽 눈**과 **오른쪽 눈** — 직접 고를 때의 눈 본
- **상한**, **하한**, **측면 한계** — 눈이 돌 수 있는 범위
- **아이 트래킹 생성** — 본 이름을 바꾸고 컨스트레인트를 만듭니다

## 포즈 & 셰이프 키

**파이프라인 단계:** 5(선택)

### 포즈를 셰이프 키로

현재 포즈를 새 셰이프 키로 바꿉니다. 사용자 표정이나 수정한 레스트 모양에 씁니다. 포즈 모드에서 아마추어에 포즈를 잡고, 오브젝트 모드로 돌아간 다음 **포즈를 셰이프 키로**를 클릭하고 셰이프 키에 이름을 붙입니다.

### 셰이프 키를 Basis로

반대 작업입니다: 셰이프 키를 메시의 중립 레스트 모양에 베이크합니다. 수정한 레스트 포즈를 영구히 고정할 때 쓰세요. 이것도 모델 수정 뒤에 실행하세요.

---

## 트랜스폼 & FBT

**파이프라인 단계:** 6(마지막)

### 모든 트랜스폼 적용

메시와 아마추어에 위치, 회전, 스케일을 함께 적용해 모든 값이 깨끗하게 읽히도록 합니다. VRChat SDK에는 이것이 필요합니다: 적용하지 않은 스케일이 있으면 VRChat에서 아바타 크기가 잘못됩니다.

### FBT 수정

풀 바디 트래킹 설정을 위한 트랜스폼 보정입니다: 루트 본을 바닥 높이로 옮깁니다.

### FBT 제거

FBT 수정의 보정을 다시 없앱니다.

## 본 도구

- **루트 본 생성** — 계층 맨 아래에 루트 본(이름은 **루트 이름**으로 정함)을 추가합니다
- **본 병합** — **병합 임계값**보다 짧은 본을 부모에 병합합니다
- **본 복제** — 선택한 본을 복제합니다

## 아마추어 도구

**하는 일:** 한 아마추어를 다른 아마추어에 병합합니다. 예를 들어 의상의 아마추어를 몸의 아마추어에.

**주요 컨트롤:**
- **Base / Root**(베이스 / 루트) — 남는 아마추어(결과는 그 이름을 유지합니다)
- **Incoming**(들어오는 쪽) — 여기에 병합되는 아마추어. 같은 이름의 본은 베이스로 합쳐집니다
- Naming Prep(이름 준비) — 병합 전에 두 리그의 본 이름을 맞춥니다. Mixamo에서 가져온 리그에만 쓰는 것이 아니라 어떤 리그에도 작동합니다: Mixamo Prefixed를 고르고 **Normalize Merge Names**(병합용 이름 정규화)를 클릭한 다음, Mixamo Stripped를 고르고 다시 정규화합니다. 두 리그가 같은 이름이 됩니다.
- 본을 자동으로 부모 연결하는 옵션과, 그 뒤에 메시를 합치는 옵션
- **Merge Incoming Into Base**(들어오는 쪽을 베이스에 병합) — 병합합니다

미리보기가 있는 단계별 병합에는 본 병합을 쓰세요([리그 빌더](06-rig-builder.md#본-병합) 참고).

---

## 메시 도구

- **머티리얼로 분리** — 머티리얼마다 메시 하나
- **분리된 파트로 분리** — 이어진 조각마다 메시 하나
- **셰이프 키로 분리** — 셰이프 키가 움직이는 부분을 떼어 냅니다

---

## Smart Automatic Weights(스마트 자동 웨이트)

기존 리그로부터 메시의 웨이트를 다시 계산합니다: **Smart Automatic Weights**, 전체 설정은 **Advanced Recalculation**(고급 재계산)에 있습니다. 같은 도구가 BoneCraft 탭(스킨 → 웨이트 도구)에도 있으며, [리그 도구](05-rig-tools.md#본-웨이트-자동-재계산)에서 설명합니다.

## 파이프라인 상태와 작업 장부

파이프라인 상태는 여섯 단계 중 어느 것을 마쳤는지 보여 줍니다. 작업 장부는 모든 CATS 작업을 시간과 결과(Changed, Clean, Failed)와 함께 나열합니다. **복사**는 클립보드에 넣고, **지우기**는 비웁니다. [CATS 파이프라인](04-cats-pipeline.md)을 보세요.
