## 9.2.4 — 작업 보드와 기본 도구

**건강 검사 열기**는 이제 리그 검증을 실행하고 결과를 엽니다. 아마추어 또는 연결된 메시를 선택하세요. **Quick Wins**는 최대 세 개의 권장 작업을 표시하고, **Remaining Tasks**는 해당 카드를 중복 표시하지 않습니다. **작업 보드 새로 고침**으로 다시 검사합니다.

Place Rig Markers와 Build Mechanism은 뷰포트 도구로 계속 사용할 수 있습니다. 도구 등록이 오브젝트 및 포즈 모드에서 기본 Grab/Move와 도구 순환 전환을 방해하던 문제를 수정했습니다.

## 9.2.3 — VRChat 내보내기 위치

Avatar Tools에서 중복된 Export to VRChat 패널을 제거했습니다. 내보내기는 CATS → Import / Export → Unity / VRChat에 유지됩니다.

## 9.2.2 — 현재 인터페이스

탭은 기능 그룹을 선택합니다. Setup Rigging, Skin, Review, Avatar Tools, Facial은 탭 안에서 펼치는 섹션이며 별도 탭이 아닙니다. 아래 경로는 영어 UI 이름입니다. 번역된 이름은 Language 설정에 따라 달라집니다.

- Bone Merge → BoneCraft → Setup Rigging
- Delta Mush / Proximity Wrap → BoneCraft → Skin
- Viseme Library / Lip Sync → CATS → Avatar Tools
- VRChat Viseme Mapping / Face Tracking → CATS → VRChat Tools → Facial

## 9.1.1(2026년 10월)

- **더 명확한 아이콘:** 이제 각 아이콘은 어디서나 한 가지 뜻만 가집니다. 약 60개의 버튼이 더 잘 맞는 Bforartists 아이콘을 쓰고(예: 모든 트랜스폼 적용, 데시메이트, 이름 정규화, 번역, 병합, 분리, 포즈 블렌드, 립싱크), 한 버튼은 모든 패널에서 같은 아이콘을 보여 줍니다.
- **차분해진 패널:** 제목과 고정 텍스트에는 더 이상 주제 아이콘이 붙지 않습니다. 상태를 알리는 안내에는 정보, 경고 또는 확인 아이콘이 붙습니다.
- **읽기 쉬운 아이콘 격자:** 툴 선반의 포즈와 웨이트 탭에 있는 버튼마다 고유한 아이콘이 있어서, 선반이 좁아도 구별할 수 있습니다.

## 9.1.0(2026년 10월)

- **Bforartists가 도구를 두는 곳에:** 추가 → 아마추어, 포즈, 웨이트, 오브젝트 메뉴에 BoneCraft 항목이 생기고, Bforartists 툴 선반의 포즈와 웨이트 탭에 BoneCraft 버튼 패널이 생겼습니다.
- **먼저 실행, 나중에 조정:** 빠른 리그, 드롭한 리그 맞추기, 웨이트 도구, 리본, 스플라인 IK, 델타 머시, CATS 본 도구가 마지막으로 쓴 값으로 바로 실행되고, 나중에 마지막 작업 조정 패널에서 조정합니다. "확실합니까" 창도 줄었습니다.
- **동작 먼저, 옵션은 접어서:** 패널은 버튼을 먼저 보여 주고 설정은 그 아래 접힌 영역에 둡니다. 설정은 설정처럼(버튼이 아닌 체크박스) 보이고 패널 헤더에는 아이콘이 없습니다.
- **제스처 도구:** 리그 마커 배치(메시를 클릭해 자동 리그 마법사의 다음 마커를 배치)와 메커니즘 만들기(파츠를 클릭해 조인트나 링크 시작)가 뷰포트 도구 막대에 있습니다.
- **툴팁:** 모든 오퍼레이터와 옵션이 스스로를 설명합니다.
- **숨기지 않고 보여 주기:** 리그가 없어도 섹션은 그대로 보이며 무엇을 선택할지 알려 주고, Rig Builder에서는 자동 리그 마법사가 맨 앞에 오며, 선반은 읽을 수 있는 너비로 열립니다.
- **수정:** 스플라인 IK 생성이 다시 작동합니다. 영향 추가가 선택한 본을 사용합니다. 비셈 미리보기가 해당 세트를 사용합니다.

## 9.0.0(2026년 10월)

- **Mechanisms:** BoneCraft 탭(과 속성 에디터의 장면 탭)의 새 섹션으로, 소품과 기계를 리깅합니다: Hinge, Slide, Telescope, Piston, Gear Link, Follow, Sequence를 안내 단계로 만들고 Test로 확인합니다. BoneCraft는 직접 한 편집을 절대 덮어쓰지 않습니다: 유지하려면 **Keep mine**을, 다시 만들려면 **복원**을 고르세요. [Mechanisms(메커니즘)](07-mechanisms.md)를 보세요.
- **탭 위치:** 뷰포트의 각 탭을 왼쪽 툴 셸프나 오른쪽 사이드바에 둘 수 있습니다(환경 설정 → Tabs → Left / Right). BoneCraft와 Rig Builder는 왼쪽에서, CATS는 오른쪽에서 시작합니다.
- **리그 빌더:** 속성 에디터의 장면 탭에 항상 있고, 전용 뷰포트 탭도 있으며 좁은 툴 셸프에서는 컴팩트한 배치를 씁니다. Basic Humanoid 리그가 BoneCraft Rigs 에셋 라이브러리에 들어 있으며, Fit Dropped Rig는 에셋 셸프에서 놓은 리그를 맞춥니다.
- **CATS 탭:** 가져오기 / 내보내기가 CATS 탭으로 옮겨졌습니다. CATS, VRChat, 가져오기 / 내보내기는 장면 탭에도 항상 있습니다.
- **Show Helpers:** 환경 설정 하나로 BoneCraft의 설명 글을 보이거나 숨깁니다. 컴팩트 모드는 그 바로 가기입니다.
- **리그 검증기:** 하이픈이 들어간 본 이름이 통과합니다. 드라이버는 Python이 필요한 식에만 경고합니다. Mechanisms 리그도 확인합니다. 작업 보드의 검증기 작업이 다시 보고됩니다.
- **이름:** 애드온의 이름은 BoneCraft입니다.

## 이전 버전

**8.5.0:** 이제 Smart Combine은 베이크 후 기본적으로 `atlas_uv`를 내보내기용 UV0으로 만듭니다. 고급 설정에서 **Keep Source UV Maps**(소스 UV 맵 유지)를 켜지 않으면, 아틀라스 이전의 소스 UV 맵은 생성된 아틀라스 메시에서 제거됩니다. CATS / Material Combiner / UVToolkit에서 유래한 컨트롤은 이제 오픈 Blender 빌드와 공유됩니다. B4Artists 전용으로 남은 것은 프로덕션 리깅, 컨트롤, 리타겟 / 내보내기, B4Artists 전용 릴리스 시스템입니다.

8.5.0은 내보내기와 검증 워크플로도 업데이트합니다. VRChat, VRM, MMD, Unreal 내보내기는 이제 Blender 파일 브라우저의 기본값에만 의존하게 하지 않고 BoneCraft 패널에 폴더와 파일 이름 컨트롤을 보여 줍니다. VRChat/Unity와 Unreal FBX 내보내기는 머티리얼을 쉽게 가져올 수 있도록 기본적으로 **Embed Textures**를 쓰며, VRChat 내보내기는 **Helper Meshes**를 켜지 않는 한 도우미 / 컨트롤 셰이프 메시를 FBX에서 뺍니다. VRM 패널에는 이제 **지금 린트**와 **Fix Humanoid Map**이 있으며, Fix Humanoid Map은 본 이름을 바꾸지 않고 내보내기 전에 오래된 휴머노이드 별칭 매핑을 고칠 수 있습니다.

**8.4.5:** Smart Combine은 이제 베이크 중에 소스 텍스처가 보존된 아틀라스 이전 UV를 샘플링하도록 강제하고, 원본을 숨기기 전에 생성된 아틀라스 메시를 검증하며, 모든 아틀라스 면을 최종 아틀라스 머티리얼 슬롯으로 재설정해 로브 / 의상 조각이 회색이 되거나 뒤섞이는 것을 막습니다.

**8.4.4:** 머티리얼 아틀라스 결합에 베이크 전 품질을 맞추는 검사 컨트롤이 추가되었습니다: 셰이더 / 머티리얼 진단, 텍스처 역할 라벨, 중복 / 공유 소스 표시, 머티리얼별 크기 재정의, 패킹 프리셋, 선택적인 Normal/Emission/Roughness 출력 베이크, 그리고 그 경로가 검증될 때까지 Metallic/ORM 채널 패킹을 막는 사전 차단.

**8.4.3:** 머티리얼 아틀라스 결합에 기존 머티리얼 아틀라스 워크플로 안에서 고를 수 있는 UV 패킹 방식이 들어갔습니다. Smart Pack, Grid Pack, Seeded Variation, Oriented Pack, Fit 0-1 Bounds, Advanced Variation, Rotation Step이 있으며, UV 방식의 세부 내용은 디버그 보고서와 베이크 기록에 남습니다.

**8.4.2:** 머티리얼 아틀라스 결합은 이제 베이크 중에 생성된 아틀라스 UV를 대상으로 하고, 복사된 소스 텍스처 노드는 아틀라스 이전 UV를 명시적으로 읽습니다. 소스 텍스처와 베이크된 아틀라스가 서로 다른 UV 맵을 샘플링해 생기던 로브 / 의상 아틀라스 결과의 깨짐이 고쳐졌습니다. 8.4.1의 선택 가능한 머티리얼과 텍스처 행은 계속 쓸 수 있습니다.

**7.1.3(환경 설정 라벨 정리):** 애드온 환경 설정의 스위치 두 개의 이름이 바뀌어, 이제 각각이 제어하는 사이드바 탭과 일치합니다. "VRChat Avatar Tools"는 이제 **CATS**(CATS 사이드바 탭과 일치)로, "Task Board & Sidebar"는 이제 **Rig Builder**(Rig Builder 사이드바 탭과 일치)로 표시됩니다. 제거된 도구는 없습니다. 편집 > 환경 설정 > 애드온 > BoneCraft의 켜기 / 끄기 라벨만 바뀌었습니다.

**7.1.1:** BoneCraft에 이제 CATS 도구가 들어 있습니다. VRChat 아바타를 깨끗하고 최적화되며 완전히 설정된 상태로 만들기 위해 특별히 설계된 모델 준비 도구 모음입니다. CATS는 전용 사이드바 탭에 있으며, 매번 올바른 작업 순서로 안내하는 파이프라인 시스템을 씁니다.
