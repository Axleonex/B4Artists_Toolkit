# Mechanisms(메커니즘)

[← 목차](index.md)

## Mechanisms가 하는 일

메커니즘은 딱딱한 표면 부품을 작동하는 기계 리그로 전환합니다.
슬라이드, 망원경, 피스톤, 기어, 추종자 및 전체 변형이 재생됩니다.
슬라이더 하나로. 일반적인 Blender 뼈대와 제약 조건을 구축하므로 다음을 볼 수 있습니다.
그리고 그것이 만드는 모든 것을 변경하면 리그는 스크립트 없이 Blender 에서 작동합니다.
엔진은 `DEF-` 뼈대를 받습니다. 구운 메커니즘 모션을 엔진으로 내보내기
나중에 제공됩니다(이 버전의 제한 사항 참조).

BoneCraft 는 무기가 아닌 도구를 배송합니다. 부품을 가져오시면 됩니다.

모든 단계에 대한 스크린샷이 포함된 완전한 작업 예제는 [튜토리얼: 메커니즘을 갖춘 Crescent Rose](12-crescent-rose.md) 입니다.

패널과 이 페이지에서 사용된 단어:

|말씀|의미|
|---|---|
|*부분*|하나의 단단한 블록으로 움직이는 조각: 물체 또는 하나의 메쉬의 느슨한 조각. 부품은 다른 부품 위에 올라갈 수 있습니다.|
|*공동*|부품 이동 방법: 힌지(회전), 슬라이드(이동), 망원경(중첩된 세그먼트 확장).|
|*링크*|부품을 움직이는 요소: 피스톤, 기어 링크, 팔로우.|
|*핸들*|뷰포트에서 드래그하는 뼈입니다. 각 관절에는 하나씩 있습니다. 해당 값은 패널의 슬라이더이기도 합니다.|
|*순서*|단계로 구성된 하나의 슬라이더로 수행되는 변형입니다.|
|*양식*|"Stowed" 또는 "Rifle"과 같은 저장된 핸들 및 시퀀스 값 세트입니다.|

## 위치

- 3D 뷰포트의 **BoneCraft tab → Mechanisms**. BoneCraft 탭이 켜져 있습니다.
오른쪽 사이드바로 이동하지 않은 경우 왼쪽 도구 선반(**T** 누르기)
(**N**) 환경 설정에서. 스킨과 리뷰 사이에 위치합니다. 메쉬가 있을 때 표시됩니다.
활성 상태이거나(리그를 시작하기 위해) 메커니즘이 있는 뼈대가 활성 상태일 때; 그렇지 않으면
무엇을 선택해야 하는지 설명합니다.
- **Properties editor → Scene tab → Mechanisms**, Rig Builder 바로 뒤. 그것은
기본 설정 → 탭 → 장면 속성 → 표시가 켜져 있는 동안 표시됩니다. 아무것도 없이
사용 가능하도록 선택하면 다음 줄이 표시됩니다: "메시를 선택하세요.
시작하거나 메커니즘을 갖춘 뼈대입니다." BoneCraft 뷰포트 탭 전환
off는 제거하지 않습니다. 장면 속성 스위치는 장면 복사본만 숨깁니다.
`mechanisms` 도구 스위치(**기본 설정 → 추가 기능 → BoneCraft → 도구**)
모든 위치에서 도구를 제거합니다.
장면 탭 섹션은 접힌 상태로 시작되므로 **Mechanisms** 를 클릭하여 확장하세요.
- **Object menu → Mechanisms**은 부품, 조인트 및 링크를 추가하는 바로가기를 제공합니다.
그리고 모션을 테스트합니다.
- **Viewport toolbar → Build Mechanism**은 다음에서 안내된 조인트 또는 링크를 시작합니다.
개체 모드 또는 포즈 모드에서 부품을 클릭합니다. 부품을 먼저 추가한 다음 선택하세요.
메커니즘 리그 또는 해당 부품 중 하나를 선택하고 도구 헤더에서 유형을 선택합니다.

메커니즘 내부에는 **1. Parts**,**2의 4개 하위 섹션이 있습니다. 관절 &
링크**,**3. 시퀀스** 및**4. 통제 수단**. 리그가 있으면 나타납니다.
부품. 그 전에는 **Add Parts from Selection** 만 표시됩니다.

모든 버튼은 하나의 실행 취소 단계입니다. 빌드가 실패하면 변경된 모든 내용이 적용됩니다.
뒤로 패널에 이유가 표시됩니다.

## 파트

1. 개체 모드에서 부품 개체(또는 느슨한 조각으로 구성된 하나의 메시)를 선택합니다.
2. **Add Parts from Selection** 를 클릭하세요.
 - 여러 개체: 개체당 하나의 부품. 각 객체는 해당 부분의 상위 항목입니다.
뼈가 있고 그 자리에 머물러 있습니다.
 - 느슨한 조각이 포함된 메시 1개: 조각당 부품 1개. 각 조각은 정점을 얻습니다.
뼈에 대한 그룹이 있고 메시는 뼈대 수정자를 얻습니다.
 - 처음으로 BoneCraft 가 당신을 위해 리그(뼈대)를 만들어줍니다.
3. 목록에서 부품을 선택하여 편집하세요.

각 부분에 대해:

- **탑승:** 이 차량이 움직이는 부분을 선택하세요. 하위 부품은 해당 부품을 따릅니다.
부모 부분. "리그(rig)"는 리그의 루트를 타고 달린다는 의미입니다.
- **Size** 는 핸들 크기를 설정하는 뼈 길이를 설정합니다.
- **Edit Pivot** 는 부품에 마커를 표시합니다. 부품이 있어야 할 위치로 드래그하세요.
돌리거나 슬라이드한 후 **Apply Pivot** 를 클릭하세요. 부품의 뼈가 그곳으로 이동합니다.
그리고 물체는 제자리에 남아있습니다.
- **Apply Transforms** 는 물체 부분에 회전이 적용되지 않은 경우 또는
규모. 클릭하세요. 적용되지 않은 변환은 축을 기울입니다.
- **X** 버튼은 부품을 제거합니다. 조인트, 링크 또는 기타
부분은 그것을 사용하고 이름을 지정합니다.
- **Merge for VRChat** (2개 이상의 객체 부분)는 객체 부분을 결합합니다.
이전 객체당 하나의 정점 그룹이 있는 하나의 메시와 뼈대 수정자.
이것을 마지막으로 하세요. 결합된 부분은 해당 메쉬의 느슨한 부분이 됩니다. 그것
이 뼈대 뼈의 이름을 딴 모든 정점 그룹을 제거합니다.
부품 자체의 `DEF-` 뼈)이므로 리깅된 부품만 병합하세요.
메커니즘 장비만 있으면 됩니다.

부품 객체의 이름을 바꿀 수 있습니다. 부품은 해당 객체에 태그가 지정되므로 부품
다시 그 대상을 찾습니다. 개체의 복사본(Shift+D)은 개체를 차지하지 않습니다.
부분. 부품의 객체가 삭제되면 부품에 "'<이름>' 부품이 없습니다"라고 표시됩니다.
**Reassign** 및**Delete** 를 사용합니다. 다른 메커니즘은 계속 작동합니다.

- **Reassign** 는 선택한 메시를 사용합니다. 논메쉬를 거부하고
다른 객체 부분이 이미 사용하고 있는 객체를 거부합니다. 하나의 느슨한 부분
메시는 해당 메시를 공유할 수 있습니다.
- **Delete** 는 부품을 제거합니다(거부되는 경우는 아래 편집 참조).

## 조인트와 링크, 각각 한 가지 예

**Add Joint** 와의 조인트,**Add Link** 와의 링크를 추가합니다. 각 선택은
가이드 빌드. 뷰포트 탭과 속성 편집기의 장면에서 작동합니다.
탭; 장면 탭에서 가이드는 화면에서 가장 큰 3D 뷰포트를 사용합니다.
또는 뷰포트 도구 모음에서 Build Mechanism을 활성화하고 조인트를 선택합니다.
또는 도구 헤더에 링크 유형을 입력하고 첫 번째 부분을 클릭하세요. 클릭하면
동일한 가이드가 첫 번째 픽을 공급합니다. 선택 및 축 선택을 계속하세요.
뷰포트에서 요청됨; 접합 추가 및 링크 추가 메뉴는 계속 사용할 수 있습니다.

모든 안내식 빌드에 대한 간단한 규칙:

- 뷰포트에서 부품을 클릭합니다. 클릭한 부분에는 윤곽선과 번호가 표시됩니다.
- 단계에 축이 필요한 경우 **X**,**Y** 또는**Z** 를 누르거나**A**를 눌러 정렬합니다.
선택. **Align to Selection** 는 각진 경첩용입니다. 부품의 메쉬가 필요합니다.
**A**를 누를 때 한쪽 모서리나 면이 선택된 상태로 여전히 편집 모드에 있어야 합니다.
가이드는 **Tab** 를 무시합니다. 따라서 부품의 메쉬에 편집 모드로 들어가서
모서리나 면 중 하나를 먼저 선택합니다. 편집 모드를 유지하고 **조인트 추가 →를 시작하세요.
힌지**, 부품을 클릭하고**A**를 누릅니다. 사용할 수 있는 항목이 선택되지 않은 경우 가이드
라고 알려주고 다른 키를 누르시면 됩니다.
- 마지막 단계에서는 루프에서 움직이는 메커니즘을 미리 봅니다. **Enter** 는 그것을 유지합니다.
**Esc** 가 이를 제거합니다.
- 헤더와 상태 표시줄에는 각 단계의 전체 문장이 표시됩니다. 쇼 포함
도우미들은 짧은 라벨을 보여줍니다.

관절 및 링크 목록의 각 행에는 4개의 아이콘 버튼이 있습니다: **Test** (재생
삼각형), **Edit** (연필, 설정 표시),**Detach** (깨진 체인) 및
**Delete** (X).

빌드 후 목록에서 선택한 항목에는 해당 항목의 설정만 표시됩니다.
유형을 사용합니다.

### Hinge(힌지)

블레이드 힌지, 0°~90°:

1. 블레이드 부품을 사용하여 선택 항목에서 부품을 추가합니다.
2. **Add Joint → Hinge**. 블레이드를 클릭합니다.**X** 를 누릅니다.**Enter** 를 누릅니다.
3. 반원형 손잡이 `CTRL-Blade` 와 *블레이드 힌지*가 있습니다.
목록. **Min** 0 및**Max** 90(경첩의 경우 °)을 설정합니다.
4. 시도해 보세요: 반원 핸들을 드래그하세요. 90°에서 멈춥니다. **Set Min** 및
**Set Max** 는 핸들의 현재 포즈를 제한에 복사합니다.

완전히 회전하는 한계는 -180°…180° 범위 내에 있어야 합니다. 다음과 같은 한도
170°…190°는 메시지와 함께 거부됩니다. 전체 회전 이상의 범위(예:
예: −180°…180°)는 제한 없이 자유롭게 회전합니다.

### Slide(슬라이드)

배럴 슬라이드, 0…0.3:

1. **Add Joint → Slide**. Barrel 부분을 클릭합니다.**Y** 를 누릅니다.**Enter** 를 누릅니다.
2. 화살표 손잡이를 얻을 수 있습니다. **Min** 0 및**Max** 0.3(장면 단위)을 설정합니다.
3. 시도해 보세요: 화살표를 드래그하세요. 배럴이 미끄러지며 0.3에서 멈춥니다.

### Telescope(텔레스코프)

세 부분으로 구성된 마스트:

1. 베이스와 3개의 세그먼트 파트를 만듭니다.
2. **Add Joint → Telescope**. 베이스를 클릭합니다. 베이스에서 각 세그먼트를 클릭합니다.
바깥쪽으로. **Enter** 를 누릅니다. 축 키를 누릅니다. 유지하려면**Enter** 를 누르세요.
3. 베이스에 화살표 핸들이 하나 있습니다. **Length** 는 총 이동 거리입니다.
**Shares (empty = even)** 는 이를 세그먼트 간에 분할합니다. 사용자 정의를 시도하려면
공유하려면 먼저 **Length** 를 1로 설정한 다음 `0.5, 0.25, 0.25` 를 입력하세요. 주식
길이까지 합산되어야 팁이 전체 길이를 이동합니다. 오타(
예 `0.5, abc` )는 동일한 일반 메시지로 거부됩니다.
길이를 합산하는 숫자(세그먼트당 하나씩)여야 합니다.
4. 시도해 보세요. 화살표 하나를 드래그하세요. 세 세그먼트 모두 해당 지분으로 확장됩니다.
**Set Max** 는 핸들 자세에서 길이를 설정합니다.

### Piston(피스톤)

리프트: 프레임의 실린더, 암의 로드.

1. 팔에 먼저 힌지를 부여하고 팔이 프레임에 탑승하도록 설정합니다.
2. **Add Link → Piston**. 원통 부분(프레임 위)을 클릭합니다. 막대를 클릭하세요.
부분 (팔).
3. 손잡이가 없는 피스톤을 얻게 됩니다. 각 부분은 다른 부분의 부착물을 가리킵니다.
포인트. **Stretch** (옵션)는 스프링과 케이블용 로드를 늘립니다.
4. 시도해 보세요. 팔의 손잡이를 움직여 보세요. 피스톤이 따라옵니다. 아무것도 움직이지 않으면
피스톤은 아직 빌드가 작동하지만 미리보기가 없으며 **Test** 는 그렇게 말합니다.

### Gear Link(기어 링크)

기어 20:40:

1. 두 부분 모두 먼저 조인트가 필요합니다. 구동부분에는 힌지가 필요합니다. 기어 및
벨트 구동 부분에는 힌지가 필요합니다. Rack의 경우 슬라이드가 필요합니다.
2. **Add Link → Gear Link**. 구동 부분을 클릭하세요. 피동 부품을 클릭합니다.
3. 해당 설정에서 **Source Teeth** 20 및**Target Teeth** 40을 설정합니다(또는
**Ratio** ).**Kind** 는 기어, 벨트 또는 랙입니다.**Reverse** 는 방향을 반전시킵니다.
4. 시도해 보십시오: 소스를 켜십시오. **Kind** Gear를 사용하면 대상이 −0.5×만큼 멀리 회전합니다.
(벨트 포함 시 +0.5배) A 기어가 반전됨
방향을 벨트가 유지하고, 랙이 회전을 슬라이드(거리)로 변환합니다.
라디안당 = **Ratio** ×**Pinion Radius** ).

BoneCraft 가 빌드하는 방법은 소스 힌지 범위에 따라 다릅니다.

- 완전히 회전하는 경우: 변환 제약 조건. 움직이는 모든 것을 따라간다
소스, 시퀀스가 포함되어 있습니다.
- 한 바퀴 이상: Python이 필요 없는 드라이버입니다. 대상은 영원히 회전합니다.
소스와 함께. 핸들과 기어만 따릅니다. 리그 검증기(Rig Validator)가 경고합니다.
시퀀스나 팔로우가 손실되는 경우.

### Follow(따라가기)

블레이드 0~90° 리프트 커버 0~40°:

1. 두 부품 모두 힌지 또는 슬라이드가 필요합니다. 소스 힌지에는 다음 제한이 필요합니다.
완전 회전; 자유 회전 소스는 거부됩니다.
2. **Add Link → Follow**. 앞부분(블레이드)을 클릭합니다. 다음을 클릭하세요
부분(표지).
3. 범위는 각 관절의 전체 범위로 시작됩니다. **Source Range** 설정
0…90 및 **Target Range** 0…40. 양쪽 끝을 지나면 목표물이 유지됩니다.
4. 시도해 보세요. 블레이드 핸들을 움직여 보세요. 표지는 다음과 같습니다.
5. 그래프 편집기에서 매핑의 모양을 변경하려면 **Curve** 를 선택하세요. BoneCraft 절대
곡선을 덮어씁니다(아래 편집 참조).

### Sequence(시퀀스)

무기를 접는 단계를 기록하세요.

1. **3. Sequences** 에서**Add Sequence** 를 클릭합니다. 슬라이더 핸들을 만듭니다.
`CTRL-SEQ-<name>`.
2. **Move Slider to End** 를 클릭하세요. 슬라이더가 끝(1)으로 이동하고 버튼이
레코드 단계가 되고 그 뒤에 다음 단계 번호가 옵니다.
3. 첫 번째 단계에서 관절의 손잡이 위치를 잡습니다. 1단계 녹음을 클릭하세요.
이동한 각 핸들은 목표 값을 갖는 단계가 되며,
핸들이 0으로 돌아갑니다.
4. 추가 단계를 보려면 2단계와 3단계를 반복하세요. 각각의 새로운 단계는 다음 분기에 수행됩니다.
기본적으로 슬라이더.
5. **Target**, 이즈(선형, 이즈 인, 이즈 아웃, 이즈 인 아웃, 스냅)를 설정합니다.
각 단계마다 **Start** 및**End** 가 있습니다. 슬라이스 외부에는 단계의 끝이 있습니다.
가치. 여러 시퀀스가 쌓일 수 있습니다.
6. **Test** 를 클릭하면 슬라이더가 0 → 1 → 0으로 재생됩니다.

단계 녹음 버튼과 **Test** 옆에 선택한 시퀀스에는**Detach** 가 있습니다.
(깨진 체인) 및 **Delete** (X). 보류된 시퀀스(예:
모양을 변경한 곡선)에는 해당 메시지와 **Restore** 버튼이 표시됩니다. 복원
레코드에서 단계를 재생성합니다. Keep Mine은 시퀀스에 제공되지 않습니다.

## 테스트

**Test** (목록 및 3. 시퀀스의 재생 버튼)이 하나를 스윕합니다.
전체 범위와 뒤로를 통한 메커니즘. 키를 쓰지 않고 포즈를 취합니다.
끝나면 다시. 일찍 중지하려면 **Esc** 를 누르세요. 그러면 포즈가 복원됩니다.
너무. Gear Link 또는 Follow의 경우 소스를 스윕합니다. 피스톤의 경우
그것을 움직이는 관절. 충돌하는 부분을 주의하세요. BoneCraft 가 감지하지 못함
충돌.

## 폼

**4. Controls** 에서:

- 모든 관절과 시퀀스에는 하나의 슬라이더가 있습니다. 핸들 자체 채널이므로
핸들을 드래그하는 것과 슬라이더를 사용하는 것은 동일합니다.
- **Save Form** 는 모든 핸들과 시퀀스 슬라이더 값을 이름으로 기록합니다.
목록에서 이름을 바꾸십시오.
- **Go to Form** 는 모든 제어를 저장된 값으로 설정합니다.
- **Go and Key** 는 동일한 작업을 수행하며 현재 프레임에 키를 삽입합니다.
- 목록 옆에 있는 **X** 는 양식을 제거합니다.

## BoneCraft가 만드는 것

각 부분에 대해:

|뼈|직업|보이는|
|---|---|---|
|`CTRL-<part>` |손잡이. 그 값은 패널 슬라이더입니다. 힌지(Hinge), 슬라이드(Slide), 텔레스코프(Telescope)만이 하나를 만듭니다.|예|
|`MCH-<part>` |핸들과 모든 링크를 추가한 다음 제한을 적용합니다.|숨겨진|
|`DEF-<part>` |`MCH-<part>` 를 복사합니다. 메쉬가 바인딩되어 있습니다. 엔진은 이 뼈를 받습니다.|숨겨진|

뼈는 `Mechanism Controls`, `Mechanism MCH` 컬렉션에 있으며
`Mechanism DEF`. 조인트가 없는 부품에는 `MCH-` 및 `DEF-` 뼈만 있습니다. 에이
망원경의 손잡이는 `CTRL-<telescope name>` 입니다. 시퀀스는 다음과 같습니다.
`CTRL-SEQ-<name>`. 피스톤은 `MCH-<part>-aim` 및 `MCH-<part>-target` 뼈를 추가합니다.
두 부분 각각에 대해.

`MCH-<part>` 의 제약 조건은 항상 동일한 순서로 나타납니다.
핸들에서 각 링크의 기여도, 조인트의 회전 제한
또는 위치 제한. `DEF-<part>` 에는 `MCH-<part>` 의 복사 변환이 하나 있습니다.

모든 BoneCraft 빌드에는 다음 레코드가 태그되어 있습니다: 제약 조건 이름 시작
`BC·<id>·<role>` 를 사용하고 뼈는 `bc_mech_id` 속성을 전달하며
`bc_mech_role`. BoneCraft 는 이름이 아닌 태그로 뼈대를 찾으므로 다음을 수행할 수 있습니다.
뼈의 이름을 바꿉니다. 다시 빌드하면 다시 찾아서 중복되지 않습니다.

Show Helpers를 켜면 각 조인트와 링크에 **How this works** 메모가 있습니다. 그것
이름별로 제약 조건을 나열하고 각각의 기능을 설명하며 **Select** 가 있습니다.
버튼(화살표 아이콘)을 사용하여 뼈를 검사합니다.

자신의 제약 조건, 드라이버 및 뼈대는 절대 건드리지 않습니다. 추가한 제약조건
MCH 뼈는 재구축 후에도 BoneCraft 아래에 유지됩니다.

## 편집과 직접 편집

- **값 편집**(한계, 비율, 범위, 타이밍, 용이성, 핸들 모양) 업데이트
기존 제약 조건이 적용되었습니다. 재건축은 없습니다.
- **구조적 편집**(Gear Link의**Kind**, Follow의**Curve**, a
피스톤의 **Stretch** )는 해당 메커니즘의 제약 조건을 대체하고 재구축만 합니다.
그 메커니즘.
- **수동으로 변경되었습니다.** BoneCraft 제약 조건을 편집하는 경우(예:
Limit) 메커니즘의 메시지는 "(changed by hand)"로 끝납니다. BoneCraft 는 절대 덮어쓰지 않습니다.
조용히 말이죠. 선택:
 - **Keep mine** 는 값을 레코드에 복사합니다. 거부할 수 없는 것은 거부한다
다시 읽어보고 복원 또는 분리를 사용하라고 말합니다.
 - **Restore** 는 편집 내용을 버리고 레코드에서 다시 작성합니다.
- 고정된 메커니즘은 뼈대를 사용하는 모든 메커니즘도 보유합니다.
그것을 해결하십시오.
- 모양이 변경된 곡선도 동일합니다. Follow 곡선의 모양을 바꾸면 (**Curve**
선택) 그래프 편집기에서 이를 대체할 값을 변경합니다.
Target Range와 같은 Follow 메시지는 "(changed by hand)"로 끝납니다. **Keep mine**
곡선을 유지합니다. **Restore** 가 이를 재생성합니다.
- 보류된 시퀀스는 **Restore** 에 해당 메시지와**3. Sequences** 를 표시합니다.
그 옆에 **Detach** 및**Delete** 가 있습니다. Keep Mine은 시퀀스에 제공되지 않습니다.
- **Detach** (깨진 체인 버튼)는 레코드와 태그를 삭제하지만 뼈대와 태그는 유지합니다.
자신의 손으로 만든 장비로 제약 조건을 충족합니다. 분리 및 삭제 모두 기록을 거부합니다.
다른 레코드가 사용하는 것을 선택하고 사용자의 이름을 지정합니다.
- **Delete** (X 버튼)는 레코드와 이를 위해 만들어진 모든 BoneCraft 를 제거합니다.
- 링크 루프는 무엇이든 구축되기 전에 거부되고 루프 이름이 지정됩니다.
예: "블레이드 힌지 → 커버 따르기 → 블레이드 힌지가 반복됩니다."

Rig Validator와 Task Board는 링크 루프, 누락된 부품, DEF를 보고합니다.
메커니즘 외부에서 이동된 뼈, Python 및 Gear가 필요한 드라이버
시퀀스 또는 팔로우가 손실된 링크. 유효성 검사기의 이름 지정 확인이 허용됩니다.
하이픈(`CTRL-`, `MCH-`, `DEF-` ) 및 해당 드라이버 확인은 다음 경우에만 경고합니다.
Python이 필요한 표현식이므로 깨끗한 Mechanisms 리그에는 유효성 검사가 표시되지 않습니다.
오류 - 이 버전의 제한 사항에 설명된 `root` 뼈에 대한 경고 하나만 있습니다.

## Show Helpers(도움말 표시)

**Show Helpers** 는 모든 BoneCraft 에 대한 하나의 기본 설정입니다.**기본 설정 →
애드온 → BoneCraft → 도우미**. Off는 무엇을/언제 어디서나 교육 텍스트를 숨깁니다.
라인, **How this works** 노트 및 전체 안내 단계 문장(해당
짧은 레이블이 됨) 단계 자체, 목록, 테스트, 경고 및
Blender 의 호버 툴팁은 항상 유지됩니다.

VRChat **Compact Mode** 버튼은 바로 가기입니다. 컴팩트 모드가 켜져 있으면 표시를 의미합니다.
도우미가 꺼졌습니다.
