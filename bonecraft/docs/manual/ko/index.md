BoneCraft 9.2.5. BoneCraft는 Bforartists용 리깅 및 아바타 툴킷입니다.

이 설명서는 영어판을 기계 번역한 것입니다.

탭은 기능 그룹을 선택합니다. Setup Rigging, Skin, Review, Avatar Tools, Facial은 탭 안에서 펼치는 섹션이며 별도 탭이 아닙니다. 아래 경로는 영어 UI 이름입니다. 번역된 이름은 Language 설정에 따라 달라집니다.

## 장

1. [시작하기](01-start.md) — BoneCraft 소개, 설치, 모든 기능의 위치.
2. [가이드 1–7](02-guides-a.md) — 첫 아바타, VRoid, MMD, 본 이름, 휴머노이드 매핑, 머리카락, 의상.
3. [가이드 8–13](03-guides-b.md) — 립싱크, 성능, 포즈, 리그 합치기, 업로드 문제, CATS.
4. [CATS 파이프라인](04-cats-pipeline.md) — 여섯 단계, 기록, 그리고 순서가 중요한 이유.
5. [리그 도구](05-rig-tools.md) — 리그 UI, 애니메이션, 웨이트, 리그 제어 도구.
