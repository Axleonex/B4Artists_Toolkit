# 리그 도구

[← 목차](index.md)

이 장에서는 BoneCraft의 리깅, 애니메이션, 웨이트 도구를 자세히 설명합니다. 기능을 더 깊이 이해하고 싶을 때나, 가이드가 내 상황을 정확히 다루지 않을 때 이 장을 보세요.

각 항목은 도구가 하는 일, 쓰는 때, 주요 컨트롤, 위치를 설명합니다. 일부 도구는 특정 모드에서만 나타나며, 각 항목의 "위치" 줄에 그 모드가 적혀 있습니다: 예를 들어 리그 컨트롤은 포즈 모드에서, 웨이트 미러와 웨이트 전송은 웨이트 페인트 모드에서, 델타 머시는 오브젝트 모드에서 나타납니다.

---

## 리그 UI 도구

아마추어를 다룰 때의 시각적인 면을 관리하는 도구입니다: 어떤 본을 보이게 할지, 어떻게 정리할지, 빠른 접근.

---

### 본 컬렉션

**하는 일:** 스켈레톤의 본 컬렉션을 줄로 보여 줍니다. 컬렉션 이름을 클릭하면 그 본들이 선택되고, 눈 아이콘으로 보이거나 숨깁니다.

> 본 컬렉션은 이름이 붙은 본의 그룹입니다(예: "IK Controls", "Face Bones", "Deform Bones"). 컬렉션을 숨기면 그 본들이 뷰포트에서 숨겨지므로, 리그의 한 부분에 집중할 수 있습니다.

**주요 컨트롤:**
- 각 줄: 강조 색, **Toggle Collection Visibility**(컬렉션 표시 전환, 눈 아이콘), 컬렉션 이름(본 선택), **Solo Collection**(컬렉션 단독 표시, S 아이콘), **Rename Collection Display**(컬렉션 표시 이름 바꾸기, 톱니바퀴 아이콘) — 마지막 것은 줄에 쓸 사용자 표시 이름을 정합니다
- **Show All Collections**(모든 컬렉션 표시)와 **Hide All Collections**(모든 컬렉션 숨기기)(목록 위의 뜬 눈과 감은 눈 아이콘) — 전부 한 번에
- 섹션 — 여러 컬렉션을 접을 수 있는 제목 아래로 묶습니다

**위치:** BoneCraft 탭 → 리뷰 → 컬렉션

---

### 가시성 북마크

**하는 일:** 어떤 본 컬렉션이 보이는지 저장해, 저장한 보기 사이를 바로 전환할 수 있게 합니다.

**사용 예:** 표정 작업을 위해 얼굴 본만 보이는 보기를 만들어 "Face Only"로 저장합니다. 그런 다음 웨이트 페인팅을 위해 전부 보이게 하고 "Full Rig"로 저장합니다. 이제 한 번의 클릭으로 둘 사이를 전환합니다.

**주요 컨트롤:** 슬롯마다 한 줄입니다.
- 북마크 이름 — 클릭하면 저장한 보기를 적용합니다
- **Save Bookmark**(북마크 저장, 디스크 아이콘) — 현재 표시 상태를 슬롯에 저장합니다
- 색 견본 — 북마크에 색을 붙입니다
- **Clear Bookmark**(북마크 지우기)와 **Remove Bookmark**(북마크 제거, 닫기 아이콘) — 슬롯을 비우거나, 추가한 슬롯을 제거합니다
- **북마크 추가** — 슬롯을 추가합니다

**기본 북마크:** FK Arms, IK Body, Face Only, Full Rig

**위치:** BoneCraft 탭 → 리뷰 → 컬렉션 → 가시성 북마크

---

### 단축키 빠른 패널

**하는 일:** BoneCraft의 리그 패널(컬렉션과 북마크)을 커서가 있는 곳에 팝업으로 엽니다.

**사용 방법:** 3D 뷰포트에서 **Ctrl+Shift+R**을 누릅니다. 팝업 바깥을 클릭하면 닫힙니다.

**위치:** 3D 뷰포트의 단축키 **Ctrl+Shift+R**(별도의 패널은 없습니다)

## 애니메이션 도구

---

### 포즈 라이브러리

**하는 일:** 이름과 썸네일이 있는 포즈를 저장해, 한 번의 클릭으로 리그에 적용할 수 있게 합니다.

**주요 컨트롤:**
- **저장** — 현재 본 위치를 이름 붙은 포즈로, 뷰포트 썸네일과 함께 저장합니다
- **적용** — 본을 저장된 포즈에 맞춥니다
- **블렌드** — 포즈를 일부 강도로, 현재 위치와 섞어 적용합니다
- **미러** — 포즈를 좌우로 뒤집어 적용합니다
- **삭제**, **이름 바꾸기**, **카테고리** — 목록을 관리합니다. **필터**는 한 카테고리만 보여 줍니다
- **내보내기**와 **가져오기** — `.bfpose` 파일에 저장하거나 그 파일에서 불러옵니다

**위치:** BoneCraft 탭 → 리뷰 → 포즈 라이브러리

---

### Control Picker(컨트롤 피커)

**하는 일:** 리그 컨트롤을 클릭할 수 있는 지도입니다. 모양을 클릭하면 그 본이 선택되고, 피커는 선택된 것을 강조합니다.

**주요 컨트롤:**
- **Generate Picker**(피커 생성) — 리그로부터 배치를 만듭니다
- **Edit Layout**(배치 편집) — 컨트롤을 옮기고, 크기를 바꾸고, 라벨을 바꿉니다. **Move Picker Control**(피커 컨트롤 이동), **Resize Picker Control**(피커 컨트롤 크기 조정), **Relabel Picker Control**(피커 컨트롤 라벨 변경)은 각 컨트롤의 줄에 아이콘으로 나타납니다. **Snap**(스냅)으로 그리드에 맞추고, **레이아웃 다시 빌드** 버튼으로 다시 만듭니다
- **선택 미러** — 반대쪽 컨트롤을 선택합니다
- **팝업 피커** — 피커를 떠 있는 창으로 엽니다. 거기에는 **Add Selection Set**(선택 세트 추가)도 있습니다

**위치:** BoneCraft 탭 → 리뷰 → Control Picker

---

### Control Layer(컨트롤 레이어, IK/FK)

그림으로 비교하는 실습은 [웨이트 검사와 IK/FK](06-rig-builder.md#파트-c-웨이트-검사와-ikfk)를 보세요.

**하는 일:** **컨트롤 리그 빌드** 버튼으로 만든 리그의 팔다리를 위한 애니메이터용 컨트롤입니다: 팔다리가 튀지 않게 IK와 FK를 전환하고, 프레임 범위에 걸쳐 한쪽을 다른 쪽으로 베이크합니다.

**주요 컨트롤:**
- **IK**와 **FK** — 팔다리를 전환하고 새 컨트롤을 팔다리의 현재 위치에 맞추므로, 팔꿈치나 무릎이 튀지 않습니다
- **Bake IK**(IK로 베이크)와 **Bake FK**(FK로 베이크) — 프레임 범위의 애니메이션을 IK나 FK로 변환합니다
- **Pole Follow**(폴 따라가기), **Pin**(고정), **Lock-Free**(잠금 해제), 그리고 보호된 잠금을 유지하는 **Global Rig Scale**(리그 전체 스케일)

**위치:** BoneCraft 탭 → 리뷰 → Control Layer(**컨트롤 리그 빌드** 버튼으로 만든 리그를 선택했을 때. [리그 빌더](06-rig-builder.md) 참고)

---

### Rigify 도구

**하는 일:** Rigify 컨트롤 리그를 감지해, BoneCraft의 컬렉션 패널, 북마크, 속성 슬라이더를 Rigify의 표준 컨트롤에 연결합니다.

> Rigify는 애니메이션 준비가 된 리그를 생성하는 Bforartists 내장 시스템입니다. Rigify로 리그를 만들었다면, 이 도구가 BoneCraft의 UI를 Rigify의 IK/FK 컨트롤에 연결합니다.

**주요 컨트롤:**
- **자동 향상** — 선택한 Rigify 리그에 맞게 BoneCraft의 패널을 설정합니다
- **향상 재실행** — 처음부터 다시 만듭니다
- **Enable Rigify**는 Quick Rig에 있고 **Generate Control Rig (active metarig)**는 그 안의 Troubleshooting을 펼치면 있습니다([리그 빌더](06-rig-builder.md) 참고)
- Rigify 속성 — 리그의 IK/FK, 스트레치, 부모 공간, 머리와 목 따라가기 슬라이더

**위치:** BoneCraft 탭 → 리깅 설정 → Rigify 도구(와 Rigify 속성 섹션)

---

### 리타겟

**하는 일:** 한 스켈레톤의 애니메이션을 다른 스켈레톤으로 옮깁니다(예: 모션 캡처 클립을 내 아바타에). 본은 이름과 방향으로 맞춰지므로 팔다리가 방향을 유지합니다. 쇄골은 느슨하게 맞춰지므로 어깨가 지나치게 돌지 않습니다.

**주요 컨트롤:**
- **클립 가져오기**와 **라이브러리 탐색** — 클립을 불러오거나 라이브러리 폴더를 설정합니다. 클립 이름을 클릭하면 선택됩니다
- **Auto-Match Bones**(본 자동 매칭, 클립 줄의 체크 표시) — 소스와 대상 본을 짝짓습니다(패널의 본 매핑 목록에 짝이 표시됩니다)
- **미리보기**와 **미리보기 중지** — 결과를 시험합니다
- **적용** — 클립을 내 리그에 베이크합니다

**위치:** BoneCraft 탭 → 리깅 설정 → 리타겟

---

### 보정 셰이프 키

**하는 일:** 본이 어떤 각도에 이르면 켜지는 셰이프 키로, 극단적인 포즈에서 생기는 꼬집힘이나 무너짐을 고칩니다.

**사용 예:** 캐릭터의 팔꿈치를 끝까지 굽히면 무너집니다. 고친 팔꿈치를 스컬프트하고 팔 본에 연결하면, 팔꿈치를 굽힐수록 자동으로 적용됩니다.

**주요 컨트롤:**
- 새 교정 — **형태 키**, **드라이버 본**, 회전 축, 모양이 완전히 켜지는 각도, 서서히 켜지는 정도를 고른 다음 **보정 생성**을 클릭합니다
- 보정 목록: 보정의 셰이프 키 이름을 클릭해 선택합니다. 목록 아래의 **편집**과 **삭제**는 선택한 보정에 적용됩니다

**위치:** BoneCraft 탭 → 스킨 → 교정(메시에 기준 셰이프 키가 필요합니다)

---

### 그래프 도구

**하는 일:** 키프레임과 커브를 다듬는 애니메이션 도구입니다.

- **인터랙티브 브레이크다운**(브레이크다우너, 3D 뷰포트 단축키 **Ctrl+Shift+B**) — 좌우로 드래그해 현재 포즈를 가장 가까운 키프레임 사이에서 블렌드합니다
- **델타 적용**(델타 무버, 3D 뷰포트 단축키 **Ctrl+Shift+D**) — 선택한 본을 화면 공간이나 월드 공간에서 정확한 양만큼 옮깁니다
- **캡처**와 **교체**(버퍼 커브) — 커브의 사본을 보관하고 그것과 편집본을 바꿔 봅니다
- **스마트 베이크** — 컨스트레인트로 움직이는 애니메이션을 키로 베이크하고 불필요한 키를 버립니다(**허용치**로 정도를 정합니다)
- **오일러 필터** — 짐벌 락으로 생긴 회전 뒤집힘을 고칩니다
- 접선 핸들 — 선택한 키의 핸들 유형을 설정합니다: **Auto**(자동), **Vector**(벡터), **Aligned**(정렬), **Free**(자유), **Auto Clamped**(자동 고정)

**위치:** BoneCraft 탭 → 리뷰 → 그래프 도구

## 웨이트 도구

본이 움직일 때 메시가 어떻게 변형되는지 제어하는 도구입니다. 웨이트는 메시의 각 부분에 어떤 본을 얼마나 따라갈지 알려 줍니다.

---

### 본 웨이트 자동 재계산

**하는 일:** 메시를 바꾸지 않고 기존 리그로 웨이트를 다시 계산합니다. 고밀도 메시는 가벼운 프록시를 사용하여 조용한 실패를 피합니다.

**컨트롤:** 대상 메시·아마추어와 Body 또는 Clothing 모드를 고릅니다. Body는 기존 리그에서 계산하고 Clothing은 올바르게 웨이트된 원본 메시에서 전송합니다. 방식·블렌드·스무딩·정점당 최대 본 영향·최소 웨이트·백업을 정하여 **Automatic Bone Weight Recalculation**을 실행합니다. 설정은 버튼 위입니다. CATS의 **Smart Automatic Weights**는 메시·아마추어·모드 및 Clothing 원본 메시를 고르는 대화상자를 엽니다.

**위치:** BoneCraft → Skin → Weight Tools.

---

### 웨이트 미러

**하는 일:** 아바타 한쪽의 웨이트를 반대쪽으로 복사합니다. 대칭 캐릭터에 꼭 필요합니다.

**주요 컨트롤:**
- **모든 웨이트 미러** — 모든 본 그룹을 반대쪽으로 미러합니다
- **활성 웨이트 미러** — 활성 본 그룹만 미러합니다
- 대칭 축과 미러 방향(양방향, 왼쪽에서 오른쪽, 오른쪽에서 왼쪽)
- **토폴로지 미러** — 위치가 아니라 메시 토폴로지로 정점을 짝짓습니다
- **검색 거리** — 두 정점이 얼마나 떨어져 있어도 짝으로 볼지(완전히 대칭이 아닌 메시라면 늘리세요)
- **일치하지 않는 항목 선택** — 짝이 없는 정점을 선택합니다. 그다음 **가중치 정규화**로 웨이트의 합을 1.0으로 만듭니다

**위치:** BoneCraft 탭, 웨이트 페인트 모드 → 웨이트 미러

미러 버튼을 먼저 누르고 Adjust Last Operation에서 축·방향·토폴로지 모드·검색 거리를 설정합니다. **Mirror Active Weight**는 Weights → BoneCraft와 기본 Weights Tool Shelf에도 있습니다.

---

### 웨이트 전송

**하는 일:** 원본 메시의 웨이트를 활성 메시로 복사합니다. 몸에서 의상으로 또는 고해상도에서 저해상도로 옮길 때 씁니다.

**컨트롤:** 원본 메시를 먼저 고르고 **Transfer Weights**를 실행합니다. 이후 Adjust Last Operation에서 전송 방식·본 필터·**Normalize**를 정합니다. Normalize는 합을 1.0으로 유지합니다. 결과는 평균·최대 거리를 보여 주며 **Select Problem Vertices**는 잘 맞지 않은 정점을 선택합니다.

**위치:** BoneCraft의 Weight Paint → Weight Transfer; Skin → Weight Tools에도 있습니다.

---

### 웨이트 테이블

**하는 일:** 선택 정점의 본별 정확한 웨이트를 보고 값을 직접 설정합니다.

**사용:** Weight Paint에서 정점 하나를 선택합니다. 행의 손 아이콘을 누르고 Adjust Last Operation에서 **Weight**를 정합니다. Add Influence는 고른 본을 사용하고 새 웨이트도 Adjust Last Operation에서 정합니다. 여러 정점에서는 **Normalize All Vertices**로 모두 정규화합니다.

**위치:** BoneCraft의 Weight Paint → Weight Table.

---

### 플러드 채우기

**하는 일:** 선택 정점에 활성 그룹의 웨이트를 **Flood to 0.0**, **Flood to 1.0**, **Flood to Custom**으로 한 번에 설정합니다. Custom 실행 후 Adjust Last Operation에서 **Value**와 **Normalize**를 정합니다. Weights 메뉴·셸프의 고정 버튼명은 Flood to Zero와 Flood to One입니다.

**위치:** BoneCraft → Skin → Weight Tools; Weights → BoneCraft, Tool Shelf → Weights → BoneCraft에도 있습니다.

---

### 변형 vs 컨트롤

**하는 일:** 리그의 본을 변형 본(메시를 움직임)과 컨트롤 본(애니메이터가 움직임)으로 나누고, 변형 본에 표시를 하고, 변형용 이름으로 바꾸고, 변형 본만 있는 스켈레톤을 내보냅니다.

**위치:** BoneCraft 탭, 포즈 모드 → 변형 vs 컨트롤

---

### 델타 머시

**하는 일:** 관절의 찌그러짐을 줄이는 스무딩 변형입니다. 레스트 형상을 유지하며 움직일 때 변형을 부드럽게 합니다.

**사용:** **Add Delta Mush**로 모디파이어를 추가하고 레스트 형상에 바인딩합니다. 즉시 Adjust Last Operation에서 **Iterations**, **Smooth Strength**, **Pin Borders**, **Only Smooth Deform**을 정합니다. 이후 패널에 **Rebind**, **Remove**와 반복 수·강도·경계 고정의 Settings가 나타납니다.

**위치:** BoneCraft → Skin → Delta Mush (Object Mode; 메시).

---

### 근접 래핑

**하는 일:** 한 메시가 다른 표면을 두 번째 피부처럼 따라갑니다. 밀착 의상에 유용합니다.

**사용:** 대상 메시와 다른 **Driver Mesh**를 고르고 **Bind Proximity Wrap**을 누릅니다. 바인딩할 때 드라이버 아마추어는 레스트 포즈여야 합니다. Options의 **Falloff Type**, **Max Distance**는 9.1.2에서 저장되지만 Surface Deform 바인딩은 바꾸지 않습니다. 연결 후 **Rebind**, **Unbind**가 표시됩니다. Unbind는 뷰포트·렌더의 모디파이어를 끄며 삭제하지 않습니다.

**위치:** BoneCraft → Skin → Proximity Wrap (Object Mode; 메시).

---

## 리그 컨트롤

이 도구들은 포즈 모드의 BoneCraft 탭에 나타납니다.

---

### 스페이스 스위치

**하는 일:** 애니메이션 중에 본이 따라가는 공간을 바꿉니다. 소품을 든 손을 한 번의 클릭으로 몸을 따라가는 상태에서 월드에 고정된 상태로 바꿀 수 있습니다.

**주요 컨트롤:**
- **공간 추가**와 **Remove Space**(공간 제거, 스페이스 관리 아래의 X 아이콘) — 본이 따라갈 수 있는 공간(월드, 원점, 다른 본)
- 공간마다 그 이름의 버튼이 하나씩 있고, 현재 공간에는 ●가 붙습니다. 다른 공간의 버튼을 클릭하면 본이 그 공간으로 바뀝니다

**위치:** BoneCraft 탭, 포즈 모드 → 스페이스 스위치

---

### 스플라인 IK

**하는 일:** 본 체인이 곡선을 따르게 합니다. 부드러운 움직임의 꼬리·촉수·밧줄·긴 머리·척추에 씁니다.

**사용:** 시작 본을 활성화하고 **Generate Spline IK**를 누릅니다. Adjust Last Operation에서 **Chain Length**, **Curve Resolution**, **Stretch**, **Volume Preservation**을 정합니다. **Remove Spline IK**로 제거합니다.

**위치:** BoneCraft의 Pose Mode → Spline IK.

---

### 체인 다이나믹스

**하는 일:** 체인의 본이 부모보다 늦게 움직이고 멈추면 튕기는 물리 유사 보조 동작입니다. 머리카락·꼬리·장식에 씁니다.

**사용:** 체인을 선택하고 **Add Chain Dynamics**를 누릅니다. Adjust Last Operation에서 **Stiffness**, **Damping**, **Mass**, **Gravity Scale**을 정합니다. 패널 아래 Settings에도 있습니다. 생성 후 **Bake**, **Remove**가 나타납니다. 충돌은 단순 구형이므로 오목한 표면과 맞지 않을 수 있습니다.

**위치:** BoneCraft의 Pose Mode → Chain Dynamics.

---

### 리본

**하는 일:** 부드럽게 굽고 비트는 Bendy Bones 리본을 만들어 입술·눈썹·벨트 같은 곡선 부위에 씁니다.

**사용:** 본 체인을 선택하고 **Generate Ribbon**, 이후 Adjust Last Operation에서 **Control Bones**, **Ribbon Width**를 정합니다. **Remove Ribbon**으로 제거합니다.

**위치:** BoneCraft의 Pose Mode → Ribbon.

---

### 비세임 라이브러리

**하는 일:** 셰이프 키에 연결된 비세임(입 모양) 세트를 만들고 관리하며, 텍스트로부터 립싱크 키를 생성합니다. VRChat용 비세임 매핑에는 VRChat Viseme Mapping을, 비세임을 처음부터 만들려면 CATS의 비세임 섹션을 쓰세요.

**주요 컨트롤:**
- **새 세트**와 **삭제** — 비세임 세트를 만들거나 삭제합니다
- 각 세트에는 비세임마다 버튼(스피커 아이콘)이 하나씩 있으며, 클릭하면 미리 봅니다
- 립싱크 — 텍스트를 비세임 키로. 음소당 프레임 수와 스무딩을 설정할 수 있습니다

**위치:** CATS → Avatar Tools → Viseme Library (Armature); Lip Sync (Pose Mode)

---

### 세트 드리븐 키

**하는 일:** Python 식 없이 한 값을 다른 값에 연결합니다. 드라이버(예: 눈썹 본)에 포즈를 잡고, 움직일 값(예: "Brow Raised" 셰이프 키)을 설정하고, 포인트를 기록합니다. BoneCraft가 드라이버 커브를 만듭니다.

**주요 컨트롤:**
- **드라이버 본**과 **드라이버 속성** — 움직이는 쪽
- **대상 본**과 **대상 속성** — 움직여지는 쪽
- **값 설정**과 **포인트 기록** — 커브에 포인트를 기록합니다
- **SDK 생성** — 드라이버를 만듭니다

**위치:** BoneCraft 탭, 포즈 모드 → 세트 드리븐 키

---

### 리그 검증기

**하는 일:** 리그를 규칙 집합에 비추어 확인하고 문제를 보고합니다: 이름, 빠진 본, 깨진 컨스트레인트, 계층, 웨이트, Python이 필요한 드라이버, Mechanisms 규칙. 하이픈이 들어간 본 이름(`DEF-upper_arm.L` 등)은 통과합니다.

**주요 컨트롤:**
- **검증 실행** — 모든 확인을 실행하고 결과를 나열합니다
- **Export Report**(보고서 내보내기) — 결과를 파일로 저장합니다

확인에 실패하면 작업 보드(BoneCraft 탭 → 개요 → 작업 보드)에 검증기 작업이 표시됩니다.

**위치:** BoneCraft 탭 → 리뷰 → 리그 검증기

---

### 리그 노트

**하는 일:** 리그의 본에 붙이는 글 메모입니다: 설정한 내용, 알림, 협업자에게 남기는 메모.

**주요 컨트롤:** **노트 추가**, 그리고 각 메모의 **제거**. 리그 README는 리그의 노트를 읽기 전용 페이지로 보여 줍니다.

**위치:** BoneCraft 탭 → 개요 → 리그 노트, 그리고 리뷰 → 리그 README
