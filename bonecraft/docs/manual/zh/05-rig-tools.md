# 绑定工具

[← 内容](index.md)

本章详细介绍了 BoneCraft 的绑定、动画和权重工具。当您想要更深入地了解某个功能，或者指南未涵盖您的确切情况时，请使用它。

每个条目都说明了该工具的用途、何时使用它、其主要控件以及在哪里可以找到它。每个条目的“在哪里找到它”行命名了使用它所需的模式：例如，姿势模式中的绑定系统控制、权重绘制模式中的权重镜和权重转移以及对象模式中的 Delta Mush。有些部分保持可见，并带有一条消息，说明当其工具无法运行时应选择什么。

在 9.1 中，许多工具会同时运行并将其选项放在“调整上次操作”面板中。单击后立即更改这些选项，然后再运行其他操作。姿势 → BoneCraft 和权重 → BoneCraft 菜单以及 Bforartists 姿势和权重工具架选项卡中的 BoneCraft 按钮面板提供了常用操作的快捷方式。 [开始使用](01-start.md#各功能在哪里) 列出了这些接入点。

---

## 绑定界面工具

这些工具可帮助您管理骨架工作的视觉方面 - 哪些骨骼可见、它们的组织方式以及快速访问。

---

### 骨骼集合

**它的作用：** 将骨骼的骨骼集合显示为行。单击集合的名称以选择其骨骼；眼睛图标显示或隐藏它。

> 骨骼集合是一组已命名的骨骼 - 例如“IK Controls”、“Face Bones”和“Deform Bones”。隐藏集合会隐藏视口中的这些骨骼，因此您可以专注于绑定系统的一个部分。

**关键控制：**
- 每行：强调色、**Toggle Collection Visibility** （眼睛图标）、集合名称（选择其骨骼）、**Solo Collection** 和**Rename Collection Display**，为该行设置自定义显示名称。将鼠标悬停在纯图标按钮上可通过其工具提示来识别它
- **Show All Collections** 和**Hide All Collections** （列表上方的睁眼和闭眼图标）— 一切同时进行
- 部分 — 将多个集合分组到可折叠标题下

**在哪里找到它：** BoneCraft 选项卡 → 评论 → 收藏

---

### 可见性书签

**它的作用：** 保存可见的骨骼集合，以便您可以立即在保存的视图之间切换。

**使用示例：** 您设置了一个仅包含面部骨骼的视图以进行表情工作，并将其保存为“仅面部”。然后，您显示权重绘制的所有内容并将其保存为“完整绑定系统”。现在，一键即可在它们之间切换。

**关键控制：** 每个插槽都是一行。
- 书签的名称 - 单击它以应用保存的视图
- **Save Bookmark** — 保存槽中的当前可见性；将鼠标悬停在其图标上即可查看工具提示
- 颜色样本 — 对书签进行颜色编码
- **Clear Bookmark** 和**Remove Bookmark** （关闭图标）— 清空插槽，或删除已添加的插槽
- **Add Bookmark** — 添加一个插槽

**默认书签：** FK 武器、IK 身体、仅面部、完整绑定系统

**在哪里找到它：** BoneCraft 选项卡 → 评论 → 收藏 → 可见性书签

---

### 快捷键快速面板

**它的作用：** 无论您的光标在哪里，都会以弹出窗口的形式打开 BoneCraft 的绑定系统面板（集合和书签）。

**如何使用：** 在 3D 视口中按**Ctrl+Shift+R**。单击弹出窗口外部将其关闭。

**在哪里可以找到它：** 3D 视口中的**Ctrl+Shift+R** 快捷键（它没有自己的面板）

---

## 动画工具

---

### 姿势库

**它的作用：** 存储带有缩略图的命名姿势，您可以一键将其应用到您的绑定系统。

**关键控制：**
- **Save** — 将当前骨骼位置存储为命名姿势，并带有视口的缩略图
- **Apply** — 将骨骼捕捉到保存的姿势
- **Blend** — 以部分强度应用姿势，与当前位置混合
- **Mirror** — 应用从左到右翻转的姿势
- **Delete** 、**Rename** 和**Category** — 管理列表；**Filter** 显示一类
- **Export** 和**Import** — 保存到 `.bfpose` 文件或从 `.bfpose` 文件加载

混合立即应用。单击后，在“调整上次操作”中设置混合强度。

**在哪里找到它：** BoneCraft 选项卡 → 查看 → 姿势库

---

### Control Picker（控制拾取器）

**它的作用：** 绑定系统控件的可点击地图。单击一个形状以选择其骨骼；选择器突出显示所选内容。

**关键控制：**
- **Generate Picker** — 从您的绑定系统构建布局
- **Edit Layout** — 移动、调整大小和重新标记控件（**Move Picker Control** 、**Resize Picker Control** 和**Relabel Picker Control** 在每个控件的行上显示为图标）并将**Snap** 将它们显示为网格；**Rebuild Layout** 再次构建
- **Mirror Selection** — 选择镜像控件
- **Pop-up Picker** — 在浮动窗口中打开选择器，其中还有**Add Selection Set**

**在哪里可以找到它：** BoneCraft 选项卡 → 查看 → 控制选取器

---

### Control Layer（控制层，IK/FK）

如需图示的实际比较，请遵循 [测试砝码及使用 IK/FK](06-rig-builder.md#c部分测试砝码和使用-ikfk)。

**它的作用：** **Build Control Rig** 制作的绑定系统的肢体的动画器控制：在 IK 和 FK 之间切换肢体，而不使肢体跳跃，并在帧范围内将一个肢体烘焙到另一个肢体中。

**关键控制：**
- **IK** 和**FK** — 切换肢体并将新控件捕捉到肢体所在的位置，这样肘部或膝盖就不会弹出
- **Bake IK** 和**Bake FK** — 将帧范围内的动画转换为 IK 或 FK
- **Pole Follow** 、**Pin** 和**Lock-Free** 以及**Global Rig Scale**，保留受保护的锁

**在哪里找到它：** BoneCraft 选项卡 → 查看 → 控制层（选择由**Build Control Rig** 制作的绑定系统；参见 [绑定系统建造者](06-rig-builder.md) ）

---

### Rigify工具

**它的作用：** 检测 Rigify 控制装置并将 BoneCraft 的集合面板、书签和属性滑块连接到 Rigify 的标准控件。

> Rigify 是 Bforartists 的内置系统，用于生成动画就绪绑定系统。如果您使用 Rigify 构建绑定系统，则会将 BoneCraft 的 UI 连接到 Rigify 的 IK/FK 控件。

**关键控制：**
- **Auto-Enhance** — 为选定的 Rigify 绑定系统设置 BoneCraft 的面板
- **Re-run Enhancement** — 从头开始重建它们
- **Enable Rigify** 在 Quick Rig 中；扩展**Generate Control Rig (active metarig)** 的故障排除范围（请参阅 [绑定系统建造者](06-rig-builder.md) ）
- Rigify 属性 — 绑定系统的 IK/FK 、拉伸、父级空间和头/颈跟随滑块

**在哪里找到它：** BoneCraft 选项卡 → 设置索具 → Rigify 工具（以及 Rigify 属性部分）

---

### 重定向

**它的作用：** 将动画从一个骨架移动到另一个骨架 - 例如将动作捕捉剪辑移动到您的头像上。骨骼按名称和方向进行匹配，因此四肢保持其方向；锁骨配合宽松，因此肩膀不会过度旋转。

**关键控制：**
- **Import Clip** 和**Browse Library** — 加载剪辑，或设置库文件夹；单击剪辑的名称以将其选中
- **Auto-Match Bones** （剪辑行上的复选标记）- 源骨骼和目标骨骼对（面板的骨骼映射列表显示这些对）
- **Preview** 和**Stop Preview** — 尝试结果
- **Apply** — 将剪辑烘焙到您的绑定系统上

**在哪里可以找到它：** BoneCraft 选项卡 → 设置绑定 → 重新定位

---

### 校正形态键

**它的作用：** 当骨骼到达某个角度时，形状键会打开，以修复极端姿势下的挤压或塌陷。

**使用示例：** 当完全弯曲时，角色的肘部会塌陷。您雕刻矫正后的肘部并将其链接到臂骨，以便在肘部弯曲时自动应用。

**关键控制：**
- 新校正 — 选择 **Shape Key** 、**Driver Bone** 、旋转轴、形状完全打开的角度以及它如何逐渐淡入，然后选择**Create Corrective**
- 校正列表：单击校正的形状键名称将其选中；列表下的 **Edit** 和**Delete** 对所选的一项进行操作

编辑从校正的当前值开始。单击后，在“调整上次操作”中更改其角度和衰减。

**在哪里找到它：** BoneCraft 选项卡 → 皮肤 → 矫正（网格需要基础形状键）

---

### 曲线图工具

**它的作用：** 用于关键帧和曲线的动画细化工具。

- **Interactive Breakdown** （Breakdowner；3D 视口中的快捷键**Ctrl+Shift+B**） - 左右拖动以混合最近关键帧之间的当前姿势
- **Apply Delta** （Delta Mover；3D 视口中的快捷键**Ctrl+Shift+D**） — 将选定的骨骼微移屏幕空间或世界空间中的精确偏移量
- **Capture** 和**Swap** （缓冲曲线）- 保留曲线的副本并在它和您的编辑之间交换
- **Smart Bake** — 将约束驱动的动画烘焙到关键点，删除冗余关键点（**Tol** 设置多少）
- **Euler Filter** — 修复了万向节锁导致的旋转翻转
- 切线控制柄 — 设置选定关键点上的控制柄类型：**Auto** 、**Vector** 、**Aligned** 、**Free** 或**Auto Clamped**

**在哪里可以找到它：** BoneCraft 选项卡 → 查看 → 图形工具

---

## 权重工具

这些工具控制骨骼移动时网格的变形方式。权重告诉网格的每个部分要遵循哪些骨骼以及遵循多少。

---

### 骨骼权重自动重算

**它的作用：** 从现有绑定系统重新计算网格的权重，而不更改网格。在密集的网格上，它通过较轻的代理网格工作，因此它不会默默地失败。

**关键控制：** 选择目标网格和骨架，然后选择“身体”或“服装”模式。 Body 根据现有绑定系统计算权重；服装从正确加权的源网格中传输它们。设置方法、混合和平滑、每个顶点的最大骨骼影响数、最小权重以及是否保留备份，然后运行**Automatic Bone Weight Recalculation**。这些设置位于按钮上方。 CATS 快捷方式**Smart Automatic Weights** 打开目标网格、骨架和模式的对话框，以及服装模式下的源网格。

**在哪里找到它：** BoneCraft 选项卡 → 皮肤 → 权重工具

---

### 权重镜像

**它的作用：** 将权重从头像的一侧复制到另一侧。对于对称字符至关重要。

**关键控制：**
- **Mirror All Weights** — 将每个骨骼组镜像到其相对侧
- **Mirror Active Weight** — 仅镜像活动骨骼组
- 对称轴和镜像方向（双向，从左到右，或从右到左）
- **Topology Mirror** — 通过网格拓扑而不是位置对顶点进行配对
- **Search Distance** — 两个顶点相距多远并且仍然算作一对（对于不完全对称的网格提高它）
- **Select Unmatched** — 选择没有伙伴的顶点；**Normalize Weights** 之后使权重总和为 1.0

先单击镜像按钮，然后在“调整上次操作”中设置轴、方向、拓扑模式和搜索距离。 **Mirror Active Weight** 也在权重 → BoneCraft 和权重工具架选项卡中。

**在哪里找到它：** BoneCraft 选项卡，在权重绘制模式 → 权重镜

---

### 权重传递

**它的作用：** 将权重从源网格复制到活动网格。在将衣服固定到身体上或将权重从高分辨率网格移动到较低分辨率网格时使用。

**关键控制：**
- 在传输之前选择源网格
- 点击后，在调整上一次操作中设置传输方式和骨骼过滤器
- 调整最后操作中的 **Normalize** — 保持权重总和为 1.0
- **Transfer Weights** — 运行它；结果显示平均距离和最大距离，**Select Problem Vertices** 选择不匹配的顶点

**在哪里找到它：** BoneCraft 选项卡，在权重绘制模式 → 权重转移（也在蒙皮 → 权重工具下）

---

### 权重表

**它的作用：** 显示每个骨骼的选定顶点的确切权重，并允许您设置精确值。

**使用方法：** 在权重绘制模式下选择一个顶点；表中列出了它的骨骼和权重。单击骨骼所在行上的手形图标，然后在调整上次操作中设置**Weight**。添加影响使用您选择的骨骼；也在“调整上次操作”中设置其新权重。选择多个顶点后，**Normalize All Vertices** 将它们全部标准化。

**哪里可以找到它：** BoneCraft 选项卡，在“权重绘制”模式下 → 权重表

---

### 洪水填充

**它的作用：** 一键设置选定顶点上活动组的权重：**Flood to 0.0** 、**Flood to 1.0** 或**Flood to Custom**。 Flood 为 Custom 后，在调整上次操作中设置**Value** 和**Normalize**。 “权重”菜单和工具架将固定值按钮“Flood to Zero”和“Flood to One”称为“Flood to Zero”和“Flood to One”。

**在哪里找到它：** BoneCraft 选项卡 → 皮肤 → 权重工具；还有配重 → BoneCraft 和工具架 → 配重 → BoneCraft

---

### 变形与控制

**它的作用：** 将绑定系统的骨骼分类为变形骨骼（它们移动网格）和控制骨骼（动画师移动它们），标记变形骨骼，将它们重命名为变形命名，并导出仅变形骨骼。

**在哪里可以找到它：** BoneCraft 选项卡，姿势模式 → 变形与控制

---

### 增量柔化

**它的作用：** 平滑变形，减少接头处的挤压。网格在静止时保持其形状，但在运动时变形更干净。

**如何使用：** 单击**Add Delta Mush** 添加修改器并将其绑定到其余形状。随后，立即在“调整上次操作”中设置**Iterations** 、**Smooth Strength** 、**Pin Borders** 和**Only Smooth Deform**。修改器存在后，面板将显示**Rebind** 和**Remove**，其中“设置”折叠包含修改器的迭代、平滑强度和边框固定控件。

**在哪里可以找到它：** BoneCraft 选项卡，在对象模式下选择网格 → Delta Mush

---

### 近距离包裹

**它的作用：** 使一个网格跟随另一个网格的表面，就像第二层皮肤一样。适用于包裹身体的衣服。

**使用方法：**选择目标网格，选择不同的**Driver Mesh**，然后单击**Bind Proximity Wrap**。绑定时，将驱动器电枢保持在静止姿势。按钮下方的选项折叠列出了**Falloff Type** 和**Max Distance**；在 9.1.2 中，这些值与设置一起存储，但不会更改其表面变形绑定。绑定后，面板显示**Rebind** 和**Unbind**。取消绑定会禁用视口中的修改器并进行渲染；它不会删除它。

**在哪里找到它：** BoneCraft 选项卡，在对象模式下选择网格 → 邻近包裹

---

## 绑定控制

这些工具出现在姿势模式下的 BoneCraft 选项卡中。

---

### 空间切换

**它的作用：** 更改动画期间骨骼所遵循的空间。握住道具的手只需轻轻一按即可从跟随身体切换到在世界中保持静止。

**关键控制：**
- **Add Space** 和**Remove Space** （管理空间下的 X 图标）- 骨骼可以遵循的空间（世界、原点或其他骨骼）
- 每个空间一个按钮，以其命名；当前空间被标记为●。单击另一个空间的按钮可将骨骼切换到该空间

**在哪里找到它：** BoneCraft 选项卡，姿势模式 → 空间切换

---

### 样条 IK

**它的作用：** 使骨骼链遵循曲线。用于需要平滑、扫掠运动的尾巴、触手、绳索、长发和刺。

**如何使用：** 激活起始骨骼，然后单击**Generate Spline IK**。在调整上次操作中设置**Chain Length** 、**Curve Resolution** 、**Stretch** 和**Volume Preservation**。**Remove Spline IK** 删除该设置。

**在哪里可以找到它：** BoneCraft 选项卡，姿势模式 → 样条线 IK

---

### 链式动力学

**它的作用：** 骨骼链上类似物理的辅助运动：当父级移动时，骨骼会滞后，当它停止时会弹回来。用于发束、发尾和配饰。

**使用方法：**选择骨链，点击**Add Chain Dynamics**。在调整上次操作中设置**Stiffness** 、**Damping** 、**Mass** 和**Gravity Scale**。该面板还在操作下方的“设置”折叠中列出了参数。一旦存在动态，就会显示**Bake** 和**Remove**。碰撞使用简化的球体形状，因此凹面可能无法正确碰撞。

**在哪里找到它：** BoneCraft 选项卡，姿势模式 → 链动力学

---

### 丝带

**它的作用：** 为嘴唇、眉毛、腰带和其他柔软的弯曲区域构建一条弯曲骨骼丝带（可平滑弯曲和扭曲的骨骼）。

**使用方法：** 选择骨链，点击**Generate Ribbon**，然后在调整上次操作中设置**Control Bones** 和**Ribbon Width**。**Remove Ribbon** 删除设置。

**在哪里找到它：** BoneCraft 选项卡，姿势模式 → 功能区

---

### 口型库

**它的作用：** 创建和管理链接到形状键的视位（嘴形）集，并从文本生成唇形同步键。对于 VRChat 视位映射，请使用 VRChat 视位映射；要从头开始生成视位，请使用 CATS 视位 部分。

**关键控制：**
- **New Set** 和**Delete** — 创建或删除视位集
- 在每组中，每个视位有一个按钮（带有扬声器图标）进行预览
- 唇形同步 — 文本到发音嘴型键，每个音素都有帧并进行平滑

**在哪里找到它：** BoneCraft 选项卡，选择了骨架 → Viseme 库

---

### 设置驱动键

**它的作用：** 将一个值链接到另一个值，无需 Python 表达式。摆出驱动器的姿势（例如眉骨），设置驱动值（例如“眉毛抬起”形状关键点），并记录该点； BoneCraft 构建驱动器曲线。

**关键控制：**
- **Driver Bone** 和**Driver Attribute** — 驱动因素
- **Target Bone** 和**Target Attribute** — 驱动什么
- **Set Value** 和**Record Point** — 记录曲线上的点
- **Create SDK** — 构建驱动程序

**在哪里找到它：** BoneCraft 选项卡，姿势模式 → 设置驱动关键点

---

### 装备验证器

**它的作用：** 根据一组规则检查您的绑定系统并报告问题 - 命名、缺失骨骼、破坏的约束、层次结构、权重、需要 Python 的驱动程序以及机制规则。带连字符的骨骼名称（例如 `DEF-upper_arm.L` ）通过。

**关键控制：**
- **Run Validation** — 运行每项检查并列出结果
- **Export Report** — 将结果保存到文件中

检查失败时，任务板（BoneCraft 选项卡 → 概述 → 任务板）会显示验证器任务。

**在哪里找到它：** BoneCraft 选项卡 → 审查 → 绑定系统验证器
