# 绑定工具

[← 目录](index.md)

本章详细介绍 BoneCraft 的绑定、动画和权重工具。当你想更深入地了解某个功能，或者指南没有涵盖你的具体情况时，请使用本章。

每个条目都说明工具的作用、使用场合、主要控件和位置。有些工具只在特定模式下出现，每个条目的"位置"一行会注明：例如，绑定控制在姿态模式下，权重镜像和权重传递在权重绘制模式下，增量柔化在物体模式下。

---

## 绑定界面工具

这些工具帮助你管理使用骨架时的视觉方面：哪些骨骼可见、如何组织，以及快速访问。

---

### 骨骼集合

**作用：** 把骨架的骨骼集合显示为一行行。点击集合名称会选中其中的骨骼；眼睛图标用于显示或隐藏该集合。

> 骨骼集合是一组有名称的骨骼，例如"IK Controls"、"Face Bones"和"Deform Bones"。隐藏一个集合会在视口中隐藏这些骨骼，让你专注于绑定的某一部分。

**主要控件：**
- 每一行：强调色、**Toggle Collection Visibility**（切换集合可见性，眼睛图标）、集合名称（选中其骨骼）、**Solo Collection**（单独显示集合，S 图标）和 **Rename Collection Display**（重命名集合显示，齿轮图标），后者为这一行设置自定义显示名称
- **Show All Collections**（显示所有集合）和 **Hide All Collections**（隐藏所有集合）（列表上方睁眼和闭眼的图标）— 一次切换全部
- 分组 — 把几个集合归到一个可折叠的标题下

**位置：** BoneCraft 选项卡 → 审查 → 集合

---

### 可见性书签

**作用：** 保存哪些骨骼集合是可见的，以便在已保存的视图之间一键切换。

**使用示例：** 你为表情工作设置了一个只显示面部骨骼的视图，并保存为"Face Only"。然后为权重绘制显示全部内容，并保存为"Full Rig"。现在一次点击就能在两者之间切换。

**主要控件：** 每个槽位是一行。
- 书签名称 — 点击即可应用已保存的视图
- **Save Bookmark**（保存书签，磁盘图标）— 把当前的可见性保存到该槽位
- 颜色块 — 为书签设置颜色标记
- **Clear Bookmark**（清除书签）和 **Remove Bookmark**（移除书签；关闭图标）— 清空槽位，或移除添加的槽位
- **添加书签** — 添加一个槽位

**默认书签：** FK Arms、IK Body、Face Only、Full Rig

**位置：** BoneCraft 选项卡 → 审查 → 集合 → 可见性书签

---

### 快捷键快速面板

**作用：** 在光标所在位置以弹出窗口打开 BoneCraft 的绑定面板（集合和书签）。

**使用方法：** 在 3D 视口中按 **Ctrl+Shift+R**。点击弹出窗口外部即可关闭。

**位置：** 3D 视口中的快捷键 **Ctrl+Shift+R**（它没有自己的面板）

---

## 动画工具

---

### 姿势库

**作用：** 保存带有名称和缩略图的姿势，可以一键应用到绑定上。

**主要控件：**
- **保存** — 把当前骨骼位置保存为一个有名称的姿势，并附带视口的缩略图
- **应用** — 让骨骼对齐到已保存的姿势
- **混合** — 以部分强度应用姿势，与当前位置混合
- **镜像** — 左右翻转后应用姿势
- **删除**、**重命名** 和 **类别** — 管理列表；**过滤器** 只显示一个类别
- **导出** 和 **导入** — 保存到 `.bfpose` 文件，或从中加载

**位置：** BoneCraft 选项卡 → 审查 → 姿势库

---

### Control Picker（控制拾取器）

**作用：** 一张可点击的绑定控制图。点击某个形状即可选中它的骨骼；拾取器会高亮显示选中的内容。

**主要控件：**
- **Generate Picker**（生成拾取器）— 根据你的绑定创建布局
- **Edit Layout**（编辑布局）— 移动、缩放控件和更改标签（**Move Picker Control**（移动拾取器控件）、**Resize Picker Control**（调整拾取器控件大小）和 **Relabel Picker Control**（重新标记拾取器控件）以图标形式显示在每个控件的行上），用 **Snap**（吸附）对齐到网格；**重建布局** 重新创建布局
- **镜像选择** — 选中镜像一侧的控件
- **弹出式拾取器** — 在浮动窗口中打开拾取器，其中还有 **Add Selection Set**（添加选择集）

**位置：** BoneCraft 选项卡 → 审查 → Control Picker

---

### Control Layer（控制层，IK/FK）

**作用：** 用于 **构建控制绑定** 所建绑定的四肢的动画师控制：在 IK 和 FK 之间切换四肢而不会跳动，并在一个帧范围内把一种烘焙为另一种。

**主要控件：**
- **IK** 和 **FK** — 切换四肢，并把新的控制器对齐到四肢当前的位置，因此肘部或膝部不会跳动
- **Bake IK**（烘焙为 IK）和 **Bake FK**（烘焙为 FK）— 在一个帧范围内把动画转换为 IK 或 FK
- **Pole Follow**（极向跟随）、**Pin**（固定）和 **Lock-Free**（解除锁定），以及保留受保护锁定的 **Global Rig Scale**（全局绑定缩放）

**位置：** BoneCraft 选项卡 → 审查 → Control Layer（选中由 **构建控制绑定** 创建的绑定时；参见 [绑定构建器](06-rig-builder.md)）

---

### Rigify工具

**作用：** 检测 Rigify 控制绑定，并把 BoneCraft 的集合面板、书签和属性滑块连接到 Rigify 的标准控制器。

> Rigify 是 Bforartists 内置的系统，用于生成可直接用于动画的绑定。如果你用 Rigify 创建了绑定，这会把 BoneCraft 的界面连接到 Rigify 的 IK/FK 控制器。

**主要控件：**
- **自动增强** — 为选中的 Rigify 绑定设置 BoneCraft 的面板
- **重新运行增强** — 从头重建它们
- **启用 Rigify** 和 **生成控制骨架（活动元骨架）** 位于 Quick Rig 中（参见 [绑定构建器](06-rig-builder.md)）
- Rigify属性 — 绑定的 IK/FK、拉伸、父空间以及头颈跟随滑块

**位置：** BoneCraft 选项卡 → 装备设置 → Rigify工具（以及 Rigify属性 部分）

---

### 重定向

**作用：** 把动画从一副骨架移到另一副上，例如把动作捕捉片段用到你的虚拟形象上。骨骼按名称和方向匹配，因此四肢保持原有的朝向；锁骨的匹配较宽松，因此肩膀不会过度旋转。

**主要控件：**
- **导入片段** 和 **浏览库** — 加载片段，或设置片段库文件夹；点击片段名称即可选中它
- **Auto-Match Bones**（自动匹配骨骼，片段行上的勾号）— 将源骨骼与目标骨骼配对（面板中的骨骼映射列表会显示这些配对）
- **预览** 和 **停止预览** — 试看结果
- **应用** — 把片段烘焙到你的绑定上

**位置：** BoneCraft 选项卡 → 装备设置 → 重定向

---

### 校正形态键

**作用：** 在骨骼达到某个角度时启用的形态键，用于修复极端姿势下的挤压或塌陷。

**使用示例：** 角色的肘部完全弯曲时会塌陷。你雕刻一个修正过的肘部，并把它链接到手臂骨骼上，这样肘部弯曲时它会自动生效。

**主要控件：**
- 新建矫正 — 选择 **形态键**、**驱动器骨骼**、旋转轴、形状完全生效的角度，以及它渐入的平缓程度，然后点击 **创建校正**
- 校正列表：点击校正的形态键名称即可选中它；列表下方的 **编辑** 和 **删除** 作用于选中的校正

**位置：** BoneCraft 选项卡 → 蒙皮 → 修正（网格需要一个基础形态键）

---

### 曲线图工具

**作用：** 用于完善关键帧和曲线的动画工具。

- **交互式分解**（分解器；3D 视口中的快捷键 **Ctrl+Shift+B**）— 左右拖动，在相邻关键帧之间混合当前姿势
- **应用增量**（增量移动器；3D 视口中的快捷键 **Ctrl+Shift+D**）— 在屏幕空间或世界空间中把选中的骨骼精确偏移一定量
- **捕获** 和 **交换**（缓存曲线）— 保留一份曲线副本，并在它和你的编辑之间切换
- **智能烘焙** — 把由约束驱动的动画烘焙为关键帧，并去掉多余的关键帧（**容差** 设置程度）
- **欧拉过滤器** — 修复万向节锁导致的旋转翻转
- 切线手柄 — 为选中的关键帧设置手柄类型：**Auto**（自动）、**Vector**（矢量）、**Aligned**（对齐）、**Free**（自由）或 **Auto Clamped**（自动钳制）

**位置：** BoneCraft 选项卡 → 审查 → 曲线图工具

---

## 权重工具

这些工具控制骨骼移动时网格如何变形。权重告诉网格的每个部分要跟随哪些骨骼，以及跟随多少。

---

### 骨骼权重自动重算

**作用：** 在不改变网格的情况下，根据现有的绑定重新计算网格的权重。对于高密度网格，它会通过一个较轻的代理网格来计算，因此不会悄无声息地失败。

**主要控件：** 目标网格和骨架、方法、混合与平滑、每个顶点受骨骼影响的最大数量、最小权重，以及旧权重的备份。运行 **Automatic Bone Weight Recalculation**（骨骼权重自动重算）。CATS 选项卡中有一个快捷方式：**Smart Automatic Weights**（智能自动权重）。

**位置：** BoneCraft 选项卡 → 蒙皮 → 权重工具

---

### 权重镜像

**作用：** 把虚拟形象一侧的权重复制到另一侧。对于对称的角色必不可少。

**主要控件：**
- **镜像所有权重** — 把每个骨骼组镜像到对侧
- **镜像活动权重** — 只镜像活动的骨骼组
- 对称轴和镜像方向（双向、从左到右或从右到左）
- **拓扑镜像** — 按网格拓扑而不是位置配对顶点
- **搜索距离** — 两个顶点相距多远仍可视为一对（对于不完全对称的网格，请调大）
- **选择不匹配项** — 选中没有配对的顶点；**归一化权重** 随后使权重之和为 1.0

**位置：** BoneCraft 选项卡，权重绘制模式下 → 权重镜像

---

### 权重传递

**作用：** 把权重从源网格复制到活动网格。用于把服装附加到身体上，或把权重从高分辨率网格移到低分辨率网格。

**主要控件：**
- 源网格、传递方法和骨骼过滤
- **转移后归一化** — 保持权重之和为 1.0
- **传输权重** — 运行传递；结果会显示平均距离和最大距离，**选择问题顶点** 会选中匹配不佳的顶点

**位置：** BoneCraft 选项卡，权重绘制模式下 → 权重传递（也在 蒙皮 → 权重工具 中）

---

### 权重表

**作用：** 显示选中顶点对每根骨骼的精确权重，以便你输入精确的数值。

**使用方法：** 在权重绘制模式下选中一个顶点；表中会列出它的骨骼和权重。选中多个顶点时，**归一化所有顶点** 会把它们全部归一化。

**位置：** BoneCraft 选项卡，权重绘制模式下 → 权重表

---

### 洪水填充

**作用：** 一键为选中的顶点设置活动组的权重：**填充到 0.0**、**填充到 1.0**，或用 **自定义值** 进行 **填充**（配合 **自定义归一化**）。

**位置：** BoneCraft 选项卡 → 蒙皮 → 权重工具

---

### 变形与控制

**作用：** 把绑定的骨骼分为变形骨骼（它们移动网格）和控制骨骼（由动画师移动），标记变形骨骼，把它们重命名为变形命名，并导出只含变形骨骼的骨架。

**位置：** BoneCraft 选项卡，姿态模式下 → 变形与控制

---

### 增量柔化

**作用：** 一种减少关节处挤压的平滑变形。网格在静止时保持原有形状，运动时变形更干净。

**主要控件：** 迭代次数、平滑强度、固定边界、仅平滑变形，以及是否在骨架之前运行。添加按钮会添加修改器，并把它绑定到静止形状。

**位置：** BoneCraft → Skin → Delta Mush (Object Mode; Mesh)

---

### 近距离包裹

**作用：** 让一个网格像第二层皮肤一样跟随另一个网格的表面。适用于贴身的服装。

**主要控件：** 要跟随的驱动网格、衰减类型和最大距离；绑定按钮会附着网格。

**位置：** BoneCraft → Skin → Proximity Wrap (Object Mode; Mesh)

---

## 绑定控制

这些工具出现在姿态模式下的 BoneCraft 选项卡中。

---

### 空间切换

**作用：** 改变骨骼在动画中跟随的空间。拿着道具的手可以一键从跟随身体切换为在世界中保持静止。

**主要控件：**
- **添加空间** 和 **Remove Space**（移除空间，管理空间下的 X 图标）— 骨骼可以跟随的空间（世界、原点或另一根骨骼）
- 每个空间有一个以其名称命名的按钮；当前空间标有 ●。点击另一个空间的按钮即可把骨骼切换过去

**位置：** BoneCraft 选项卡，姿态模式下 → 空间切换

---

### 样条 IK

**作用：** 让一条骨骼链沿着曲线。用于需要平滑、大幅摆动的尾巴、触手、绳索、长发和脊柱。

**主要控件：** **链长**、**曲线分辨率**、**拉伸**、**扭曲模式**、**保持体积**；**生成样条 IK** 和 **删除样条IK**。

**位置：** BoneCraft 选项卡，姿态模式下 → 样条 IK

---

### 链式动力学

**作用：** 在骨骼链上产生类似物理的次级运动：父级移动时骨骼会滞后，停下时会回弹。用于发束、尾巴和饰品。

**主要控件：** 刚度、阻尼、质量和重力；为选中的链添加动力学。碰撞使用简化的球形，因此凹面可能无法正确碰撞。

**位置：** BoneCraft 选项卡，姿态模式下 → 链式动力学

---

### 丝带

**作用：** 用弯曲骨骼（可以平滑弯曲和扭转的骨骼）创建一条丝带，用于嘴唇、眉毛、腰带和其他柔软的弯曲部位。

**主要控件：** **控制骨骼** 和 **丝带宽度**；**生成绸带** 和 **删除丝带**。

**位置：** BoneCraft 选项卡，姿态模式下 → 丝带

---

### 口型库

**作用：** 创建并管理链接到形态键的口型（嘴型）集合，并根据文本生成口型同步关键帧。VRChat 的口型映射请使用 VRChat Viseme Mapping；要从零开始生成口型，请使用 CATS 的口型部分。

**主要控件：**
- **新建集合** 和 **删除** — 创建或删除口型集
- 每个集合中，每个口型有一个按钮（扬声器图标），点击即可预览
- 口型同步 — 从文本生成口型关键帧，可设置每个音素的帧数和平滑

**位置：** CATS → Avatar Tools → Viseme Library (Armature); Lip Sync (Pose Mode)

---

### 设置驱动键

**作用：** 不用 Python 表达式就把一个值链接到另一个值。给驱动者摆好姿势（例如眉毛骨骼），设置被驱动的值（例如"Brow Raised"形态键），然后记录这个点；BoneCraft 会创建驱动曲线。

**主要控件：**
- **驱动器骨骼** 和 **驱动器属性** — 由什么驱动
- **目标骨骼** 和 **目标属性** — 驱动什么
- **设置值** 和 **记录点** — 在曲线上记录一个点
- **创建SDK** — 创建驱动器

**位置：** BoneCraft 选项卡，姿态模式下 → 设置驱动键

---

### 装备验证器

**作用：** 按照一组规则检查你的绑定并报告问题：命名、缺失的骨骼、损坏的约束、层级、权重、需要 Python 的驱动器，以及 Mechanisms 的规则。带连字符的骨骼名称（例如 `DEF-upper_arm.L`）可以通过。

**主要控件：**
- **运行验证** — 运行每项检查并列出结果
- **Export Report**（导出报告）— 把结果保存到文件

某项检查失败时，任务板（BoneCraft 选项卡 → 概览 → 任务板）会显示一项验证器任务。

**位置：** BoneCraft 选项卡 → 审查 → 装备验证器

---

### 装备笔记

**作用：** 附在绑定骨骼上的文字笔记：你设置了什么、备忘，以及给协作者的说明。

**主要控件：** **添加注释**，以及每条笔记上的 **移除**。装备说明会以只读页面显示绑定的笔记。

**位置：** BoneCraft 选项卡 → 概览 → 装备笔记，以及 审查 → 装备说明
