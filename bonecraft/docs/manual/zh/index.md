# BoneCraft 手册

BoneCraft 9.2.3。BoneCraft 是用于 Bforartists 的绑定与虚拟形象工具包。

本手册由英文版机器翻译而成。

选项卡用于选择功能组。Setup Rigging、Skin、Review、Avatar Tools 和 Facial 是选项卡内可展开的分区，不是独立选项卡。下列路径保留英文界面标签；翻译名称取决于 Language 设置。

## 章节

1. [入门](01-start.md)： BoneCraft 是什么、如何安装、各功能在哪里。
2. [指南 1–7](02-guides-a.md)： 第一个虚拟形象、VRoid、MMD、骨骼名称、人形映射、头发、服装。
3. [指南 8–13](03-guides-b.md)： 口型同步、性能、姿势、合并骨架、上传问题、CATS。
4. [CATS 流程](04-cats-pipeline.md)： 六个阶段、记录，以及顺序为何重要。
5. [绑定工具](05-rig-tools.md)： 绑定界面、动画、权重和绑定控制工具。
6. [绑定构建器](06-rig-builder.md)： 创建新骨架、Basic Humanoid 资源和骨骼合并。
7. [Mechanisms（机械装置）](07-mechanisms.md)： 用于道具和机械的关节与连接：铰链、滑动、齿轮、序列。
8. [VRChat 工具](08-vrchat.md)： VRChat、VRM 和 MMD 工具，I/O 中心和任务板。
9. [CATS 工具](09-cats.md)： 逐一介绍每个 CATS 工具。
10. [快速修复与术语表](10-reference.md)： 常见问题以及本手册使用的术语。
11. [新功能](11-whats-new.md)： 按版本列出的更改。
