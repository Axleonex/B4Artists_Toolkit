## 创建新的绑定

绑定构建器为角色创建新的绑定。它位于左侧工具架（按 **T**）上专属的 **Rig Builder** 选项卡中，也位于 **属性** 编辑器的 **场景** 选项卡中。在较窄的工具架中，它会切换为使用短标签的紧凑布局。 仅在 Preferences → Tabs → Scene Properties → Show 开启时显示场景面板；关闭视口选项卡不会隐藏此副本。

---

### 自动绑定向导

**作用：** 一步一步地引导你在网格上放置标记，并据此创建带权重的绑定。这是从零开始绑定角色的主要方式。

[指南 1](02-guides-a.md#指南-1把你的第一个虚拟形象带进-vrchat) 会一步一步地介绍它。

**步骤：** 选择网格 → 绑定类型 → 身体标记 → 手指标记 → 面部标记 → 检查 → 生成

**主要控件：**
- **开始自动骨架**，以及每一步上下方的 **返回**、**取消** 和 **下一步**
- 网格列表（点击你的网格），然后是绑定类型：**Body + Face**（身体和面部）、**Body Only**（仅身体）或 **Face Only**（仅面部，用于已有骨架）
- **Detect Markers**（检测标记，在 Smart Detection 中）— 沿网格中的四肢追踪，并放置每个身体标记，每个都带有置信度；**Accept High**（接受高置信度）保留有把握的标记，**Reset Low**（重置低置信度）清除可疑的标记
- **从网格猜测标记** 和 **猜测精度**（身体）、**猜测手指标记**（手指标记根据手的形状放置）和 **猜测面部标记**
- 手指细节 — 要创建的手指数量，从"0 — No Fingers"到"5 — Full Human Hand"
- 每个标记的行：**Place Marker**（放置标记，箭头图标）、**Confirm Marker**（确认标记，勾号）和 **Reset Marker**（重置标记，环形箭头）；左右标记上还有 **Toggle Symmetry**（切换对称，第一个图标）
- **Mirror L to R**（左镜像到右）和 **Mirror R to L**（右镜像到左）— 沿中线复制已确认的标记
- **确认全部已放置** — 确认该步骤中所有已放置的标记
- **生成绑定** — 根据已确认的标记创建绑定；然后在最后一步使用 **构建控制绑定**（见下文）和 **关闭向导**

**生成绑定会创建：**
- 一个身体绑定，带有你选择的脊柱和颈部段数，以及 IK/FK、仅 IK 或仅 FK 的手臂和腿（**运动学** 选项）
- 你选择数量的手指骨骼
- 对于 **Body + Face**：一个面部绑定；开启 **生成控制形状** 时还带有控制器形状
- 按所选质量设置的蒙皮权重。高密度网格会通过一个较轻的代理网格设置权重，因此一个 678,000 顶点的角色大约一分钟就能完成，而不会悄无声息地失败。

**构建控制绑定：** 检查步骤还会显示 **Twist Bones**（扭转骨骼）、**Skirt Bones**（裙子骨骼）、**Face Controls**（面部控制）和 **Joint Correctives**（关节校正），但生成绑定不会应用它们。它们属于引擎控制绑定（扭转骨骼、跟随双腿的裙子骨骼、视线和眨眼控制，以及关节校正形态键）。生成绑定之后，最后一步会提供 **构建控制绑定**，它会按你选择的选项在生成的骨架上创建该绑定。请在点击 **关闭向导** 之前点击它，因为关闭会重置向导的选项。Control Layer 面板（绑定工具）只会出现在这样创建的绑定上。

**位置：** Rig Builder → 自动绑定向导

### Quick Rig（快速绑定）

**作用：** 一键添加一个现成的骨架：BoneCraft 的 Basic Humanoid（19 根骨骼，不需要 Rigify）或 Rigify 的某个元绑定。比向导更快，但与角色的贴合度较低。

**主要控件：**
- Basic Humanoid 按钮和 Rigify 元绑定（如果 Rigify 处于关闭状态，请先点击 **启用 Rigify**）
- 用于下一次点击的选项：**将骨架适配到活动网格**、自动权重、**添加IK/FK控制器** 和 **初始姿势**
- **T形姿势** 和 **A形姿势** — 切换所选绑定的静止姿势
- **检查活动骨架控件** 和 **诊断快速绑定（输出到控制台）** — 检查创建了什么
- **生成控制骨架（活动元骨架）** — 当 Rigify 元绑定处于活动状态时，生成它的 Rigify 控制绑定

**BoneCraft Rigs 资源库：** Basic Humanoid 也是一个资源。把它从资源架拖到你的角色上。选中放下的绑定后，Quick Rig 会显示"Dropped rig: fit it to a mesh"（已放下的绑定：请将它适配到网格）：选择 **Mesh**（网格），选择是否适配并设置权重，然后点击 **Fit Dropped Rig**（适配放下的绑定）。

**位置：** Rig Builder → Quick Rig

### 人体模型

**作用：** 创建一个带绑定的简单人形，在你还没有模型时作为替身。它仅用于预览：最终使用前，请换成你自己的网格。

**主要控件：**
- **快速人体模型** — 用默认比例创建一个
- **添加人体模型** — 用下面的设置创建一个
- **重新生成** 和 **移除** — 用新的设置重建，或连同其绑定一起删除
- **模式**、**体型** 和 **半径缩放**，高级设置中还有更多选项

**位置：** Rig Builder → 人体模型

## 骨骼合并

**作用：** 把两个骨架合并为一个，例如身体绑定和服装或头发绑定，并保留所有权重。

[指南 11](03-guides-b.md#指南-11将两个骨架合并为一个) 会一步一步地介绍它。

**三个阶段：**
1. 范围 — 选择两个骨架，查看它们的区别
2. 重命名 — 解决名称冲突，标记新骨骼
3. 合并 — 先预览，再合并

**主要控件：**
- **基础** — 保留下来的骨架；另一个骨架会合并进来，然后被隐藏
- **Analyze**（分析）— 比较两副骨架；**Acknowledge Scope — Proceed to Rename**（确认范围 — 进入重命名）打开阶段 2
- **Normalize Both Armatures**（规范化两个骨架）— 把两个绑定的标准骨骼重命名为同一种命名标准（Mixamo Prefixed、Mixamo Stripped 或自定义）
- **Auto-Propose Renames**（自动建议重命名）— 为要合并的绑定自己的骨骼建议名称
- **Apply Rename**（应用重命名）— 重命名一个条目（一次撤销步骤）；**Apply Batch Pattern**（应用批量模式）用一个模式重命名许多骨骼（可使用 `{bone}`、`{side}` 和 `{index}`）
- **Mark as Unique**（标记为唯一）— 把骨骼作为新骨骼保留，而不是合并它
- **Verify Rename — Proceed to Merge**（验证重命名 — 进入合并）— 打开阶段 3
- **Run Merge Preview**（运行合并预览）— 报告合并会做什么，而不做任何更改
- **合并骨架** — 先备份两个骨架，然后合并它们

**位置：** BoneCraft → Setup Rigging → Bone Merge
