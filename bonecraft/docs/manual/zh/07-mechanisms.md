# Mechanisms（机械装置）

[← 目录](index.md)

## Mechanisms 能做什么

Mechanisms 把硬表面部件变成可以运动的机械绑定：铰链、滑动、伸缩、活塞、齿轮、跟随，以及由一个滑块播放的整段变形。它创建的是普通的 Blender 骨骼和约束，因此它做出的一切你都能看到并修改，绑定在 Blender 中无需脚本即可工作。游戏引擎接收的是 `DEF-` 骨骼。把烘焙后的机械运动导出到引擎的功能会在以后的版本中提供（见"本版本的限制"）。

BoneCraft 提供的是工具，而不是武器。部件由你自己提供。

面板和本页使用的术语：

| 术语 | 含义 |
|---|---|
| *部件*（Part） | 作为一个整体移动的零件：一个物体，或一个网格中的一块松散部分。部件可以搭载在另一个部件上。 |
| *关节*（Joint） | 部件的运动方式：Hinge（转动）、Slide（移动）、Telescope（嵌套的段伸出）。 |
| *连接*（Link） | 替你移动部件的东西：Piston、Gear Link、Follow。 |
| *手柄*（Handle） | 你在视口中拖动的骨骼。每个关节有一个。它的值也是面板中的一个滑块。 |
| *序列*（Sequence） | 由一个滑块播放、由若干步骤组成的变形。 |
| *形态*（Form） | 保存下来的一组手柄和序列的值，例如"Stowed"（收起）或"Rifle"（步枪）。 |

## 位置

- 3D 视口中的 **BoneCraft 选项卡 → Mechanisms**。BoneCraft 选项卡位于左侧工具架（按 **T**），除非你在偏好设置中把它移到了右侧边栏（**N**）。它位于蒙皮和审查之间。当活动物体是网格（用来开始一个绑定），或是带有机械装置的骨架时，它才会显示。
- **属性编辑器 → 场景选项卡 → Mechanisms**，紧接在绑定构建器之后。它始终在那里。没有选中任何可用的东西时，它只显示一行："Select a mesh to start, or an armature with mechanisms."（选择一个网格以开始，或选择一个带有机械装置的骨架。）关闭视口中的 BoneCraft 选项卡不会移除它。只有 `mechanisms` 工具开关（**偏好设置 → 插件 → BoneCraft → 工具**）会把它连同视口中的副本一起移除。场景选项卡中的部分一开始是折叠的，因此请点击 **Mechanisms** 展开它。

Mechanisms 中有四个子部分：**1. Parts**（部件）、**2. Joints & Links**（关节与连接）、**3. Sequences**（序列）和 **4. Controls**（控制）。绑定有了部件之后它们才会出现。在此之前你只能看到 **Add Parts from Selection**（从所选项添加部件）。

每个按钮都是一个撤销步骤。如果某次创建失败，它所做的所有更改都会被还原，面板会显示原因。

## 部件

1. 在物体模式下选中作为部件的物体（或一个由松散部分组成的网格）。
2. 点击 **Add Parts from Selection**。
   - 多个物体：每个物体一个部件。每个物体都以其部件的骨骼为父级，并保持在原位。
   - 一个带有松散部分的网格：每个部分一个部件。每个部分都会得到一个对应其骨骼的顶点组，网格会得到一个骨架修改器。
   - 第一次时，BoneCraft 会为你创建绑定（一个骨架）。
3. 在列表中选择一个部件来编辑它。

对于每个部件：

- **Rides on:**（搭载于）：选择这个部件随之移动的部件。子部件会跟随它的父部件。"the rig"表示它搭载在绑定的根骨骼上。
- **Size**（大小）设置骨骼长度，也就决定了手柄的大小。
- **Edit Pivot**（编辑枢轴）会在部件上放一个标记。把它拖到部件转动或滑动的起点，然后点击 **Apply Pivot**（应用枢轴）。部件的骨骼会移到那里，物体保持原位。
- 当物体部件有未应用的旋转或缩放时，会出现 **Apply Transforms**（应用变换）。点击它。未应用的变换会让轴倾斜。
- **X** 按钮移除部件。只要有关节、连接或其他部件在使用它，它就会拒绝，并列出它们的名称。
- **Merge for VRChat**（为 VRChat 合并；有两个或更多物体部件时）会把物体部件合并为一个网格，每个原物体对应一个顶点组，并带有一个骨架修改器。请最后再做这一步。合并后的部件会成为这个网格中的松散部分。它会移除所有以该骨架的骨骼命名的顶点组（部件自己的 `DEF-` 骨骼除外），因此只合并仅绑定到机械装置绑定上的部件。

你可以重命名部件的物体：部件是标记在物体上的，因此部件能重新找到自己的物体。物体的副本（Shift+D）不会接管该部件。如果部件的物体被删除，部件会显示"Part '<name>' is missing"（部件 '<name>' 丢失），并提供 **Reassign**（重新指定）和 **删除**。其他机械装置会继续工作。

- **Reassign** 使用你选中的网格。它拒绝非网格物体，也拒绝已被另一个物体部件使用的物体。同一个网格的松散部分可以共用该网格。
- **删除** 移除部件（何时会被拒绝，见下文的"编辑与手动编辑"）。

## 关节与连接，各举一例

用 **Add Joint**（添加关节）添加关节，用 **Add Link**（添加连接）添加连接。每个选项都会开始一次引导式创建。它们在视口选项卡和属性编辑器的场景选项卡中都能使用；从场景选项卡使用时，引导会使用屏幕上最大的 3D 视口。所有引导式创建的简短规则：

- 在视口中点击部件。被点击的部件会显示轮廓和编号。
- 在需要轴的步骤中，按 **X**、**Y** 或 **Z**，或按 **A** 对齐到所选项。**Align to Selection**（对齐到所选项）用于倾斜的铰链。按 **A** 时，部件的网格必须仍处于编辑模式，并且选中了一条边或一个面；同时引导会忽略 **Tab**。因此请先进入该部件网格的编辑模式，并选中一条边或一个面。保持在编辑模式中，开始 **Add Joint → Hinge**，点击部件，按 **A**。如果没有选中任何可用的东西，引导会告诉你，你可以改按其他键。
- 最后一步会循环预览机械装置的运动。**Enter** 保留它。**Esc** 移除它。
- 标题栏和状态栏会为每一步显示一句完整的话。关闭 Show Helpers（显示帮助）时，它们只显示简短的标签。

Joints & Links 列表的每一行都有四个图标按钮：**Test**（测试，播放三角形）、**编辑**（铅笔，显示设置）、**Detach**（分离，断开的链条）和 **删除**（X）。

创建完成后，列表中选中的项目只显示其类型所使用的设置。

### Hinge（铰链）

刀刃 Hinge，0°…90°：

1. 用 Add Parts from Selection 添加一个 Blade（刀刃）部件。
2. **Add Joint → Hinge**。点击 Blade。按 **X**。按 **Enter**。
3. 你会得到一个半圆形手柄 `CTRL-Blade`，列表中会出现 *Blade Hinge*。把 **Min**（最小值）设为 0，**Max**（最大值）设为 90（Hinge 的单位是 °）。
4. 试一试：拖动半圆形手柄。它会停在 90°。**Set Min**（设置最小值）和 **Set Max**（设置最大值）会把手柄当前的姿势复制到限制中。

小于一整圈的限制必须保持在 −180°…180° 之内。170°…190° 这样的限制会被拒绝并给出提示。一整圈或更大的范围（例如 −180°…180°）会无限制地自由旋转。

### Slide（滑动）

枪管 Slide，0…0.3：

1. **Add Joint → Slide**。点击 Barrel（枪管）部件。按 **Y**。按 **Enter**。
2. 你会得到一个箭头手柄。把 **Min** 设为 0，**Max** 设为 0.3（场景单位）。
3. 试一试：拖动箭头。枪管会滑动并停在 0.3。

### Telescope（伸缩）

三段的桅杆：

1. 创建底座和三个段部件。
2. **Add Joint → Telescope**。点击底座。从底座向外依次点击每一段。按 **Enter**。按轴的键。按 **Enter** 保留。
3. 底座上会出现一个箭头手柄。**Length**（长度）是总行程；**Shares (empty = even)**（分配，空 = 平均）把它分配给各段。要试用自定义分配，先把 **Length** 设为 1，然后输入 `0.5, 0.25, 0.25`。分配之和必须等于 Length，这样末端才能走完全长。输入错误（例如 `0.5, abc`）会以同样的简单提示被拒绝：分配必须是数字，每段一个，且总和等于 Length。
4. 试一试：拖动这一个箭头。三段都会按各自的分配伸出。**Set Max** 根据手柄的姿势设置 Length。

### Piston（活塞）

升降机：缸体在框架上，活塞杆在臂上。

1. 先给臂添加一个 Hinge，并把臂设置为搭载在框架上。
2. **Add Link → Piston**。点击缸体部件（在框架上）。点击活塞杆部件（在臂上）。
3. 你会得到一个没有手柄的 Piston。每个部件都指向对方的连接点。**拉伸**（可选）会拉伸活塞杆，用于弹簧和缆线。
4. 试一试：移动臂的手柄。活塞会跟着动。如果还没有任何东西驱动这个 Piston，创建依然有效，但没有预览，**Test** 也会这样提示。

### Gear Link（齿轮连接）

齿轮 20:40：

1. 两个部件都需要先有关节。驱动部件需要一个 Hinge。对于 Gear 和 Belt，被驱动部件需要一个 Hinge；对于 Rack，它需要一个 Slide。
2. **Add Link → Gear Link**。点击驱动部件。点击被驱动部件。
3. 在它的设置中，把 **Source Teeth**（源齿数）设为 20，**Target Teeth**（目标齿数）设为 40（或输入 **Ratio**（比率））。**Kind**（类型）可以是 Gear、Belt 或 Rack。**Reverse**（反向）会翻转方向。
4. 试一试：转动源部件。当 **Kind** 为 Gear 时，目标转动的幅度为 −0.5 倍（Belt 时为 +0.5 倍）。Gear 会反转方向，Belt 保持方向，Rack 把旋转变成滑动（每弧度的距离 = **Ratio** × **Pinion Radius**（小齿轮半径））。

BoneCraft 的创建方式取决于源 Hinge 的范围：

- 小于一整圈：一个变换约束。它会跟随驱动源的一切，包括序列。
- 一整圈或更大：一个不需要 Python 的驱动器。目标会随源一直旋转。它只跟随手柄和齿轮。当序列或 Follow 会因此失效时，装备验证器会发出警告。

### Follow（跟随）

Blade 0–90° 抬起 Cover（盖子）0–40°：

1. 两个部件都需要一个 Hinge 或 Slide。源 Hinge 需要小于一整圈的限制；自由旋转的源会被拒绝。
2. **Add Link → Follow**。点击带头的部件（Blade）。点击跟随的部件（Cover）。
3. 范围一开始是每个关节的完整范围。把 **Source Range**（源范围）设为 0…90，**Target Range**（目标范围）设为 0…40。超出任一端时，目标保持不动。
4. 试一试：移动 Blade 的手柄。Cover 会跟着动。
5. 勾选 **Curve**（曲线），即可在曲线编辑器中重塑映射关系。BoneCraft 绝不会覆盖你的曲线（见下文的"编辑与手动编辑"）。

### Sequence（序列）

用 Capture Step 折叠一件武器：

1. 在 **3. Sequences** 中点击 **Add Sequence**（添加序列）。它会创建一个滑块手柄 `CTRL-SEQ-<name>`。
2. 点击 **Capture Step**（捕获步骤）。滑块会跳到末端（1）。
3. 为第一步摆好各关节的手柄。再次点击 **Capture Step**。每个移动过的手柄都会成为一个带有目标值的步骤，手柄回到零。
4. 要添加更多步骤，重复第 3 步。默认情况下，每个新步骤占用滑块的下一个四分之一。
5. 为每个步骤设置 **目标**、缓动（Linear、Ease In、Ease Out、Ease In Out、Snap）、**开始** 和 **End**（结束）。在自己的区段之外，步骤保持其结束值。多个序列可以叠加。
6. 点击 **Test**：滑块会按 0 → 1 → 0 播放。

在 **Capture Step** 和 **Test** 旁边，选中的序列有 **Detach**（断开的链条）和 **删除**（X）。被搁置的序列（例如某个步骤的曲线被你重塑过）会显示提示和一个 **恢复** 按钮。恢复会根据记录重新生成各步骤。序列不提供 Keep mine（保留我的）。

## 测试

**Test**（列表中以及 3. Sequences 中的播放按钮）会让一个机械装置在它的完整范围内来回运动一遍。它不写入任何关键帧，结束时会把姿势还原。按 **Esc** 可以提前停止；这时姿势同样会被还原。对于 Gear Link 或 Follow，它会运动源部件。对于 Piston，它会运动驱动它的关节。请留意相互碰撞的部件；BoneCraft 不检测碰撞。

## 形态

在 **4. Controls** 中：

- 每个关节和序列都有一个滑块。它就是手柄自身的通道，因此拖动手柄和使用滑块是一回事。
- **Save Form**（保存形态）会以一个名称记录每个手柄和序列滑块的值。可以在列表中重命名。
- **Go to Form**（转到形态）会把每个控件设为保存的值。
- **Go and Key**（转到并插帧）做同样的事，并在当前帧插入关键帧。
- 列表旁边的 **X** 会移除一个形态。

## BoneCraft 创建的内容

对于每个部件：

| 骨骼 | 作用 | 可见 |
|---|---|---|
| `CTRL-<part>` | 手柄。它的值就是面板中的滑块。只有 Hinge、Slide 和 Telescope 会创建它。 | 是 |
| `MCH-<part>` | 叠加手柄和每个连接，然后应用限制。 | 隐藏 |
| `DEF-<part>` | 复制 `MCH-<part>`。网格绑定到它上面。引擎接收的是这根骨骼。 | 隐藏 |

这些骨骼位于集合 `Mechanism Controls`、`Mechanism MCH` 和 `Mechanism DEF` 中。没有关节的部件只有 `MCH-` 和 `DEF-` 骨骼。Telescope 的手柄是 `CTRL-<telescope name>`。序列的手柄是 `CTRL-SEQ-<name>`。Piston 会为它的两个部件各添加 `MCH-<part>-aim` 和 `MCH-<part>-target` 骨骼。

`MCH-<part>` 上的约束总是按相同的顺序排列：先是来自手柄的复制变换，然后是每个连接的贡献，最后是关节的限制旋转或限制位置。`DEF-<part>` 有一个来自 `MCH-<part>` 的复制变换。

BoneCraft 创建的一切都带有它的记录标记：约束名称以 `BC·<id>·<role>` 开头，骨骼带有属性 `bc_mech_id` 和 `bc_mech_role`。BoneCraft 按标记而不是按名称查找它的骨骼，因此你可以重命名任何骨骼。重建时会再次找到它，不会创建重复项。

开启 Show Helpers 时，每个关节和连接都有一条 **How this works**（工作原理）说明。它按名称列出约束，说明每个约束的作用，并有一个 **选择** 按钮（箭头图标）用来检查骨骼。

你自己的约束、驱动器和骨骼绝不会被改动。你添加到 MCH 骨骼上的约束在重建后会保留在 BoneCraft 的约束下方。

## 编辑与手动编辑

- **Value edits**（数值编辑：限制、比率、范围、时间、缓动、手柄外观）会就地更新现有的约束。不会重建。
- **Structural edits**（结构编辑：Gear Link 的 **Kind**、Follow 的 **Curve**、Piston 的 **拉伸**）会替换该机械装置的约束，并只重建这个机械装置。
- **Changed by hand.**（已手动更改）如果你编辑了 BoneCraft 的某个约束（例如某个限制），该机械装置的提示末尾会显示"(changed by hand)"。BoneCraft 绝不会悄悄覆盖它。请选择：
  - **Keep mine**（保留我的）会把你的值复制到记录中。它会拒绝无法读回的内容，并提示你使用恢复或 Detach。
  - **恢复** 会丢弃你的编辑，并根据记录重建。
- 被搁置的机械装置也会搁置所有使用其骨骼的机械装置，直到你处理好它。
- 重塑过的曲线也一样。如果你在曲线编辑器中重塑了 Follow 的曲线（勾选了 **Curve**），然后更改了一个会替换它的值（例如它的 Target Range），Follow 的提示末尾会显示"(changed by hand)"。**Keep mine** 保留你的曲线。**恢复** 会重新生成它。
- 被搁置的序列会在 **3. Sequences** 中显示提示和 **恢复**，旁边有 **Detach** 和 **删除**。序列不提供 Keep mine。
- **Detach**（断开链条按钮）会删除记录和标记，但把骨骼和约束作为你自己手工制作的绑定保留下来。Detach 和删除都会拒绝被其他记录使用的记录，并列出使用者的名称。
- **删除**（X 按钮）会移除记录以及 BoneCraft 为它创建的一切。
- 连接循环在创建任何东西之前就会被拒绝，并指出这个循环，例如"Blade Hinge → Cover Follow → Blade Hinge would loop."（会形成循环）

装备验证器和任务板会报告连接循环、丢失的部件、从机械装置外部被移动的 DEF 骨骼、需要 Python 的驱动器，以及会使序列或 Follow 失效的 Gear Link。验证器的命名检查接受连字符（`CTRL-`、`MCH-`、`DEF-`），驱动器检查只对需要 Python 的表达式发出警告，因此一个干净的 Mechanisms 绑定不会显示验证错误——只有"本版本的限制"中所述、关于 `root` 骨骼的那一条警告。

## Show Helpers（显示帮助）

**Show Helpers** 是对整个 BoneCraft 生效的一个偏好设置：**偏好设置 → 插件 → BoneCraft → Helpers**。关闭后，各处的教学文字都会隐藏：做什么 / 何时用的说明、**How this works** 说明，以及引导步骤中的完整句子（会变成简短的标签）。步骤本身、列表、Test、警告以及 Blender 的悬停提示始终保留。

VRChat 的 **紧凑模式** 按钮是它的快捷方式：开启紧凑模式就等于关闭 Show Helpers。

## 本版本的限制

- Click Turn、Track 和 Linkage 机械装置会在以后的版本中提供。
- 把烘焙后的机械运动导出到引擎的功能会在桌面端手动检查之后的版本中提供。在那之前，请导出 `DEF-` 骨骼。
- BoneCraft 不检测碰撞。请使用 Test 并亲眼查看。
- 自由旋转的 Gear Link 只跟随手柄和齿轮。
- 绑定的 `root` 骨骼不在任何骨骼集合中，因此装备验证器的集合检查会对它发出警告，任务板会显示"Rig validation warnings (1)"（绑定验证警告 (1)）。
