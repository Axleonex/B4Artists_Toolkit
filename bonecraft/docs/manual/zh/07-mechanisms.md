# Mechanisms（机械装置）

[← 内容](index.md)

## Mechanisms 能做什么

将硬表面零件转变为工作机械装置的机构：铰链、
幻灯片、望远镜、活塞、齿轮、随动件和整个变换
通过一个滑块。它构建了普通的 Blender 骨骼和约束，所以你可以看到
并改变它所做的一切，该绑定系统可以在 Blender 中运行，无需脚本。
发动机接收 `DEF-` 骨骼。将烘焙的机构运动导出到引擎
稍后会出现（请参阅此版本的限制）。

BoneCraft 运送的是工具，而不是武器。你把零件带来。

[教程：Crescent Rose 带机构](12-crescent-rose.md) 是一个完整的示例，每个步骤都有屏幕截图。

面板和本页中使用的词语：

|词|含义|
|---|---|
|*部分*|作为一个固体块移动的一块：一个物体，或一个网格的松散块。一个部件可以骑在另一个部件上。|
|*联合*|零件如何移动：铰链（转动）、滑动（移动）、望远镜（延伸嵌套段）。|
|*链接*|为您移动零件的部件：活塞、齿轮连杆、跟随。|
|*手柄*|您在视口中拖动的骨骼。每个关节都有一个。它的值也是面板中的滑块。|
|*顺序*|由一个滑块进行的变换，由步骤组成。|
|*表格*|一组已保存的手柄和序列值，例如“收起”或“步枪”。|

## 位置

- 3D Viewport 中的 **BoneCraft tab → Mechanisms**。BoneCraft 选项卡位于
左侧工具架（按 **T**），除非您将其移至右侧边栏
(**N**) 在首选项中。它位于皮肤和评论之间。它显示当网格
处于活动状态（启动装置）或当带机构的电枢处于活动状态时；否则
它解释了要选择什么。
- **Properties editor → Scene tab → Mechanisms**，位于 Rig Builder 之后。它是
当首选项 → 选项卡 → 场景属性 → 显示打开时显示。什么也没有
可用选择它显示一行：“选择一个网格
启动，或带有机构的电枢。”切换 BoneCraft 视口选项卡
off 不会将其删除。场景属性开关仅隐藏场景副本。
`mechanisms` 工具开关（**首选项 → 附加组件 → BoneCraft → 工具**）
从每个位置删除该工具。
场景选项卡部分开始折叠，因此单击 **Mechanisms** 将其展开。
- **Object menu → Mechanisms**提供添加零件、关节和链接的快捷方式，
并测试运动。
- **Viewport toolbar → Build Mechanism** 从
在对象模式或姿势模式下单击某个部分。先添加零件，然后选择
机械装备或其零件之一，然后在工具标题中选择类型。

内部机制有四个小节：**1. Parts**，**2。关节&
链接**、**3。序列**和**4。控制**。一旦绑定系统完成，它们就会出现
零件。在此之前您只能看到 **Add Parts from Selection**。

每个按钮都是一个撤消步骤。如果构建失败，它更改的所有内容都会被放置
返回，面板显示原因。

## 部件

1. 在对象模式中选择零件对象（或由松散零件组成的一个网格）。
2. 单击 **Add Parts from Selection**。
 - 多个对象：每个对象一个部分。每个对象都是其部分的父对象
骨头并留在原处。
 - 带有松散碎片的一张网：每片一个零件。每一块都有一个顶点
对其骨骼进行组，并且网格体获得骨架修改器。
 - BoneCraft 第一次为您制作了钻机（电枢）。
3. 选择列表中的一个部分进行编辑。

对于每个部分：

- **骑乘：** 选择该部件移动的部分。子部分遵循其
父部分。 “钻机”意味着它骑在钻机的根部上。
- **Size** 设置骨骼长度，从而设置手柄尺寸。
- **Edit Pivot** 在零件上放置标记。将其拖动到零件应该放置的位置
转动或滑动，然后单击 **Apply Pivot**。该部分的骨骼移动到那里
并且该物体保持在原位。
- **Apply Transforms** 会在零件对象尚未应用旋转或
规模。单击它。未应用的变换会使轴倾斜。
- **X** 按钮可移除该部件。当接头、链接或其他
部分使用它，并命名它们。
- **Merge for VRChat** （两个或多个对象部分）将对象部分连接成
一个网格，每个前一个对象有一个顶点组和一个骨架修改器。
最后做这个。连接的部分成为该网格的松散部分。它
删除以该骨架的骨骼命名的每个顶点组（除了
零件自己的 `DEF-` 骨骼），因此仅合并绑定到零件的零件
单独的机械装置。

您可以重命名零件的对象：零件在其对象上标记，因此零件
再次找到它的对象。对象的副本 (Shift+D) 不会接管
部分。如果删除零件的对象，该零件会显示“零件 '<name>' 丢失”
与 **Reassign** 和**Delete**。其他机制继续发挥作用。

- **Reassign** 使用您选择的网格。它拒绝非网格，并且它
拒绝另一个对象部分已经使用的对象。一个零件松动
网格可以共享该网格。
- **Delete** 删除该部分（有关何时被拒绝的信息，请参阅下面的编辑）。

## 关节与连接，各举一例

添加与 **Add Joint** 的接头，与**Add Link** 的链接。每个选择都开始一个
引导构建。它们在视口选项卡和属性编辑器的场景中工作
选项卡；在“场景”选项卡中，指南使用屏幕上最大的 3D 视口。
或者，在视口工具栏中激活构建机制，选择关节
或在工具标题中键入链接，然后单击其第一部分。单击该按钮将启动
相同的指南并提供其第一选择。继续选择镐和轴
在视口中请求；添加联合和添加链接菜单仍然可用。

每个引导构建的简短规则：

- 单击视口中的零件。单击的零件会获得轮廓和编号。
- 如果步骤需要轴，请按 **X** 、**Y** 或**Z**，或**A** 来对齐
选择。 **Align to Selection** 适用于斜角铰链。它需要零件的网格
当您按 **A** 时仍处于编辑模式，并选择一个边缘或面，
并且指南忽略 **Tab**。因此，在零件网格上进入编辑模式，然后
首先选择一条边或面。保持编辑模式，开始 **添加关节 →
铰链**，单击零件，按**A**。如果没有选择任何可用的指南
告诉你，你可以按另一个键。
- 最后一步预览了循环移动的机制。 **Enter** 保留它。
**Esc** 将其删除。
- 标题和状态栏显示每个步骤的完整句子。随秀
帮手们展示了一个简短的标签。

关节和链接列表的每一行都有四个图标按钮： **Test** （播放
三角形）、**Edit** （铅笔，显示设置）、**Detach** （断链）和
**Delete** (X)。

构建后，列表中所选项目仅显示其设置
类型用途。

### Hinge（铰链）

刀片铰链，0°…90°：

1. 使用刀片零件从选择中添加零件。
2. **Add Joint → Hinge**。单击刀片。按**X**。按**Enter**。
3. 您将获得一个半圆手柄 `CTRL-Blade` 和一个*刀片铰链*
列表。设置 **Min** 0 和**Max** 90（铰链为°）。
4. 尝试一下：拖动半圆形手柄。它停在 90°。 **Set Min** 和
**Set Max** 将手柄的当前位姿复制到限制中。

整转以下的限制必须保持在 −180°…180° 范围内。限制例如
170°…190° 被拒绝并显示消息。一整圈或更多的范围（对于
例如-180°…180°）自由旋转，没有限制。

### Slide（滑动）

筒形滑块，0…0.3：

1. **Add Joint → Slide**。单击桶部分。按**Y**。按**Enter**。
2. 你会得到一个箭头手柄。设置 **Min** 0 和**Max** 0.3（场景单位）。
3. 尝试一下：拖动箭头。枪管滑动并停在0.3处。

### Telescope（伸缩）

桅杆分为三段：

1. 制作底座和三段部件。
2. **Add Joint → Telescope**。单击底座。单击底部的每个段
向外。按 **Enter**。按轴键。按**Enter** 保留。
3. 底座上有一个箭头手柄。 **Length** 为总行程；
**Shares (empty = even)** 将其分割到各个段之间。尝试定制
股，先将 **Length** 设置为 1，然后输入 `0.5, 0.25, 0.25`。股份
必须加起来等于长度，以便尖端移动整个长度。拼写错误（对于
例如 `0.5, abc` ）被拒绝，并带有相同的明文消息：股票
必须是数字，每段一个，加起来就是长度。
4. 尝试一下：拖动一个箭头。所有三个部门均按其份额扩展。
**Set Max** 根据手柄的姿势设置长度。

### Piston（活塞）

升降：气缸在机架上，杆在臂上。

1. 首先给手臂一个铰链，然后将手臂设置在框架上。
2. **Add Link → Piston**。单击圆柱体部分（在框架上）。单击杆
部分（手臂上）。
3. 你会得到一个没有手柄的活塞。每个部分都指向对方的附加部分
点。 **Stretch** （可选）拉伸杆，用于弹簧和电缆。
4. 尝试一下：移动手臂的手柄。活塞紧随其后。如果没有任何动静
活塞还没有，构建可以工作，但没有预览，**Test** 是这么说的。

### Gear Link（齿轮连接）

齿轮 20:40:

1. 两个部分首先需要一个接头。驱动部分需要铰链。对于齿轮和
皮带从动部分需要铰链；对于机架，它需要一个幻灯片。
2. **Add Link → Gear Link**。单击驱动部分。单击从动零件。
3. 在其设置中设置 **Source Teeth** 20 和**Target Teeth** 40 （或键入
**Ratio** ）。**Kind** 是齿轮、皮带或齿条。**Reverse** 翻转方向。
4. 尝试一下：打开源。使用 **Kind** Gear，目标转动 −0.5× 远
（+0.5× 带腰带）。 A 齿轮反转
方向，皮带保持它，齿条将旋转变成滑动（距离
每弧度 = **Ratio** ×**Pinion Radius** )。

BoneCraft 如何构建它取决于源铰链的范围：

- 在完整转弯下：变换约束。它跟随一切移动的事物
来源，包括序列。
- 一整圈或更多：不需要 Python 的驱动程序。目标永远旋转
与来源。它仅跟随手柄和齿轮。钻机验证器发出警告
当序列或跟随会丢失时。

### Follow（跟随）

刀片 0–90° 升起 盖子 0–40°：

1. 两个部件都需要铰链或滑块。源铰链需要限制在
全转；自由旋转的来源被拒绝。
2. **Add Link → Follow**。单击前导部分（刀片）。点击以下
部分（封面）。
3. 范围从每个关节的完整范围开始。套装 **Source Range**
0…90 和 **Target Range** 0…40。越过任一端，目标都保持不变。
4. 尝试一下：移动刀片手柄。封面如下。
5. 勾选 **Curve** 以在图表编辑器中重塑映射。 BoneCraft 永不
覆盖您的曲线（请参阅下面的编辑）。

### Sequence（序列）

记录一下折叠武器的步骤：

1. 在“**3. Sequences** ”中，单击“**Add Sequence** ”。它制作了一个滑块手柄
`CTRL-SEQ-<name>`。
2. 单击 **Move Slider to End**。滑块跳到末尾 (1)，按钮
变为记录步骤，后跟下一步编号。
3. 第一步，摆好关节手柄的姿势。单击记录步骤 1。
每个移动的手柄都会成为一个具有其目标值的步骤，并且
手柄回到零。
4. 重复步骤 2 和 3 以获取更多步骤。每一个新步骤都需要下一个季度的时间
默认情况下滑块。
5. 设置**Target**，缓动（线性、缓入、缓出、缓入出、捕捉）、
每个步骤的 **Start** 和**End**。在其切片之外，有一个台阶固定其末端
值。多个序列可以堆叠。
6. 单击**Test**：滑块播放0→1→0。

在分步录制按钮和 **Test** 旁边，所选序列有**Detach**
（断链）和 **Delete** (X)。一个持有的序列（例如一个步骤，其
您重塑的曲线）显示其消息和 **Restore** 按钮。恢复
从记录中重新生成步骤。序列不提供保留我的功能。

## 测试

**Test** （列表中的播放按钮，以及3.序列中的）扫一扫
机制通过其全范围和背部。它不写关键点并放置姿势
结束时回来。按**Esc** 提前停止；然后姿势恢复
也是。对于 Gear Link 或 Follow 它会扫描源。对于活塞来说，它横扫了
移动它的关节。注意发生冲突的部分； BoneCraft 未检测到
碰撞。

## 形态

在**4. Controls** 中：

- 每个关节和序列都有一个滑块。这是手柄自己的通道，所以
拖动手柄和使用滑块是同一件事。
- **Save Form** 在名称下记录每个手柄和序列滑块值。
在列表中重命名它。
- **Go to Form** 将每个控制设置为保存的值。
- **Go and Key** 执行相同的操作，也在当前帧上插入关键点。
- 列表旁边的 **X** 删除一个表单。

## BoneCraft 创建的内容

对于每个部分：

|骨|职位|可见|
|---|---|---|
|`CTRL-<part>` |手柄。它的值是面板滑块。只有铰链、滑动件和望远镜是其中之一。|是的|
|`MCH-<part>` |添加句柄和每个链接，然后应用限制。|隐藏|
|`DEF-<part>` |副本 `MCH-<part>`。网格与其绑定。发动机接受这根骨头。|隐藏|

这些骨头位于 `Mechanism Controls` 、`Mechanism MCH` 和
`Mechanism DEF`。没有关节的零件只有 `MCH-` 和 `DEF-` 骨骼。一个
望远镜的手柄是`CTRL-<telescope name>`。一个序列是
`CTRL-SEQ-<name>`。活塞添加 `MCH-<part>-aim` 和 `MCH-<part>-target` 骨骼
对于它的两个部分中的每一个。

`MCH-<part>` 上的约束始终以相同的顺序出现： 复制变换
从手柄开始，然后是每个连杆的贡献，然后是关节的极限旋转
或限制位置。 `DEF-<part>` 有一个来自 `MCH-<part>` 的复制转换。

BoneCraft 构建的所有内容都标有其记录：约束名称开始
具有 `BC·<id>·<role>`，并且骨骼具有属性 `bc_mech_id` 和
`bc_mech_role`。 BoneCraft 通过标签而不是名称查找其骨骼，因此您可以
重命名任何骨骼。重建会再次找到它并且不会重复。

打开“显示助手”后，每个关节和链接都有 **How this works** 注释。它
按名称列出约束，说明每个约束的作用，并有一个 **Select**
按钮（箭头图标）来检查骨骼。

你自己的约束、驱动力和骨头永远不会被触及。您添加的约束
重建后，MCH 骨骼的高度仍低于 BoneCraft。

## 编辑与手动编辑

- **值编辑**（限制、比率、范围、计时、缓和、手柄外观）更新
现有的限制。没有重建。
- **结构编辑**（Gear Link 的**Kind** 、Follow 的**Curve** 、
活塞的 **Stretch** ）取代该机制的约束并仅重建
那个机制。
- **手动更改。** 如果您编辑 BoneCraft 约束（例如
限制），该机制的消息以“（手动更改）”结尾。 BoneCraft 从不覆盖
它默默地。选择：
 - **Keep mine** 将您的值复制到记录中。它拒绝它不能拒绝的东西
读回来，并说使用“恢复”或“分离”。
 - **Restore** 丢弃您的编辑并从记录中重建。
- 一个固定机构还可以固定所有使用其骨骼的机构，直到您
解决它。
- 重塑曲线是相同的。如果重塑跟随曲线 (**Curve**
勾选）在图形编辑器中，然后更改将替换它的值，
例如其目标范围，Follow 的消息以“（手动更改）”结尾。 **Keep mine**
保持你的曲线。 **Restore** 重新生成它。
- 保留的序列在 **Restore** 中显示其消息和**3. Sequences**，其中
旁边是**Detach** 和**Delete**。序列不提供保留我的功能。
- **Detach** （断链按钮）删除记录和标签，但保留骨骼和
约束作为您自己的手工制作的装备。分离和删除都拒绝记录
另一个记录使用的名称，并命名用户。
- **Delete** （X 按钮）删除记录以及 BoneCraft 为其构建的所有内容。
- 在构建任何内容之前，链接循环会被拒绝，并且该循环被命名为 for
例如“刀片铰链→盖跟随→刀片铰链将循环。”

绑定系统验证器和任务板报告链接循环、缺失零件、DEF
骨骼从其机制外部移动，需要 Python 和 Gear 的驱动程序
丢失序列或关注的链接。验证器的命名检查接受
连字符（`CTRL-` 、`MCH-` 、`DEF-` ），其驱动程序仅检查警告
需要 Python 的表达式，因此干净的 Mechanisms 绑定系统不会显示任何验证
错误 — 只有一个关于 `root` 骨骼的警告，此版本的限制中描述了这一点。

## Show Helpers（显示帮助）

**Show Helpers** 是所有 BoneCraft 的一项首选项：**首选项 →
附加组件 → BoneCraft → 助手**。 Off 到处隐藏教学文本：什么/何时
行、**How this works** 注释和完整的引导步骤句子（那些
成为短标签）。步骤本身、列表、测试、警告和
Blender 的悬停工具提示始终保留。

VRChat **Compact Mode** 按钮是它的快捷方式： 紧凑模式打开意味着显示
帮手下班了

## 本版本的限制

- 单击转向、跟踪和联动机制稍后推出。
- 烘焙机械运动的引擎导出稍后出现，在桌面手之后
检查。在此之前，`DEF-` 骨骼就是要导出的骨骼。
- BoneCraft 不检测冲突。使用测试并查看。
- 自由旋转的齿轮连杆仅跟随手柄和齿轮。
- 该绑定系统的 `root` 骨骼不在无骨骼集合中，因此绑定系统验证器的
集合检查会发出警告，并且任务板显示“装备验证
警告（1）”。
