## 9.2.3 — VRChat 导出位置

移除 Avatar Tools 中重复的 Export to VRChat 面板。导出功能保留在 CATS → Import / Export → Unity / VRChat。

## 9.2.2 — 当前界面

选项卡用于选择功能组。Setup Rigging、Skin、Review、Avatar Tools 和 Facial 是选项卡内可展开的分区，不是独立选项卡。下列路径保留英文界面标签；翻译名称取决于 Language 设置。

- Bone Merge → BoneCraft → Setup Rigging
- Delta Mush / Proximity Wrap → BoneCraft → Skin
- Viseme Library / Lip Sync → CATS → Avatar Tools
- VRChat Viseme Mapping / Face Tracking → CATS → VRChat Tools → Facial

## 9.1.2（2026年10月）

- **场景属性开关：** 偏好设置 > 选项卡中新增了“场景属性”一行。它的“显示”按钮（开启时为蓝色）可以在不停用插件的情况下，显示或隐藏属性 > 场景选项卡中 BoneCraft 的所有部分（绑定构建器、机构、CATS、VRChat、导入 / 导出）。它默认开启，不影响 3D 视图的选项卡和骨架选项卡。

## 9.1.1（2026年10月）

- **更清楚的图标：** 现在每个图标在任何地方都只表示一种含义。约 60 个按钮换上了更贴切的 Bforartists 图标（例如应用全部变换、精简、规范名称、翻译、合并、分离、混合姿态和口型同步），同一个按钮在所有面板中显示同一个图标。
- **更清爽的面板：** 标题和固定文字不再带主题图标。报告状态的提示显示信息、警告或勾选图标。
- **易读的图标网格：** 工具架姿态和权重选项卡中的每个按钮都有自己的图标，工具架变窄时也能分辨。

## 9.1.0（2026年10月）

- **工具放在 Bforartists 放自己工具的地方：** 添加 → 骨架、姿态、权重和物体菜单中有了 BoneCraft 条目，Bforartists 工具架的姿态和权重选项卡中有了 BoneCraft 按钮面板。
- **先执行，后调整：** 快速绑定、适配拖入的骨架、权重工具、条带、样条 IK、Delta Mush 和 CATS 骨骼工具会用上次的数值立即执行，之后在“调整上一步操作”面板中调整。“确定吗”弹窗也更少了。
- **先显示操作，选项折叠：** 面板先显示按钮，设置放在下方的折叠区。设置以设置的样子显示（复选框，而不是按钮），面板标题不带图标。
- **手势工具：** “放置绑定标记”（点击网格放置自动绑定向导的下一个标记）和“构建机械结构”（点击部件开始一个关节或连接）位于视图工具栏中。
- **工具提示：** 每个操作和每个选项都有说明。
- **显示而不隐藏：** 骨架不在时各部分仍然可见并提示要选择什么，自动绑定向导在 Rig Builder 中排在最前，工具架打开时宽度足够阅读。
- **修复：** 生成样条 IK 重新可用；添加影响使用所选骨骼；口型预览使用其所属的集合。

## 9.0.0（2026年10月）

- **Mechanisms：** BoneCraft 选项卡（以及属性编辑器的场景选项卡）中的一个新部分，用于绑定道具和机械：Hinge、Slide、Telescope、Piston、Gear Link、Follow 和 Sequence，通过引导式步骤创建，并用 Test 检查。BoneCraft 绝不会覆盖手动编辑：选择 **Keep mine** 保留它，或选择 **恢复** 重建。参见 [Mechanisms（机械装置）](07-mechanisms.md)。
- **选项卡位置：** 每个视口选项卡都可以放在左侧工具架或右侧边栏（偏好设置 → Tabs → Left / Right）。BoneCraft 和 Rig Builder 默认在左侧，CATS 在右侧。
- **绑定构建器：** 始终位于属性编辑器的场景选项卡中，另外还有它自己的视口选项卡，在较窄的工具架中使用紧凑布局。Basic Humanoid 绑定随 BoneCraft Rigs 资源库一起提供；Fit Dropped Rig 会适配从资源架放下的绑定。
- **CATS 选项卡：** 导入 / 导出移到了 CATS 选项卡中。CATS、VRChat 和导入 / 导出也始终位于场景选项卡中。
- **Show Helpers：** 一个偏好设置即可显示或隐藏 BoneCraft 的教学文字；紧凑模式是它的快捷方式。
- **装备验证器：** 带连字符的骨骼名称可以通过；驱动器只对需要 Python 的表达式发出警告；Mechanisms 绑定也会被检查。任务板的验证器任务恢复了报告。
- **名称：** 这个插件名为 BoneCraft。

## 更早的版本

**8.5.0：** 现在 Smart Combine 在烘焙后默认把 `atlas_uv` 作为导出用的 UV0。除非在高级设置中启用 **Keep Source UV Maps**（保留源 UV 贴图），否则图集化之前的源 UV 贴图会从生成的图集网格中移除。CATS / Material Combiner / 源自 UVToolkit 的控件现在与开放的 Blender 版本共用；B4Artists 独占的仍是生产级的绑定、控制、重定向 / 导出以及仅限 B4Artists 的发布系统。

8.5.0 还更新了导出和验证的工作流。VRChat、VRM、MMD 和 Unreal 导出现在会在 BoneCraft 面板中提供文件夹和文件名控件，而不是只能依赖 Blender 文件浏览器的默认设置。VRChat/Unity 和 Unreal 的 FBX 导出默认开启 **Embed Textures**，便于导入材质；VRChat 导出则会把辅助 / 控制形状网格排除在 FBX 之外，除非启用 **Helper Meshes**。VRM 面板现在包含 **立即检查** 和 **Fix Humanoid Map**，后者可以在导出前修复过时的人形别名映射，而不会重命名你的骨骼。

**8.4.5：** Smart Combine 现在在烘焙时强制源纹理采样保留下来的图集化之前的 UV，在隐藏原始内容之前验证生成的图集网格，并把所有图集面重置为最终的图集材质槽，以防止长袍 / 服装出现灰色或错乱的色块。

**8.4.4：** 材质图集合并在烘焙前加入了达到同等质量的检查控件：着色器 / 材质诊断、纹理角色标签、重复 / 共享的源标记、按材质的尺寸覆盖、打包预设、可选的 Normal/Emission/Roughness 输出烘焙，以及在该路径验证之前对 Metallic/ORM 通道打包的预检阻止。

**8.4.3：** 材质图集合并在现有的材质图集工作流中加入了可选的 UV 打包方法。包括 Smart Pack、Grid Pack、Seeded Variation、Oriented Pack、Fit 0-1 Bounds、Advanced Variation 和 Rotation Step，UV 方法的详细信息会记录在调试报告和烘焙记录中。

**8.4.2：** 材质图集合并现在在烘焙时以生成的图集 UV 为目标，而复制过来的源纹理节点会明确读取图集化之前的 UV。这修复了由于源纹理和烘焙出的图集采样不同 UV 贴图而导致的长袍 / 服装图集结果损坏。8.4.1 中可选择的材质和纹理行仍然可用。

**7.1.3（偏好设置标签整理）：** 两个插件偏好设置开关被重命名，现在与它们控制的侧边栏选项卡一致。"VRChat Avatar Tools"现在标为 **CATS**（与 CATS 侧边栏选项卡一致）。"Task Board & Sidebar"现在标为 **Rig Builder**（与 Rig Builder 侧边栏选项卡一致）。没有移除任何工具——只有 编辑 > 偏好设置 > 插件 > BoneCraft 中的开 / 关标签变了。

**7.1.1：** BoneCraft 现在包含 CATS 工具——一整套专门用于让 VRChat 虚拟形象变得干净、经过优化并完全配置好的模型准备工具。CATS 有自己的侧边栏选项卡，并使用一套流程系统，每次都引导你按正确的顺序操作。
