# 新功能

[← 内容](index.md)

最新的优先。

## 9.1.2（2026年10月）

- **场景属性开关：**首选项>选项卡有一个新的场景属性行。其“显示”按钮（打开时呈蓝色）显示或隐藏“属性”>“场景”选项卡（绑定系统生成器、机制、CATS 、阿凡达工具、VRChat 工具、导入/导出）中的所有 BoneCraft 部分，而无需禁用附加组件。它开始，并且只留下视口选项卡和骨架选项卡。参见 [东西在哪里](01-start.md#各功能在哪里)。

## 9.1.1（2026年10月）

- **更清晰的图标：**现在每个图标在任何地方都意味着一件事。大约 60 个按钮获得了更合适的 Bforartists 图标（例如“应用所有变换”、“抽取”、“规范化名称”、“翻译”、“合并”、“分离”、“混合姿势”和“唇形同步”），并且有一个按钮在每个面板中显示相同的图标。
- **更平静的面板：**标题和固定文本不再带有主题图标。报告状态的提示显示信息、警告或检查图标。
- **可读的图标网格：**姿势和权重工具架选项卡中的每个按钮都有自己的图标，因此狭窄的工具架保持可读。

## 9.1.0（2026年10月）

- **Bforartists 放置自己的工具：** 添加 → 骨架、姿势、权重和对象菜单中的 BoneCraft 条目，以及 Bforartists 的姿势和权重工具架选项卡中的 BoneCraft 按钮面板。
- **先行动，后调整：** Quick Rig、Fit Dropped Rig、权重工具、Ribbon、Spline IK 、Delta Mush 和 CATS 骨骼工具会使用您上次使用的值立即运行；之后您可以在“调整上次操作”面板中调整它们。更少的“您确定吗”弹出窗口。
- **操作优先，选项折叠：** 几个面板首先显示其按钮，并在下面的折叠中显示可选设置。所需的输入保留在操作之前，就像修复模型的清理开关一样。设置看起来像设置（复选框，而不是按钮），并且面板标题没有图标。
- **手势工具：** 放置绑定系统标记（单击网格以放置自动绑定系统向导的下一个标记）和构建机制（单击零件以启动关节或链接）位于视口工具栏中。
- **头像部分：** 头像工具包含人形映射、头发、发音嘴型和导出。单独的 VRChat 工具部分对性能、服装和命名实用程序进行分组。指南使用这些当前的面板名称。
- **工具提示：** 每个操作符和每个选项都有其自身的解释。
- **显示，不要隐藏：**部分保持可见，并说明当绑定系统消失时要选择什么，自动绑定系统向导在绑定系统生成器中首先出现，并且架子开始足够宽以方便阅读。
- **Fixes:** 生成样条线 IK 再次工作；添加影响使用所选骨骼；视位预览使用他们的集合。

## 9.0.0（2026年10月）

- **机制：** BoneCraft 选项卡（以及“属性场景”选项卡）的新部分，用于绑定系统道具和机器：铰链、滑块、望远镜、活塞、齿轮连杆、跟随和序列，使用引导步骤构建并通过测试进行检查。 BoneCraft 永远不会覆盖手动编辑：您选择**Keep mine** 保留它或**Restore** 重建。参见 [机制](07-mechanisms.md)。
- **示例文件：** `examples/crescent-rose/` 持有装有机构（镰刀、步枪和紧凑型）的 Crescent Rose，手册中的 [第12章](12-crescent-rose.md) 逐步构建它。
- **选项卡侧面：** 每个视口选项卡都可以位于左侧工具架或右侧边栏上（首选项 → 选项卡 → 左/右）。 BoneCraft 和 Rig Builder 从左侧开始，CATS 在右侧开始。
- **装备生成器：**始终位于“属性场景”选项卡中，加上其自己的视口选项卡，其布局紧凑，适用于狭窄的工具架。 BoneCraft Rigs 资源库中提供了基本人形绑定系统；适合掉落的绑定系统适合从资产架上掉落的绑定系统。
- **CATS 选项卡：** 导入/导出移至 CATS 选项卡。 CATS 、VRChat 和导入/导出也始终位于“场景”选项卡中。
- **显示助手：**一项偏好显示或隐藏BoneCraft 的教学文本；紧凑模式是它的快捷方式。
- **装备验证器：**带有连字符的骨骼名称通过；驱动程序仅对需要 Python 的表达式发出警告；机械装置也经过检查。任务板的验证人任务再次报告。
- **名称：** 该附加组件名为 BoneCraft。

## 8.9.x（2026 年 9 月–10 月）

- **8.9.6:** 整件连衣裙遵循裙骨（无臀部剪裁）；下巴张开的角矫正器，带有粘性嘴唇。
- **8.9.5:** IK/FK 肘形开关，无弹出；对称肩部检测；眼睛标记不再折断；控制选择器显示选择；嘴角更圆；穿着过大腿矫正；放松的重新定位锁骨； T 形导出。
- **8.9.4：** 更圆的膝盖（矫正措施取代了保留体积）；用于深度弯曲的接触键；肩缝混合。
- **8.9.3：** 两段裙骨，跟随腿并由腿推动。
- **8.9.2:** 使用形状键闪烁（盖子不折叠）；椭圆形的嘴巴张开。
- **8.9.1：** 密集网格上的蒙皮速度更快（678,000 个顶点：232 秒到 57 秒）；骨热通过更轻的代理网格而不是默默地失败。
- **8.9.0:** 关节矫正形状关键点；面部控制（眼睛瞄准、眨眼、嘴唇跟随）；随关节弯曲的衣服。
- 8.9 中还包括：自动骨骼权重重新计算，以及更清晰的图集选择。

- **8.6.1–8.6.3:** Material Atlas：烘烤后的瓷砖诊断； MToon 透明度根据真实纹理 Alpha 进行检查，并在图集过程中保持不变；更好地分配混合材料。
- **8.5.5–8.5.10：** VRM / MToon 材料：尊重 alpha 模式，alpha 适用于 Blender 5 主机，无排放爆裂，洋红色诊断和安全地图集名称。

- **8.5.1:** FBX 导出保持混合形状。

## 更早的版本

**8.5.0:** 智能组合现在在烘焙后默认将 `atlas_uv` 设为导出 UV0。除非在高级设置中启用**Keep Source UV Maps**，否则图集前源 UV 贴图将从生成的图集网格中删除。 CATS / 材质组合器 / UVToolkit 衍生控件现在与开放的 Blender 版本共享； B4Artists 在制作绑定系统、控制、重定向/导出和仅限 B4Artists 的发布系统上仍享有独家权。

8.5.0 还更新了导出和验证工作流程。 VRChat 、VRM 、MMD 和 Unreal 导出现在在 BoneCraft 面板中公开文件夹和文件名控件，而不是强迫您仅依赖 Blender 的文件浏览器默认设置。 VRChat /Unity 和 Unreal FBX 导出默认为 **Embed Textures**，以便于材质导入，而 VRChat 导出将帮助器/控制形状网格体保留在 FBX 之外，除非**Helper Meshes** 已启用。 VRM 面板现在包括**Lint Now** 和**Fix Humanoid Map**，它可以在导出之前修复过时的人形别名映射，而无需重命名骨骼。

**8.4.5：** 智能组合现在强制源纹理在烘焙过程中对保留的图集前 UV 进行采样，在隐藏原始图集之前验证生成的图集网格，并将所有图集面重置为最终图集材质槽以防止出现灰色或混乱的长袍/衣服块。

**8.4.4:** 材质图集组合器在烘焙前添加了质量奇偶校验控制：着色器/材质诊断、纹理角色标签、重复/共享源标记、每种材质尺寸覆盖、打包预设、可选的法线/发射/粗糙度输出烘焙以及用于金属/ORM 通道打包的预检阻止程序，直到验证该路径。

**8.4.3:** Material Atlas Combiner 包括现有 Material Atlas 工作流程中可选择的 UV 打包方法。它包括智能包、网格包、种子变体、定向包、拟合 0-1 边界、高级变体和旋转步骤，并在调试报告和烘焙分类帐中记录 UV 方法详细信息。

**8.4.2:** 材质图集组合器现在以烘焙期间生成的图集 UV 为目标，而复制的源纹理节点显式读取图集前的 UV。这修复了由源纹理和采样不同 UV 贴图的烘焙图集导致的破损长袍/服装图集结果。 8.4.1 中的可选材质和纹理行仍然可用。

**7.1.3（首选项标签清理）：** 两个附加首选项切换已重命名，因此它们现在与它们控制的侧边栏选项卡相匹配。 “VRChat 头像工具”现在标记为**CATS** （与 CATS 侧边栏选项卡匹配）。 “任务板和侧栏”现在标记为**Rig Builder** （与 Rig Builder 侧栏选项卡匹配）。没有删除任何工具 - 仅编辑 > 首选项 > 附加组件 > BoneCraft 中的开/关标签发生了变化。

**7.1.1：** BoneCraft 现在包括 CATS 工具 - 一套完整的模型准备工具，专门用于使 VRChat 化身干净、优化和完全配置。 CATS 位于其自己的侧边栏选项卡中，并使用管道系统来引导您每次完成正确的操作顺序。
