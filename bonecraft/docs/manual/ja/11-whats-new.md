# 新機能

[← 目次](index.md)

新しい順に並べています。

## 9.2.3 — VRChat エクスポートの場所

Avatar Tools の重複した Export to VRChat パネルを削除しました。エクスポートは CATS → Import / Export → Unity / VRChat に残ります。

## 9.2.2 — 現在のインターフェース

タブで機能グループを選びます。Setup Rigging、Skin、Review、Avatar Tools、Facial はタブ内の展開可能なセクションで、独立したタブではありません。以下は英語 UI のラベルです。翻訳名は Language 設定に従います。

- Bone Merge → BoneCraft → Setup Rigging
- Delta Mush / Proximity Wrap → BoneCraft → Skin
- Viseme Library / Lip Sync → CATS → Avatar Tools
- VRChat Viseme Mapping / Face Tracking → CATS → VRChat Tools → Facial

## 9.1.2（2026年10月）

- **シーンプロパティのスイッチ:** プリファレンス > タブに「シーンプロパティ」の行が加わりました。その「表示」ボタン（オンの間は青）で、プロパティ > シーンタブにある BoneCraft のすべてのセクション（リグビルダー、メカニズム、CATS、VRChat、インポート / エクスポート）を、アドオンを無効にせずに表示・非表示にできます。最初はオンで、3D ビューのタブとアーマチュアタブには影響しません。

## 9.1.1（2026年10月）

- **わかりやすいアイコン:** 各アイコンはどこでも一つの意味だけを持つようになりました。約 60 個のボタンが、より合った Bforartists のアイコンになり（例: すべてのトランスフォームを適用、デシメート、名前の正規化、翻訳、マージ、分離、ポーズのブレンド、リップシンク）、同じボタンはどのパネルでも同じアイコンを表示します。
- **すっきりしたパネル:** 見出しや固定のテキストには、話題を表すアイコンを付けなくなりました。状態を知らせるヒントには、情報・警告・チェックのアイコンが付きます。
- **読みやすいアイコングリッド:** ツールシェルフのポーズタブとウェイトタブのボタンはそれぞれ別のアイコンを持つので、シェルフを狭くしても見分けられます。

## 9.1.0（2026年10月）

- **Bforartists の定位置にツール:** 追加 → アーマチュア、ポーズ、ウェイト、オブジェクトの各メニューに BoneCraft の項目を追加し、Bforartists のツールシェルフのポーズ・ウェイトタブに BoneCraft のボタンパネルを追加しました。
- **まず実行、あとで調整:** クイックリグ、ドロップしたリグのフィット、ウェイトツール、リボン、スプライン IK、デルタマッシュ、CATS のボーンツールは前回の値ですぐに実行され、あとから「最後の操作を調整」パネルで調整します。「よろしいですか」の確認も減りました。
- **操作が先、オプションは折りたたみ:** パネルはまずボタンを表示し、設定はその下の折りたたみに入ります。設定は設定らしく(ボタンではなくチェックボックス)表示され、パネルのヘッダーにはアイコンがありません。
- **ジェスチャーツール:** 「リグマーカーを配置」(メッシュをクリックしてオートリグウィザードの次のマーカーを配置)と「メカニズムを構築」(パーツをクリックしてジョイントやリンクを開始)がビューポートのツールバーに入りました。
- **ツールチップ:** すべてのオペレーターとオプションに説明が付きました。
- **隠さずに表示:** リグがなくてもセクションは表示されたまま何を選ぶかを示し、Rig Builder ではオートリグウィザードが先頭になり、シェルフは読める幅で開きます。
- **修正:** スプライン IK の生成が再び動作します。影響の追加は選んだボーンを使います。ビセムのプレビューは自分のセットを使います。

## 9.0.0（2026年10月）

- **Mechanisms：** BoneCraft タブ（とプロパティのシーンタブ）の新しいセクション。小道具や機械をリギングします。Hinge、Slide、Telescope、Piston、Gear Link、Follow、Sequence を、案内付きの手順で作り、Test で確認します。BoneCraft が手での編集を上書きすることはありません。残すなら **Keep mine**、作り直すなら **復元** を選びます。[Mechanisms（メカニズム）](07-mechanisms.md) を参照してください。
- **タブの位置：** ビューポートの各タブを、左のツールシェルフか右のサイドバーに置けます（プリファレンス → Tabs → Left / Right）。BoneCraft と Rig Builder は左、CATS は右から始まります。
- **リグビルダー：** プロパティのシーンタブに常にあり、さらに専用のビューポートのタブもあります。狭いツールシェルフではコンパクトな表示になります。Basic Humanoid のリグが BoneCraft Rigs アセットライブラリに入っています。Fit Dropped Rig は、アセットシェルフからドロップしたリグをフィットします。
- **CATS タブ：** インポート / エクスポートが CATS タブに移りました。CATS、VRChat、インポート / エクスポートは、シーンタブにも常にあります。
- **Show Helpers：** 1 つの設定で BoneCraft の説明の文を表示・非表示にします。コンパクトモードはその近道です。
- **リグバリデーター：** ハイフンを含むボーン名は合格します。ドライバーは Python が必要な式にだけ警告します。Mechanisms のリグも確認されます。タスクボードのバリデーターのタスクが再び報告されます。
- **名前：** アドオンの名前は BoneCraft です。

## それ以前のバージョン

**8.5.0：** Smart Combine は、ベイクの後、標準で `atlas_uv` をエクスポート用の UV0 にするようになりました。アトラス化する前の元の UV マップは、詳細設定で **Keep Source UV Maps**（元の UV マップを残す）を有効にしない限り、生成されたアトラスのメッシュから取り除かれます。CATS / Material Combiner / UVToolkit に由来する操作は、オープンな Blender 版と共有されるようになりました。B4Artists 専用のままなのは、本番向けのリギング、コントロール、リターゲット / エクスポート、B4Artists 専用のリリースの仕組みです。

8.5.0 では、エクスポートと検証のワークフローも更新されました。VRChat、VRM、MMD、Unreal のエクスポートでは、Blender のファイルブラウザーの標準設定だけに頼らずに済むよう、BoneCraft のパネルにフォルダーとファイル名の操作が表示されるようになりました。VRChat/Unity と Unreal の FBX のエクスポートは、マテリアルをインポートしやすいよう標準で **Embed Textures** になります。VRChat のエクスポートでは、**Helper Meshes** を有効にしない限り、ヘルパーやコントロール用の形のメッシュを FBX に含めません。VRM のパネルには **今すぐリント** と **Fix Humanoid Map** が加わりました。Fix Humanoid Map は、ボーンの名前を変えずに、エクスポート前に古くなったヒューマノイドの別名の対応を直せます。

**8.4.5：** Smart Combine は、ベイク中に元のテクスチャが、保存したアトラス化前の UV を必ず参照するようにしました。また、元のものを隠す前に生成したアトラスのメッシュを検証し、アトラスのすべての面を最終的なアトラスのマテリアルスロットに戻して、ローブや衣装の一部が灰色になったり乱れたりするのを防ぎます。

**8.4.4：** マテリアルアトラス結合に、ベイク前の品質を確かめる確認の操作が加わりました。シェーダーとマテリアルの診断、テクスチャの役割のラベル、重複や共有された元の印、マテリアルごとのサイズの上書き、パッキングのプリセット、任意の法線 / エミッション / ラフネスの出力のベイク、そしてその方法が検証されるまでの、メタリック / ORM のチャンネルのパッキングに対する事前の阻止です。

**8.4.3：** マテリアルアトラス結合に、既存のマテリアルアトラスのワークフローの中で選べる UV のパッキングの方式が入りました。Smart Pack、Grid Pack、Seeded Variation、Oriented Pack、Fit 0-1 Bounds、Advanced Variation、Rotation Step があり、UV の方式の詳細はデバッグレポートとベイクの記録に書き込まれます。

**8.4.2：** マテリアルアトラス結合は、ベイク中に生成したアトラスの UV を対象にし、コピーした元のテクスチャのノードは、アトラス化前の UV を明示的に読むようになりました。元のテクスチャとベイクしたアトラスが違う UV マップを参照することで起きていた、ローブや衣装のアトラスが壊れる問題が直りました。8.4.1 で入った、選べるマテリアルとテクスチャの行も引き続き使えます。

**7.1.3（プリファレンスのラベルの整理）：** アドオンのプリファレンスの 2 つのスイッチの名前が変わり、それぞれが操作するサイドバーのタブと一致するようになりました。「VRChat Avatar Tools」は **CATS**（CATS のサイドバーのタブと一致）に、「Task Board & Sidebar」は **Rig Builder**（Rig Builder のサイドバーのタブと一致）になりました。取り除かれたツールはありません。変わったのは、編集 > プリファレンス > アドオン > BoneCraft にあるオン / オフのラベルだけです。

**7.1.1：** BoneCraft に CATS のツールが入りました。VRChat のアバターをきれいにし、最適化し、すべて設定するために作られた、モデルの準備のツール一式です。CATS は専用のサイドバーのタブにあり、毎回正しい順番で操作を進めるよう案内するパイプラインの仕組みを使います。
