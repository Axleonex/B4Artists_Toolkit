# 新機能

[← 目次](index.md)

最新のものから順に。

## 9.1.2（2026年10月）

- **シーン プロパティ スイッチ:** [環境設定] > [タブ] に新しいシーン プロパティ行が追加されました。その表示ボタン (オンの間は青色) は、アドオンを無効にすることなく、プロパティ > シーン タブの BoneCraft のすべてのセクション (リグ ビルダー、メカニズム、CATS 、アバター ツール、VRChat ツール、インポート/エクスポート) を表示または非表示にします。それが開始され、ビューポート タブとアーマチュア タブはそのままになります。 [物がどこにあるのか](01-start.md#各機能の場所) を参照してください。

## 9.1.1（2026年10月）

- **より明確なアイコン:** 各アイコンはどこでも同じことを意味するようになりました。約 60 個のボタンには、より適切な Bforartists アイコンが追加され (たとえば、「すべての変換を適用」、「間引き」、「名前の正規化」、「変換」、「マージ」、「分離」、「ブレンド ポーズ」、「リップシンク」)、ボタンにはすべてのパネルで同じアイコンが表示されます。
- **落ち着いたパネル:** 見出しと固定テキストにはトピック アイコンが表示されなくなりました。状態を報告するヒントには、情報、警告、またはチェックのアイコンが表示されます。
- **読みやすいアイコン グリッド:** ポーズとウェイト ツールのシェルフ タブのすべてのボタンに独自のアイコンがあるため、狭いシェルフでも読みやすくなります。

## 9.1.0（2026年10月）

- **Bforartists が独自に配置するツール:** [追加] → [アーマチュア、ポーズ、ウェイト、オブジェクト] メニューの BoneCraft エントリ、および Bforartists の [ポーズ] および [ウェイト] ツール シェルフ タブのボタンの BoneCraft パネル。
- **最初に動作し、その後調整します。** クイック リグ、フィット ドロップ リグ、ウェイト ツール、リボン、スプライン IK 、デルタ マッシュ、および CATS ボーン ツールは、最後に使用した値で同時に実行されます。後で [最後の操作を調整] パネルで調整します。 「よろしいですか」というポップアップが減りました。
- **最初にアクション、折りたたまれたオプション:** いくつかのパネルには最初にボタンが表示され、オプションの設定はその下に折りたたまれて表示されます。必要な入力は、Fix Model のクリーンアップ スイッチと同様に、アクションの前に残ります。設定は設定と同じように見えます (チェックボックス、ボタンはありません)、パネル ヘッダーにはアイコンがありません。
- **ジェスチャ ツール:** リグ マーカーの配置 (メッシュをクリックして自動リグ ウィザードの次のマーカーを配置) とビルド メカニズム (パーツをクリックしてジョイントまたはリンクを開始) はビューポート ツール バーにあります。
- **アバター セクション:** アバター ツールには、ヒューマノイド マッピング、ヘア、口形素、およびエクスポートが含まれます。別の VRChat ツール セクションでは、パフォーマンス、クロージング、およびネーミング ユーティリティがグループ化されています。ガイドでは、これらの現在のパネル名が使用されます。
- **ツールヒント:** すべての演算子とすべてのオプションが説明されています。
- **非表示ではなく表示します:** セクションは表示されたままになり、リグがなくなったときに何を選択するかを示します。自動リグ ウィザードはリグ ビルダーで最初に表示され、シェルフは読みやすい幅から始まります。
- **Fixes:** スプラインの生成 IK が再び機能します。 [影響を追加] では、選択したボーンが使用されます。口形素のプレビューではそのセットが使用されます。

## 9.0.0（2026年10月）

- **メカニズム:** BoneCraft タブ (および [プロパティ シーン] タブ) の新しいセクション。プロップとマシンをリグします: ヒンジ、スライド、テレスコープ、ピストン、ギア リンク、フォロー、シーケンス。ガイド付きの手順で構築され、テストでチェックされます。 BoneCraft は手動編集を上書きしません。それを保持するために**Keep mine** を選択するか、再構築するために**Restore** を選択します。 [メカニズム](07-mechanisms.md) を参照してください。
- **サンプル ファイル:** `examples/crescent-rose/` はメカニズム (鎌、ライフル、コンパクト フォーム) を備えた Crescent Rose を保持し、マニュアルの [第12章](12-crescent-rose.md) はそれを段階的に構築します。
- **タブの側面:** 各ビューポート タブは、左側のツール シェルフまたは右側のサイドバーに配置できます ([設定] → [タブ] → [左/右])。 BoneCraft と Rig Builder は左側から始まり、CATS は右側から始まります。
- **リグ ビルダー:** 常にプロパティ シーン タブに表示され、さらに狭いツール シェルフ用のコンパクトなレイアウトを備えた独自のビューポート タブが表示されます。 Basic Humanoid リグは、BoneCraft Rigs アセット ライブラリに同梱されています。 Fit Dropped Rig は、アセット シェルフからドロップされたリグに適合します。
- **CATS タブ:** インポート/エクスポートは CATS タブに移動しました。 CATS 、VRChat およびインポート/エクスポートも常に [シーン] タブにあります。
- **ヘルパーを表示:** 1 つの設定で、BoneCraft の教育テキストを表示または非表示にします。コンパクトモードがそのショートカットです。
- **Rig Validator:** ハイフンを含むボーン名はパスします。ドライバーは、Python を必要とする式についてのみ警告します。メカニズムリグもチェックされます。タスクボードの検証タスクが再び報告されます。
- **名前:** アドオンの名前は BoneCraft です。

## 8.9.x（2026 年 9 月～10 月）

- **8.9.6:** ドレス全体はスカートの骨に沿っています (ヒップのクリッピングはありません)。粘着性のある唇を備えた顎を開いた角の矯正。
- **8.9.5:** IK/FK エルボー スイッチ (ポップ音なし)。対称的な肩の検出。アイマーカーはスナップしなくなりました。コントロール ピッカーには選択内容が表示されます。口角が丸くなる。太もも上のドレスの補正。リラックスしたリターゲット鎖骨。 T ポーズのエクスポート。
- **8.9.4:** 膝を丸くします (ボリュームを保持する代わりに修正を加えます)。深い曲げの場合はキーに接触します。ショルダーシームブレンド。
- **8.9.3:** 脚に続き、脚によって押される 2 つのセグメントに分かれたスカートの骨。
- **8.9.2:** シェイプ キーで点滅します (蓋は折りたたまれません)。楕円形の口の開口部。
- **8.9.1:** 高密度メッシュでのスキニングが大幅に高速化 (678,000 頂点: 232 秒から 57 秒)。静かに失敗するのではなく、軽量のプロキシ メッシュを介してボーン ヒートを実行します。
- **8.9.0:** ジョイント修正形状キー;顔のコントロール（目の照準、まばたき、リップフォロー）;関節で曲がる衣服。
- また、8.9 では、骨ウェイトの自動再計算と、より明確なアトラス選択が可能になりました。

## 8.7–8.8（2026 年 9 月）

- **8.8.0:** リターゲット パネルは Blender 5 ホストで動作します。手の形状から配置された指のマーカー。 IK 肌まで伸びる。ボリュームを保持するオプション。デルタマッシュバインドの修正。
- **8.7.0:** 統合されたコントロール リグ。手足を追跡した関節の検出。方向に一致したリターゲティング。骨をねじる。

## 8.5–8.6（2026 年 7 月）

- **8.6.1–8.6.3:** マテリアル アトラス: ベイク後のタイル診断。 MToon の透明度は実際のテクスチャ アルファに対してチェックされ、アトラス処理中に保持されます。混合材料のより良い分割。
- **8.5.5–8.5.10:** VRM / MToon マテリアル: アルファ モードが尊重され、アルファは Blender 5 ホストで動作し、エミッションのブローアウトなし、マゼンタの診断および安全なアトラス名。
- **8.5.4:** ヒューマノイド マッピングは正しく読み取られます。ネーミング準備ガイダンス。
- **8.5.2–8.5.3:** VRoid ダウンロード (.zip) をインポートします。 VRoid プロジェクト引き継ぎカード。
- **8.5.1:** ブレンドシェイプを維持する FBX エクスポート。

## それ以前のバージョン

**8.5.0:** Smart Combine は、ベイク処理後にデフォルトで `atlas_uv` をエクスポート UV0 にするようになりました。詳細設定で**Keep Source UV Maps** が有効になっていない限り、プレアトラス ソース UV マップは、生成されたアトラス メッシュから削除されます。 CATS / マテリアル コンバイナー / UVToolkit 派生コントロールは、オープン Blender ビルドと共有されるようになりました。 B4Artists の独占権は、プロダクション リギング、コントロール、リターゲット/エクスポート、および B4Artists 専用リリース システムに残ります。

8.5.0 では、エクスポートと検証のワークフローも更新されます。 VRChat 、VRM 、MMD 、および Unreal エクスポートでは、Blender のファイル ブラウザーのデフォルトのみに依存するのではなく、BoneCraft パネルでフォルダーとファイル名のコントロールが公開されるようになりました。 VRChat /Unity および Unreal FBX エクスポートは、マテリアルのインポートを容易にするためにデフォルトで **Embed Textures** に設定されますが、VRChat エクスポートでは、**Helper Meshes** が有効になっていない限り、ヘルパー/コントロール シェイプ メッシュが FBX から除外されます。 VRM パネルには、**Lint Now** と**Fix Humanoid Map** が含まれるようになりました。これにより、ボーンの名前を変更せずに、エクスポート前に古いヒューマノイド エイリアス マッピングを修復できます。

**8.4.5:** Smart Combine は、ベイク処理中にソース テクスチャに保存されたプリアトラス UV を強制的にサンプリングし、オリジナルを非表示にする前に生成されたアトラス メッシュを検証し、グレーまたはスクランブルされたローブ/衣類のチャンクを防ぐためにすべてのアトラス フェイスを最終アトラス マテリアル スロットにリセットするようになりました。

**8.4.4:** マテリアル アトラス コンバイナーは、ベイク処理の前に品質パリティ検査コントロールを追加します。シェーダ/マテリアル診断、テクスチャ ロール ラベル、複製/共有ソース マーカー、マテリアルごとのサイズ オーバーライド、パッキング プリセット、オプションのノーマル/エミッション/ラフネス出力ベイク、パスが検証されるまでのメタリック/ORM チャネル パッキングのプリフライト ブロッカーなどです。

**8.4.3:** マテリアル アトラス コンバイナーには、既存のマテリアル アトラス ワークフロー内に選択可能な UV パッキング方法が含まれています。これには、スマート パック、グリッド パック、シード バリエーション、オリエンテッド パック、フィット 0-1 境界、高度なバリエーション、回転ステップが含まれており、UV メソッドの詳細はデバッグ レポートとベイク台帳に記録されます。

**8.4.2:** マテリアル アトラス コンバイナは、ベイク中に生成されたアトラス UV をターゲットにするようになり、コピーされたソース テクスチャ ノードはプレアトラス UV を明示的に読み取ります。これにより、ソース テクスチャとベイク処理されたアトラスが異なる UV マップをサンプリングすることによって引き起こされる破損したローブ/衣類アトラスの結果が修正されます。 8.4.1 から選択可能なマテリアルとテクスチャの行は引き続き使用できます。

**7.1.3 (環境設定ラベルのクリーンアップ):** 2 つのアドオン環境設定トグルの名前が変更され、制御するサイドバー タブと一致するようになりました。 「VRChat アバター ツール」は、**CATS** というラベルになりました (CATS サイドバー タブと一致します)。 「Task Board & Sidebar」には**Rig Builder** というラベルが付けられました (Rig Builder のサイドバー タブと一致します)。ツールは削除されず、[編集] > [環境設定] > [アドオン] > [BoneCraft] のオン/オフ ラベルのみが変更されました。

**7.1.1:** BoneCraft には、CATS ツールが含まれるようになりました。これは、VRChat アバターをクリーン、最適化、完全に構成するために特別に設計されたモデル準備ツールの完全なスイートです。 CATS は独自のサイドバー タブ内に存在し、毎回正しい操作順序でガイドするパイプライン システムを使用します。
