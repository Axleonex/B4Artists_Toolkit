# リグビルダー

[← 目次](index.md)

## 新しいリグを作る

リグビルダーは、キャラクター用の新しいリグを作ります。左のツールシェルフ（**T** キー）の専用の **Rig Builder** タブにあり、**プロパティ** エディターの **シーン** タブにもあります。ツールシェルフの幅が狭いと、短いラベルのコンパクトな表示に切り替わります。 シーンのパネルは Preferences → Tabs → Scene Properties → Show がオンのとき表示されます。ビューポートのタブを隠しても、このパネルは隠れません。

### オートリグウィザード

**できること：** メッシュにマーカーを置く手順を順に案内し、そのマーカーからウェイト付きのリグを作ります。キャラクターを一からリギングする主な方法です。

[ガイド 1](02-guides-a.md#ガイド-1最初のアバターを-vrchat-へ) で手順を順に説明しています。

**手順：** メッシュを選択 → リグの種類 → 体のマーカー → 指のマーカー → 顔のマーカー → 確認 → 生成

**主な操作：**
- **オートリグを開始**、各手順の上下にある **戻る**、**キャンセル**、**次へ**
- メッシュの一覧（メッシュをクリック）と、リグの種類：**Body + Face**（体と顔）、**Body Only**（体のみ）、**Face Only**（顔のみ。既存のアーマチュア用）
- **Detect Markers**（マーカーを検出。Smart Detection の中）— メッシュの手足をたどり、体のマーカーをすべて信頼度付きで配置します。**Accept High**（高信頼度を採用）は確実なものを残し、**Reset Low**（低信頼度をリセット）は疑わしいものを消します
- **メッシュからマーカーを推測** と **精度を推測**（体）、**指マーカーを推測**（指のマーカーは手の形から配置されます）、**顔のマーカーを推測**
- 指の詳細 — 作る指の数。「0 — No Fingers」から「5 — Full Human Hand」まで
- 各マーカーの行：**Place Marker**（マーカーを配置。矢印のアイコン）、**Confirm Marker**（マーカーを確定。チェックマーク）、**Reset Marker**（マーカーをリセット。円形の矢印）。左右のマーカーには **Toggle Symmetry**（対称の切り替え。最初のアイコン）
- **Mirror L to R**（左を右へミラー）と **Mirror R to L**（右を左へミラー）— 確定したマーカーを中心線の反対側へコピーする
- **すべて配置済みを確認** — その手順で置いたマーカーをすべて確定する
- **リグを生成** — 確定したマーカーからリグを作る。その後、最後の手順で **コントロールリグを構築**（下記参照）と **ウィザードを閉じる**

**リグを生成で作られるもの：**
- 選んだ背骨と首の区間数を持つ体のリグと、IK/FK、IK のみ、FK のみの腕と脚（**キネマティクス** のオプション）
- 選んだ数の指のボーン
- **Body + Face** の場合：顔のリグ。**コントロールシェイプを生成** がオンならコントロールの形も付きます
- 選んだ品質のスキンウェイト。高密度のメッシュは軽い代理メッシュを通してウェイトを付けるので、678,000 頂点のキャラクターでも、何も言わずに失敗することなく約 1 分で済みます。

**コントロールリグを構築：** 確認の手順には **Twist Bones**（ツイストボーン）、**Skirt Bones**（スカートボーン）、**Face Controls**（顔のコントロール）、**Joint Correctives**（ジョイント補正）も表示されますが、リグを生成はこれらを適用しません。これらはエンジン用のコントロールリグ（ツイストボーン、脚に付いて動くスカートボーン、視線とまばたきのコントロール、ジョイント補正のシェイプキー）に属します。リグを生成の後、最後の手順に **コントロールリグを構築** が表示され、選んだオプションでそのリグを生成したアーマチュアに作ります。**ウィザードを閉じる** の前にクリックしてください。閉じるとウィザードのオプションがリセットされます。Control Layer パネル（リグツール）は、この方法で作ったリグにだけ表示されます。

**場所：** Rig Builder → オートリグウィザード

### Quick Rig

**できること：** 1 クリックで既製のアーマチュアを追加します。BoneCraft の Basic Humanoid（19 ボーン、Rigify 不要）か、Rigify のメタリグのどれかです。ウィザードより速いですが、キャラクターへの合わせ込みは少なくなります。

**主な操作：**
- Basic Humanoid のボタンと Rigify のメタリグ（Rigify が無効なら先に **Rigifyを有効化**）
- 次のクリックに使うオプション：**アクティブメッシュにリグをフィット**、自動ウェイト、**IK/FKコントローラーを追加**、**初期ポーズ**
- **Tポーズ** と **Aポーズ** — 選択したリグのレストポーズを切り替える
- **アクティブリグコントロールを検査** と **クイックリグを診断（コンソールに出力）** — 作られたものを確認する
- **コントロールリグを生成（アクティブメタリグ）** — Rigify のメタリグがアクティブなとき、その Rigify コントロールリグを生成する

**BoneCraft Rigs アセットライブラリ：** Basic Humanoid はアセットとしても使えます。アセットシェルフからキャラクターの上へドラッグします。ドロップしたリグを選択すると、Quick Rig に「Dropped rig: fit it to a mesh」（ドロップしたリグ：メッシュにフィットしてください）と表示されます。**Mesh**（メッシュ）を選び、フィットとウェイト付けをするかを選んで、**Fit Dropped Rig**（ドロップしたリグをフィット）をクリックします。

**場所：** Rig Builder → Quick Rig

### マネキン

**できること：** リグ付きの簡単な人型を作ります。まだモデルがないときの代役です。プレビュー専用なので、最終的に使う前に自分のメッシュに置き換えてください。

**主な操作：**
- **クイックマネキン** — 標準の比率で 1 体作る
- **マネキンを追加** — 下の設定で 1 体作る
- **再生成** と **削除** — 新しい設定で作り直す、またはリグごと削除する
- **モード**、**体型**、**半径スケール**。詳細設定にはさらに項目があります

**場所：** Rig Builder → マネキン

## ボーンマージ

**できること：** 2 つのアーマチュアを 1 つにまとめます（例：体のリグと、衣装や髪のリグ）。ウェイトはすべて保たれます。

[ガイド 11](03-guides-b.md#ガイド-112-つのリグを-1-つにまとめる) で手順を順に説明しています。

**3 つの段階：**
1. 範囲 — 2 つのアーマチュアを選び、違いを確認する
2. 名前の変更 — 名前の衝突を解決し、新しいボーンに印を付ける
3. マージ — プレビューしてからマージする

**主な操作：**
- **ベース** — 残るアーマチュア。もう一方のアーマチュアはこれにマージされた後、非表示になります
- **Analyze**（解析）— 2 つのスケルトンを比べます。**Acknowledge Scope — Proceed to Rename**（範囲を確認 — 名前の変更へ進む）で段階 2 が開きます
- **Normalize Both Armatures**（両方のアーマチュアを正規化）— 両方のリグの標準のボーンを、1 つの命名規則（Mixamo Prefixed、Mixamo Stripped、またはカスタム）に合わせて名前を変更します
- **Auto-Propose Renames**（名前の変更を自動提案）— マージされる側のリグ独自のボーンに名前を提案します
- **Apply Rename**（名前の変更を適用）— 1 項目の名前を変更します（元に戻す 1 回分）。**Apply Batch Pattern**（一括パターンを適用）はパターン（`{bone}`、`{side}`、`{index}` を使用）で多くの名前を変更します
- **Mark as Unique**（固有として指定）— ボーンをマージせず、新しいボーンとして残します
- **Verify Rename — Proceed to Merge**（名前の変更を確認 — マージへ進む）— 段階 3 を開きます
- **Run Merge Preview**（マージのプレビューを実行）— 何も変えずに、マージで何が起きるかを報告します
- **アーマチュアをマージ** — 両方のアーマチュアをバックアップしてからマージします

**場所：** BoneCraft → Setup Rigging → Bone Merge
