# リグビルダー

[← 目次](index.md)

## 新しいリグを作る

リグ ビルダーはキャラクター用の新しいリグを作成します。これは、左側のツール シェルフ (**Rig Builder** を押す) にある独自の**Rig Builder** タブにあり、[環境設定] → [タブ] → [シーン プロパティ] → [表示] がオンになっている間は、**Properties** エディタの**Scene** タブにあります。狭いツールシェルフでは、短いラベルを備えたコンパクトなレイアウトに切り替わります。 Auto-Rig Wizard が最初にあり、次に Quick Rig と Mannquin が続きます。ウィザードを開始したり、ビューポートの Add → Armature メニューからクイック リグを追加したりすることもできます。

---

### オートリグウィザード

**内容:** メッシュ上にマーカーを配置し、そこからのウェイトを使用して完全なリグを構築するステップバイステップのガイドです。キャラクターを最初からリグする主な方法。

[ガイド 1](02-guides-a.md#ガイド-1最初のアバターを-vrchat-へ) はそれを段階的に説明します。

**手順:** [メッシュ] → [リグ タイプ] → [ボディ マーカー] → [フィンガー マーカー] → [フェイス マーカー] → [レビュー] → [生成] を選択します。

**キーコントロール:**
- **Start Auto-Rig** ウィザードが開きます。**Back** と**Cancel** が一番上にあります。**Next** は、メッシュ、リグ タイプ、マーカーのステップの一番下にあります。レビューでは、次への代わりに**Generate Rig** を使用します。最後のステップでは**Close Wizard** を使用します
- メッシュ リスト (メッシュをクリック)、リグ タイプ: **Body + Face** 、**Body Only** または**Face Only** (既存のアーマチュアの場合)
- **Detect Markers** (スマート検出内) — メッシュ内の手足をトレースし、すべてのボディ マーカーを自信を持って配置します。**Accept High** は確実なものを保持し、**Reset Low** は疑わしいものをクリアします
- **Guess Markers from Mesh** および**Guess Precision** (ボディ)、**Guess Finger Markers** (指のマーカーは手の形状から配置されます)、および**Guess Face Markers**
- 指の詳細 — 「0 — 指なし」から「5 — 完全な人間の手」まで、作成する指の数
- 各マーカーの行: **Place Marker** (矢印アイコン)、**Confirm Marker** (チェック マーク)、および**Reset Marker** (円形矢印)。左右のマーカーの**Toggle Symmetry** (最初のアイコン)
- **Mirror L to R** および**Mirror R to L** — 中心線を越えて確認済みマーカーをコピーします
- **Confirm All Placed** — ステップに配置されたすべてのマーカーを確認します
- **Generate Rig** — 確認されたマーカーからリグを構築します。次に、最後のステップで、**Build Control Rig** (以下を参照) および**Close Wizard**

**Generate Rig が構築するもの:**
- 選択した脊椎と首のセグメント、および IK/FK 、IK のみ、または FK のみの腕と脚を含むボディ リグ (**Kinematics** オプション)
- 選択した指の数に応じた指の骨
- **Body + Face** の場合:**Generate Control Shapes** がオンの場合のコントロール シェイプを含むフェイス リグ
- 選択した品質でのスキン ウェイト。密なメッシュは軽いプロキシ メッシュを通じてウェイト付けされるため、678,000 頂点のキャラクタは何も言わずに失敗するのではなく、約 1 分かかります。

**ビルド コントロール リグ:** レビュー ステップでは、**Twist Bones** 、**Skirt Bones** 、**Face Controls** 、および**Joint Correctives** も表示されます。リグの生成ではそれらは適用されません。これらは、エンジン コントロール リグ (ツイスト ボーン、脚に従うスカート ボーン、目の照準とまばたきのコントロール、ジョイント修正シェイプ キー) に属します。リグを生成した後の最後のステップでは、選択したオプションを使用して、生成されたアーマチュア上にそのリグを構築する**Build Control Rig** が提供されます。閉じるとウィザードのオプションがリセットされるため、**Close Wizard** の前をクリックします。 Control Layer パネル (Rig Tools) は、この方法で構築されたリグにのみ表示されます。

**場所:** リグ ビルダー → 自動リグ ウィザード

**ビューポート ツールを使用して複数のマーカーを配置します。** ウィザードを開始し、ボディ、指、または顔のマーカーのステップに進みます。オブジェクト モードでは、ビューポート ツールバーで [リグ マーカーを配置] をアクティブにします。ツール ヘッダーには、次の未確認マーカーの名前が示され、軸ロックとミラー スイッチが表示されます。ウィザードのメッシュをクリックして配置し、そのマーカーを確認します。対称はウィザードの設定に従います。マーカーごとの [配置] ボタンは引き続き機能します。ツールにステップが完了したことが表示されたら、ウィザードで**Next** を押します。他の場所をクリックしてもマーカーは配置されません。

### Quick Rig

**機能:** ワンクリックで既製のアーマチュアを追加します: BoneCraft の Basic Humanoid (ボーン 19 個、Rigify は必要ありません)、または Rigify のメタリグの 1 つです。ウィザードよりも高速で、カスタマイズ性は低くなります。

**キーコントロール:**
- Basic Humanoid ボタン、および Rigify メタリグ (Rigify がオフの場合は、最初に **Enable Rigify** )
- リグ ボタンをクリックしてすぐに追加し、最後の操作の調整でメッシュへのフィッティング、自動ウェイト、**Add IK/FK Controllers** および**Initial Pose** を調整します。
- **T-Pose** および**A-Pose** — 選択したリグのレスト ポーズを切り替えます
- **Diagnose Quick Rig (print to console)** のトラブルシューティングを展開します。非メタリグ アーマチュアがアクティブな場合は、**Inspect Active Rig Controls** も表示されます。
- Rigify メタリグがアクティブな場合、トラブルシューティングでは、Inspect Active Rig Controls ではなく **Generate Control Rig (active metarig)** が表示されます。 Rigify コントロール リグを生成します

**BoneCraft Rigs アセット ライブラリ:** Basic Humanoid もアセットです。それをアセット シェルフからキャラクター上にドラッグします。ドロップされたリグが選択された状態で、クイック リグに「ドロップされたリグ: メッシュに合わせる」と表示されます。**Mesh** を選択し、**Fit Dropped Rig** をクリックします。その直後に、最後の操作の調整で**Fit Rig to Mesh** および**Parent + Auto-Weight Mesh** を使用して、フィッティングとウェイト付けを選択します。新しい操作では、デフォルトでフィッティングがオンになり、自動ウェイトがオフになります。

**場所:** Rig Builder → Quick Rig; 「Add」→「Armature」→「Quick Rig」で既製のリグも追加されます

### マネキン

**機能:** 既存のリグの周囲にプレビュー メッシュを構築し、完成したキャラクター メッシュがなくてもその変形を検査できるようにします。まず、アーマチュア、またはその親であるメッシュを選択します。リグがまだない場合は、Quick Rig でリグを追加します。マネキンはプレビューのみです。最終的に使用する前に独自のメッシュに置き換えてください。

**キーコントロール:**
- **Quick Mannequin** — 固定デフォルトでプレビューを構築し、このリグの以前のマネキンを置き換えます
- **Add Mannequin** — シーン設定を使用してプレビューを構築します。デフォルトで既存のマネキンを置き換えます。 「既存を置換」はクリック後の「最後の操作を調整」にあります
- **Regenerate** — 保存された設定を使用して既存のプレビューを再構築します
- **Remove** — マネキン メッシュを削除し、アーマチュアを保持します
- **Mode** 、**Body Type** 、密度、**Radius Scale** のボタンの下にあるオプションを展開します。 [オプション] 内の [詳細設定] には、領域スケールと出力設定が保持されます。変更したシーン設定を使用するには、もう一度**Add Mannequin** をクリックします。

**どこで見つけられますか:** リグビルダー → マネキン

次の 3 つの部分を順番に実行します: [A — シンプルヒューマンからマネキンへ](#パート-a-シンプルヒューマンからマネキンへ) 、[B — Auto-Rig によるリグレス マネキン](#パート-b-auto-rig-によるリグレス-マネキン) 、および [C — ウェイトをテストし、IK/FK を使用します。](#パート-c-ウェイトをテストしikfk-を使用する)。番号付きの各ステップには実際のインターフェイスのスクリーンショットが含まれています。赤い数字はキャプションと一致します。スクリーンショットは、`Bforartists 5.2.0` の **BoneCraft 9.1.2 リリース** でキャプチャされました。 Blender のパネル配置とショートカットは異なる場合があります。指定されたコマンドは参照です。

この演習では、リギングを学習するための簡単なカプセル プレビューを作成します。頭、手、胴体はプレースホルダーであり、完成したキャラクター モデルではありません。新しいファイルから始めます。保存された 2 つのチェックポイントを保持しておくと、元のメタリグを失うことなく変換を繰り返すことができます。

リポジトリには、`examples/mannequin/` の両方のチェックポイントが含まれています。`SimpleHuman_Mannequin.blend` は中立的なパート A の結果であり、`Mannequin_AutoRig.blend` は、ウェイトが修正された、完了したポーズ済みのパート C の例です。

### パート A: シンプルヒューマンからマネキンへ

#### A1. Rigify を有効にする

新しいシーンから始めます。 **Scene Properties → Rig Builder → Quick Rig** を開きます。 Rigify プリセットが使用できない場合は、**Enable Rigify** をクリックします。このチュートリアルでは、Rigify `Simple Human` メタリグを使用します。**BoneCraft Basic Humanoid (19 bones)** は別のプリセットです。

![A1: Rigify を有効にする](../images/rig-builder/en/a01-enable-rigify.png)

*1 — シーンのプロパティ。 2 — Rigify を有効にします。*

#### A2.シンプルヒューマンを追加

「クイック リグ」の下の「`Simple Human` 」をクリックします。結果は編集可能なメタリグですが、まだメッシュではありません。このリリースには 29 個のボーンがあります。

![A2: シンプルヒューマンを追加](../images/rig-builder/en/a02-simple-human.png)

*1 — シンプルヒューマンのプリセット*

#### A3.メタリグを検査する

ポインタをビューポートに移動し、正面正射投影の場合は `Numpad 1` を押します。スケルトン全体が表示されていることを確認します。マウス ホイールを使用して枠を設定します。新しいメタリグはポーズ モードで開始される場合があります。

![A3: メタリグを検査する](../images/rig-builder/en/a03-metarig.png)

※1 - 正面図。 2 — 単純な人間の骨格。*

#### A4.オブジェクトモードに戻る

ビューポート モードのドロップダウンを使用して、**Object Mode** を選択します。 `SimpleHumanArmature` を選択したままにします。レスト ポーズを変更したりマネキンを生成したりする前に、オブジェクト モードを選択してください。

![A4: オブジェクトモードに戻ります](../images/rig-builder/en/a04-object-mode.png)

*1 — モードのドロップダウン。 2 — オブジェクト モード。*

#### A5. T ポーズを使用する

クイック リグで、**T-Pose** をクリックします。腕は水平に伸びます。カスタム ボディの場合は、プレビューを生成する前に編集モードでメタリグをフィットさせます。このエクササイズでは、左右の関節を対称に保ちます。

![A5: Tポーズを使用する](../images/rig-builder/en/a05-t-pose.png)

*1 — T-Pose コマンド。*

#### A6.マネキンを生成する

**Mannequin → Options** を展開します。 `Mode: Universal` 、`Body Type: Neutral` 、**Medium** 、および `Radius Scale: 1.00` を設定します。 [詳細設定] で、領域スケールを 1.00 に保ち、`Joined (non-manifold)` 、**フラット カラー**を選択し、**Joint Smoothing** を有効にします。統合ボリュームはオフのままにしておきます。これらのオプションを設定した後、「**Add Mannequin** 」をクリックします。スクリーンショットは、結果として得られるカプセル メッシュを示しています。現在のオプションには [追加] を使用します。再生成では、保存されたマネキン設定を再利用します。

![A6: マネキンを生成する](../images/rig-builder/en/a06-final-settings.png)

*1 — マネキンを追加します。 2 — ユニバーサルおよび本体の設定。 3 — 結合された出力と平滑化。*

#### A7.骨のポーズを試してみる

アーマチュアを選択し、**Pose Mode** に切り替えて、左前腕ボーンをクリックします (キャラクターの左側は正面図で右側にあります)。回転ツールを使用して少し回転させます。付属のマネキンが続きます。これはメタリグの加重プレビューです。パート C で使用されるアニメーター コントロールはまだありません。

![A7: 骨のポーズを試してみる](../images/rig-builder/en/a07-select-forearm.png)

*1 — ポーズモード。 2 — 選択した前腕とその変換ギズモ。*

#### A8.プレビューを復元して保存する

ビューポート内にポインタを置き、すべてのポーズ ボーンを選択します。 **F3** を押して、`Clear Pose Transforms` を検索し、**すべて** を選択します。マネキンが T ポーズに戻ることを確認します。**File → Save As** を使用し、ファイルに `SimpleHuman_Mannequin.blend` という名前を付けます。続行する前に、このチェックポイントを保持してください。

![A8: プレビューを復元して保存する](../images/rig-builder/en/a09-clear-pose.png)

*1 — ポーズ変換検索をクリアします。 2 — 選択したポーズ ボーンをすべてリセットします。*

### パート B: Auto-Rig によるリグレス マネキン

#### B1.マネキンメッシュを選択してください

パート A のニュートラル チェックポイントから続行します。**Object Mode** に切り替えて、アウトライナーで `SimpleHumanArmature_Mannequin` を選択します。ウィザードを実行する前に、そのリグを意図的に削除します。パート A を保存するには、結果を別のファイル名で保存します。

![B1: マネキンメッシュを選択](../images/rig-builder/en/b01-select-mesh.png)

*1 — アーマチュアではなくメッシュを選択します。*

#### B2.プレビューをメッシュにベイク処理する

マネキンのみを選択した状態で **F3** を押し、`Convert Mesh` を検索して実行します。これにより、表示されるニュートラル ジオメトリが維持され、アーマチュア モディファイアが削除されます。復元された T ポーズのマネキンでこれを行います。

![B2: プレビューをメッシュにベイク処理します](../images/rig-builder/en/b02-convert-mesh.png)

*1 — メッシュ変換コマンド。*

#### B3.親をクリアする

**Alt+P** を押して、`Clear and Keep Transformation` を選択します。これにより、古いメタリグを移動せずにメッシュが切り離されます。

![B3: 親をクリア](../images/rig-builder/en/b03-clear-parent.png)

*1 — 変換をクリアして維持します。*

#### B4.古いウェイトを取り外します

**Object Data Properties → Vertex Groups** を開きます。リストのドロップダウン メニューで `Delete All Groups` を選択します。これらのグループは古いメタリグに属します。ウィザードは新しいものを作成します。このアクションは、この使い捨てトレーニング メッシュに対するものです。

![B4: 古いウェイトを取り外します](../images/rig-builder/en/b04-clear-groups.png)

*1 — [頂点グループ] メニュー。 2 - すべてのグループを削除します。*

#### B5.不正なチェックポイントを検証する

アウトライナーの目のアイコンを使用して、古い `SimpleHumanArmature` を非表示にします。マネキンが表示されたままであること、[モディファイヤ]パネルにアーマチュア モディファイヤがないこと、および[頂点グループ]リストが空であることを確認します。これはリグレス マネキン入力です。 BoneCraft 9.1.2 はアーマチュアからマネキンを生成します。このプレビューを切り離すことが、リグレス トレーニング メッシュへのルートです。

![B5:不正なチェックポイントを検証する](../images/rig-builder/en/b05-rigless-check.png)

*1 — 古いメタリグを非表示にします。 2 — 空のモディファイア スタック。*

#### B6.ビューポートの「リグビルダー」タブを有効にする

**Edit → Preferences → Add-ons → BoneCraft → Tabs** を開きます。**Rig Builder** を有効にし、**Left** を選択します。環境設定を閉じ、ポインタをビューポートの上に置き、左側のツール シェルフが非表示の場合は**T** を押します。マーカーの配置にはこのビューポート タブを使用します。テストされた 9.1.2 ホストでは、シーン プロパティからマーカーの配置を開始してもビューポートのクリックが受け入れられませんでした。

![B6: ビューポートの「リグビルダー」タブを有効にする](../images/rig-builder/en/b10a-enable-rig-builder-tab.png)

*1 — リグビルダーを有効にします。 2 — 左側のツール シェルフの配置*

#### B7.オートリグを開始する

リグレス マネキンを選択した状態で、「**Start Auto-Rig** 」をクリックします。スクリーンショットは、同等の「シーン プロパティ」ボタンを示しています。同じコマンドが、前の手順で有効にしたビューポートの [リグ ビルダー] タブの上部にあります。

![B7: オートリグの開始](../images/rig-builder/en/b06-start-wizard.png)

*1 — オートリグを開始します。*

#### B8.入力メッシュを選択します

`Select Mesh` で、マネキンを選択し、選択されたメッシュのチェックを確認し、**Next** をクリックします。ウィジェットや別のプレビュー オブジェクトを選択しないでください。

![B8: 入力メッシュを選択します](../images/rig-builder/en/b07-select-input.png)

*1 — マネキン入力。 2 — 次へ*

#### B9.両方の方法でボディ リグを選択してください

**Body Only** および `Kinematics: IK + FK` を選択します。**Generate Control Shapes** を有効のままにしてください。 「**Next** 」をクリックします。このカプセル マネキンには顔のトポロジーがないため、Body + Face は不要です。

![B9: 両方の方法でボディ リグを選択する](../images/rig-builder/en/b08-body-ikfk.png)

※1：本体のみ。 2 — IK + FK。 3 — 次へ*

#### B10.初期ボディマーカーの検出

[ボディ マーカー] で、[スマート検出] の下の [**Detect Markers**] をクリックします。その推測を出発点として扱います。この対称マネキンに対して**Mirror Symmetry** を有効にしておきます。すべての推測を確認せずに受け入れないでください。

![B10: 初期ボディマーカーの検出](../images/rig-builder/en/b09-detect-markers.png)

*1 — マーカーを検出します。 2 — ミラー対称。*

#### B11.検出された位置を確認する

頭頂部、首の付け根、骨盤、手首、足首を目に見えるメッシュと照らし合わせてチェックしてください。このセグメント化されたプレビューでは、信頼性の低い推測がいくつか生成されます。生成する前に、主要なランドマークとオプションの精度ランドマークの両方を確認して修正します。信頼度ラベルは元の検出を説明します。行の先頭にある緑色のチェックは、現在の配置が確認されていることを示します。

![B11: 検出された位置を確認する](../images/rig-builder/en/b10-review-markers.png)

*1 — 検出信頼性の概要。 2 — ボディマーカー行*

#### B12.手首をメッシュの上に置きます

ビューポートの **Rig Builder** タブで、手首の左側にある**Place Marker** スポイトをクリックし、ビューポート内の手首のサーフェスをクリックします。すでに確認されているマーカーの場合は、最初にその行をリセットして、その配置ボタンを表示します。正面図では、キャラクターの左手首が画面の右側にあります。

![B12: 手首をメッシュの上に置きます](../images/rig-builder/en/b11-place-wrist.png)

*1 — 手首左置きコントロール。 2 — 手首の表面をクリックします。*

#### B13.鏡面された手首と足首をチェックしてください

両方の手首の行に緑色のチェックが表示され、X 座標が反対になっていることを確認します。 `Ankle Left` の配置を繰り返します。対称供給足首右。各足首をつま先ではなく関節に置きます。サンプルの座標をサイズの異なるキャラクタにコピーするのではなく、メッシュに対する対称性を確認してください。

![B13: 手首と足首の鏡面チェック](../images/rig-builder/en/b12-mirrored-wrist.png)

※1 — 手首ペア確認済み。 2 — メッシュ上にミラーリングされた手首。*

#### B14.肩と肘を整える

「精密マーカー」までスクロールします。リセットして、`Shoulder Left` を上腕ピボットに配置し、`Elbow Left` を肘のギャップに配置します。ミラーリングされたパートナーを確認します。手首を前腕の手側の端に置きます。これらのポイントは腕のチェーンを決定するため、間違ったカプセル上で推測された肩や肘は修正する必要があります。

![B14: 肩と肘を整える](../images/rig-builder/en/b13-arm-precision.png)

*1 — 肩と肘のマーカー行。 2 — 肩。 3 — 肘*

#### B15.腰と膝を整える

`Hip Left` を太ももの上部に配置し、`Knee Left` を太ももとすねの隙間に配置します。対称によって提供される反対側を確認してください。骨盤を腰の間の中心線上に保ちます。

![B15: ヒップと膝を整える](../images/rig-builder/en/b14-leg-precision.png)

*1 — 腰と膝の列。 2 — 股関節表面。 3 — 膝の隙間*

#### B16.横から深さとつま先をチェック

ビューポート上にポインターを置き、`Numpad 3` を押します。正面からだけでなく、右正投影でもランドマークを確認してください。 `Toe Left` を足の前部近くに配置します。ミラーリングされたパートナーを確認します。マーカーは、正面から見ると正しく見えても、体の前方または後方にありすぎる場合があります。

![B16：深さとつま先を横からチェック](../images/rig-builder/en/b15-side-depth.png)

*1 — 右正書法。 2 — つま先マーカー行。 3 — 足の表面。*

#### B17.かかとを置きます

間違って推測されたかかとをリセットし、側面図で `Heel Left` を足の後ろ近くに配置します。かかとが右であることを確認します。これらのマーカーはオプションですが、両方をゼロのままにすると、テストされたリリースで近接警告が生成されました。それらを足に置くことで、その警告は解除されました。

![B17:かかとを置く](../images/rig-builder/en/b16-place-heels.png)

※1 — ヒールペア確認済み。 2 — かかとの位置*

#### B18.確認して続行

頭頂部、首の付け根、骨盤、およびすべてのペアのランドマークを確認します。 [**Confirm All Placed**]、[**Next**] の順にクリックします。名前の横にある緑色のチェックは確認状態です。元の REVIEW/ADJUST 信頼ラベルは 9.1.2 でも表示されたままになる場合があります。

![B18: 確認して続行](../images/rig-builder/en/b17-confirm-markers.png)

*1 — すべての配置を確認します。 2 — 次へ*

#### B19.このメッシュでは指をスキップします

`0 — No Fingers` を選択し、**Next** をクリックします。このマネキンにはハンド カプセルがありますが、指の形状はありません。実際のハンド メッシュ上で、適切なカウントを選択し、代わりにその指マーカーを配置します。

![B19: このメッシュでは指をスキップします](../images/rig-builder/en/b18-no-fingers.png)

*1 — 指なし。 2 — 次へ*

#### B20。レビューと生成

続行する前に **All checks passed** が必要です。この演習では、**IK + FK** 、コントロール シェイプ、`Spine Segments: 3` 、`Neck Segments: 1` 、`No Fingers` 、および**Game Ready** を使用します。ツイスト ボーン、スカート ボーン、ボリューム保持、およびジョイント修正をオフにします。 「**Generate Rig** 」をクリックします。これらの設定は、この単純なトレーニング用マネキンを説明するものであり、普遍的な輸出規定ではありません。

![B20: レビューと生成](../images/rig-builder/en/b19-review-generate.png)

*1 — マーカーチェック。 2 — 生成設定。 3 — リグの生成*

#### B21.アニメーター コントロールを構築する

生成後、**Build Control Rig** をクリックします。 Generate Rig はボディ リグとウェイトを提供します。 Build Control Rig は、以下で使用するコントロール レイヤを追加します。 [クイック マネキン] を再度クリックしないでください。完了パネルに一般的なマネキンのオファーが表示されている場合でも、入力メッシュはすでに存在しています。

![B21: アニメーター コントロールを構築する](../images/rig-builder/en/b20-build-controls.png)

*1 — ビルド コントロール リグ*

#### B22.ウィザードを終了する

コントロール リグの完了メッセージが表示されるまで待ち、**Close Wizard** をクリックします。新しいアーマチュアがアウトライナーに表示されます。古い Simple Human メタリグは隠しておきます。新しいリグはメッシュを変形する必要があります。ビューポートでボーンを確認するだけでは十分な検証とはなりません。

![B22: ウィザードを終了する](../images/rig-builder/en/b21-close-wizard.png)

### パート C: ウェイトをテストし、IK/FK を使用する

テストされたリリースでは、生成されたアーマチュアのオブジェクト名は次のようになります (アウトライナーとウェイト ツールで使用します)。

```text
BoneForge_Rig
```

`FK (Forward Kinematics)` **FK（順運動学）**は階層に沿って回転を伝えます。上腕、前腕、手の順に回転させます。大きなスイングや自由に動く手足に適しています。`IK (Inverse Kinematics)`**IK（逆運動学）**は末端の目標位置から姿勢を求めます。手首や足首のターゲットを動かすと、ソルバーがボーンのチェーンを曲げてその位置に到達させます。接地した足や、指定した面に触れる手に適しています。

|タスク|使用するコントロール|何を見るべきか|
|---|---|---|
|腕を振る|FK 肩と肘のコントロール|子コントロールは親に従います|
|手を置く|IK リストターゲット|肩と肘はターゲットに向かって解決します|
|足を植える|IK その脚の足首ターゲット|到達可能なターゲットを配置したまま体を移動します|
|肘または膝を曲げることを目指す|IK 極制御|ポールは曲げ方向を設定します。手首/足首のターゲットではありません|
|変更方法|四肢の IK/FK ボタン|アニメーションをキー入力する前にスナップされたポーズを確認する|

以下の演習では、両方のモードで片腕を比較します。各手足には独自のスイッチがあります。 `Bake IK / Bake FK` はアニメーション変換ツールです。単一ポーズのスイッチは、アニメーションのベイク処理やキーイングに代わるものではありません。他のコントロールについては、[制御層](05-rig-tools.md#control-layerコントロールレイヤーikfk) を参照してください。

#### C1.コントロールレイヤーを開く

**生成されたアーマチュア**を選択し、**Pose Mode** を選択して、**BoneCraft → Review → Control Layer** を開きます。腕と脚ごとに個別の IK/FK スイッチがあります。**arm-L → FK** から始めます。左右はキャラクターを表すため、正面から見るとアーム L が右側に表示されます。

![C1: コントロール層を開く](../images/rig-builder/en/c02-control-layer.png)

*1 — ポーズモード。 2 — 制御層と arm-L スイッチ。*

#### C2.アニメーター コントロールを表示する

アーマチュアの **Object Data Properties → Bone Collections** を開きます。 `Controls` および**FK** のソロ スターを使用して、コントロール シェイプを分離します。コントロールがメッシュで隠れている場合は、ビューポート表示で**In Front** を有効にします。後でターゲットを使用するときに**IK** を含めます。このネイティブ コレクション リストは、BoneCraft コレクション パネルがこのホストでの描画に失敗した場合にも機能します。

![C2: アニメーター コントロールを表示する](../images/rig-builder/en/c03-visible-controls.png)

*1 — コントロールおよび FK Solo スター。 2 — 前。*

#### C3.前腕 FK コントロールを選択します

正面ビューで、キャラクターの左肘にある円形のコントロールをクリックします。ビューポート選択名が **forearm.fk-L** であることを確認します。 FK 前腕コントロールは肘を中心に回転します。ショルダー コントロールを選択すると、代わりに上腕とその子が回転します。

![C3: 前腕 FK コントロールを選択します](../images/rig-builder/en/c04-select-fk.png)

*1 — 選択された forarm.fk-L コントロール。 2 — FK は arm-L に対してアクティブです。*

#### C4.回転させて変形を検査する

選択した FK コントロールをグローバル **Y** を中心に回転させます (この正面図の例では約 `−45°` )。回転ツールを使用します。表示されている Bforartists キーマップで、**Ctrl+E**、**Y** 、**-45** と入力すると、**Enter** がその回転を実行します。 Blender のデフォルトの回転ショートカットは**R** です。スクリーンショットは、初期のウェイトの問題を意図的に示しています。つまり、上腕のカプセルが前腕とともに傾いています。これを完成したリグとして受け入れないでください。

![C4: 回転させて変形を検査する](../images/rig-builder/en/c05-fk-weight-check.png)

*1 — FK テスト中の上腕の動きが正しくありません。*

#### C5.マネキンのウェイトを再計算する

上記の姿勢テストが失敗した場合は、**Object Mode** に切り替え、メッシュを選択し、**BoneCraft → Skin → Weight Tools → Automatic Bone Weight Recalculation** を開きます。マネキンの再ウェイトするメッシュを設定し、**生成されたアーマチュア**に既存のアーマチュアを設定します。**Body** 、`Body Method: Bone Heat` 、`New Weight Strength: 1.00` 、`Smooth Passes: 0` 、`Max Bones per Vertex: 0` 、および `Minimum Weight: 0.001` を選択します。**Keep Weight Backup** をオンのままにして、**Automatic Bone Weight Recalculation** を実行します。これにより、テストされたリリースのセグメント化されたプレビューが修復されました。

![C5: マネキンのウェイトを再計算する](../images/rig-builder/en/b23-recalculate-weights.png)

*1 — メッシュとアーマチュア。 2 — 骨の熱。 3 — 置き換え設定とバックアップ。 4 — 再計算します。*

#### C6.修復された FK 曲げを確認します。

生成されたアーマチュアを再度選択し、**Pose Mode** に戻ります。上腕は肩から肘まで水平に保たれ、前腕は肘から上がります。非表示の `WEIGHTS_BACKUP_…` オブジェクトは古いウェイトを保持します。アニメーションで独自のキャラクターを使用する前に、他の手足もテストしてください。生成されたスケルトンだけでは、スキニングが正しいことを証明することはできません。

![C6: 修復された FK 曲げを確認します。](../images/rig-builder/en/c05-fk-result.png)

※1 — アッパーアームは固定されます。 2 — 前腕は肘のところで曲がります。*

#### C7.同じアームを IK に切り替えます

**arm-L → IK** をクリックします。スイッチはターゲットを現在のポーズにスナップするため、腕は上げたポーズのままでなければなりません。ターゲットが非表示の場合は、**IK** を表示される Solo コレクションに追加します。スイッチングはチェーンを駆動するコントロールを変更します。新しいアニメーションが録画されたという意味ではありません。

![C7: 同じアームを IK に切り替えます](../images/rig-builder/en/c06-switch-ik.png)

*1 — arm-L IK スイッチ。 2 — 切り替え時にポーズが保持されます。*

#### C8.手首の IK ターゲットを選択してください

手首のコントロールをクリックし、選択名 **forearm.ik-L** を確認します。前腕という名前にもかかわらず、これはアーム チェーンのエンドポイント ターゲットです。このターゲットを移動して手を配置します。ソルバーはそれに到達するために肩と肘の角度を変更します。

![C8: 手首の IK ターゲットを選択します](../images/rig-builder/en/c07-select-ik.png)

*1 — 選択されたリストターゲット。 2 — 選択名。*

#### C9.ターゲットを移動して比較する

手首のターゲットをグローバル **X** に沿ってわずかに内側に移動します。この例では、`−0.15 m` は明らかに異なる曲げを作成します。表示されたキーマップで**Ctrl+W**、**X** を使用し、`-0.15` と入力してから**Enter** を入力するか、移動ツールの X 矢印をドラッグします。 Blender のデフォルトの移動ショートカットは**G** です。アーム全体を FK の例と比較します。エンドポイントが先行し、両方のアーム セグメントが続きます。ターゲットを腕の届く範囲に置いてください。

![C9: ターゲットを移動して比較する](../images/rig-builder/en/c08-move-ik.png)

*1 — 手首の終点。 2 — チェーンが応答します。 3 — X の動きの例。*

#### C10.元に戻って例を保存します

もう一度 **arm-L → FK** をクリックします。 FK コントロールは、現在の IK ポーズにスナップします。メッシュがジャンプしないことを確認し、**File → Save As** を使用して `Mannequin_AutoRig.blend` を保存します。スクリーンショットは、FK がアクティブな状態で保存された例を示しています。ニュートラルなトレーニング コピーの場合は、4 つの手足すべてを FK に保持し、表示されているすべてのポーズ コントロールを選択し、パート A と同様に**F3 → Clear Pose Transforms → All** を使用します。それを別名で保存します。

![C10: 元に戻って例を保存します](../images/rig-builder/en/c10-save-complete.png)

*1 — FK が再びアクティブになります。 2 — ポーズが保存されます。 3 — 保存されたファイル名*

**完了チェック:** 元のメタリグ プレビューを保存し、リグレス マネキンをデタッチし、新しいボディ リグとそのコントロールを生成し、プレビュー ウェイトを修正し、FK 回転と IK ターゲット移動を比較しました。保存したリグは学習用のサンプルとして保存してください。プレビューを制作に適したキャラクター ジオメトリに置き換えます。

## ボーンマージ

**機能:** 2 つのアーマチュアを 1 つに結合します。たとえば、ボディ リグと衣服やヘア リグなどで、すべてのウェイトを維持します。

[ガイド 11](03-guides-b.md#ガイド-112-つのリグを-1-つにまとめる) がそれを段階的に説明します。

**3 つの段階:**
1. スコープ — 2 つのアーマチュアを選択し、それらがどのように異なるかを確認します
2. 名前の変更 — 名前の競合を解決し、新しいボーンにマークを付けます
3. マージ — プレビューしてからマージします

**キーコントロール:**
- **Base** — 留まるアーマチュア。もう一方のアーマチュアはそれにマージされて非表示になります
- **Analyze** — 2 つのスケルトンを比較します。**Acknowledge Scope — Proceed to Rename** がステージ 2 を開始します
- **Normalize Both Armatures** — 両方のリグの標準ボーンの名前を 1 つの命名標準 (Mixamo Prefixed、Mixamo Stripped、またはカスタム) に変更します。
- **Auto-Propose Renames** — マージするリグ自体のボーンの名前を提案します
- **Apply Rename** — 1 つのエントリの名前を変更します (1 つの元に戻す手順)。**Apply Batch Pattern** は、パターンを使用して多くの名前を変更します (`{bone}` 、`{side}` 、および `{index}` )
- **Mark as Unique** — ボーンをマージせずに新しいボーンとして保持します
- **Verify Rename — Proceed to Merge** — ステージ 3 を開始します
- **Run Merge Preview** — 何も変更せずに、マージによって何が行われるかをレポートします。
- **Merge Armatures** — 両方のアーマチュアをバックアップし、それらをマージします

**場所:** BoneCraft タブ → ボーン マージ
