# リグツール

[← 目次](index.md)

この章では、BoneCraft のリギング、アニメーション、ウェイト ツールについて詳しく説明します。機能をより深く理解したい場合、またはガイドが正確な状況をカバーしていない場合に使用してください。

各エントリには、ツールの機能、いつ使用するか、主なコントロール、およびツールの場所が記載されています。各エントリの「どこにあるか」行には、その使用に必要なモードの名前が付けられています。たとえば、ポーズ モードではリグ コントロール、ウェイト ペイント モードではウェイト ミラーとウェイト トランスファー、オブジェクト モードではデルタ マッシュです。一部のセクションは、ツールを実行できない場合に何を選択するかに関するメッセージとともに表示されたままになります。

9.1 では、多くのツールが一度に実行され、そのオプションが [最後の操作の調整] パネルに表示されます。クリックした直後、別の操作を実行する前に、これらのオプションを変更します。 [ポーズ] → [BoneCraft] および [ウェイト] → [BoneCraft] メニュー、および Bforartists の [ポーズ] および [ウェイト] ツール シェルフ タブの BoneCraft ボタン パネルには、一般的な操作へのショートカットが用意されています。 [はじめに](01-start.md#各機能の場所) には、これらのアクセス ポイントがリストされています。

---

## リグ UI ツール

これらのツールは、アーマチュアの操作の視覚的な側面 (どのボーンが表示されるか、ボーンがどのように構成されているか、および迅速なアクセス) を管理するのに役立ちます。

---

### ボーンコレクション

**機能:** スケルトンのボーン コレクションを行として表示します。コレクションの名前をクリックしてボーンを選択します。目のアイコンで表示または非表示になります。

> ボーン コレクションは、名前付きのボーン グループです。たとえば、「IK Controls」、「Face Bones」、「Deform Bones」などです。コレクションを非表示にすると、ビューポート内のボーンが非表示になるため、リグの一部に集中できます。

**キーコントロール:**
- 各行: アクセント カラー、**Toggle Collection Visibility** (目のアイコン)、コレクションの名前 (ボーンを選択)、**Solo Collection** および**Rename Collection Display** (行のカスタム表示名を設定します)。アイコンのみのボタンにカーソルを合わせると、ツールチップでボタンが識別されます
- **Show All Collections** および**Hide All Collections** (リストの上にある目を開けたアイコンと閉じたアイコン) - すべてを一度に
- セクション — 複数のコレクションを折りたたみ可能なヘッダーの下にグループ化します。

**場所:** BoneCraft タブ → レビュー → コレクション

---

### 表示ブックマーク

**機能:** どのボーン コレクションが表示されているかを保存し、保存されたビューを一度に切り替えることができます。

**使用例:** 表情作業用に顔のボーンのみを含むビューを設定し、「顔のみ」として保存します。次に、ウェイト ペイント用のすべてを表示し、「フル リグ」として保存します。ワンクリックでそれらを切り替えることができます。

**キーコントロール:** 各スロットは 1 行です。
- ブックマークの名前 — クリックして保存されたビューを適用します
- **Save Bookmark** — 現在の可視性をスロットに保存します。アイコンにカーソルを置くとツールチップが表示されます
- カラー見本 — ブックマークを色分けします。
- **Clear Bookmark** および**Remove Bookmark** (アイコンを閉じる) — スロットを空にするか、追加したスロットを削除します
- **Add Bookmark** — スロットを追加します

**デフォルトのブックマーク:** FK アーム、IK ボディ、フェイスのみ、フル リグ

**場所:** BoneCraft タブ → レビュー → コレクション → 可視ブックマーク

---

### ホットキーのクイックパネル

**機能:** カーソルが置かれている場所で、BoneCraft のリグ パネル (コレクションとブックマーク) をポップアップとして開きます。

**使用方法:** 3D ビューポートで**Ctrl+Shift+R** を押します。ポップアップの外側をクリックして閉じます。

**場所:** 3D ビューポートの**Ctrl+Shift+R** ショートカット (独自のパネルはありません)

---

## アニメーションツール

---

### ポーズライブラリ

**機能:** ワンクリックでリグに適用できる名前付きポーズをサムネイルとともに保存します。

**キーコントロール:**
- **Save** — 現在のボーンの位置をビューポートのサムネイルとともに名前付きポーズとして保存します
- **Apply** — 保存されたポーズにボーンをスナップします
- **Blend** — 現在の位置と混合して部分的な強さでポーズを適用します
- **Mirror** — 左から右に反転したポーズを適用します
- **Delete** 、**Rename** 、および**Category** — リストを管理します。**Filter** は 1 つのカテゴリを表示します
- **Export** および**Import** — `.bfpose` ファイルへの保存またはそこからのロード

ブレンドはすぐに適用されます。クリック後の「最後の操作を調整」でブレンドの強さを設定します。

**場所:** BoneCraft タブ → レビュー → ポーズ ライブラリ

---

### Control Picker（コントロールピッカー）

**機能:** リグのコントロールのクリック可能なマップ。シェイプをクリックしてボーンを選択します。ピッカーは選択された内容を強調表示します。

**キーコントロール:**
- **Generate Picker** — リグからレイアウトを構築します
- **Edit Layout** — コントロールを移動、サイズ変更、ラベル変更し (**Move Picker Control** 、**Resize Picker Control** 、および**Relabel Picker Control** は各コントロールの行にアイコンとして表示されます)、それらをグリッドに**Snap** します。**Rebuild Layout** が再度ビルドします
- **Mirror Selection** — ミラーリングされたコントロールを選択します
- **Pop-up Picker** — フローティング ウィンドウでピッカーを開きます。これにも**Add Selection Set** が含まれています

**場所:** BoneCraft タブ → レビュー → コントロール ピッカー

---

### Control Layer（コントロールレイヤー、IK/FK）

図解による実際の比較については、[ウェイトをテストし、IK/FK を使用します。](06-rig-builder.md#パート-c-ウェイトをテストしikfk-を使用する) を参照してください。

**機能:** **Build Control Rig** で作成されたリグの四肢のアニメーター コントロール: 四肢をジャンプさせることなく IK と FK の間で四肢を切り替え、フレーム範囲にわたって一方を他方にベイク処理します。

**キーコントロール:**
- **IK** および**FK** — 四肢を切り替え、新しいコントロールを四肢の位置にスナップして、肘や膝が飛び出ないようにする
- **Bake IK** および**Bake FK** — フレーム範囲のアニメーションを IK または FK に変換します
- **Pole Follow** 、**Pin** 、**Lock-Free** 、および**Global Rig Scale**。保護されたロックを保持します。

**場所:** BoneCraft タブ → レビュー → コントロール レイヤー (**Build Control Rig** によって作成されたリグが選択されています。[リグビルダー](06-rig-builder.md) を参照)

---

### Rigifyツール

**機能:** Rigify コントロール リグを検出し、BoneCraft のコレクション パネル、ブックマーク、プロパティ スライダーを Rigify の標準コントロールに接続します。

> Rigify は、アニメーション対応リグを生成するための Bforartists の組み込みシステムです。 Rigify を使用してリグを構築した場合、これにより、BoneCraft の UI が Rigify の IK/FK コントロールに接続されます。

**キーコントロール:**
- **Auto-Enhance** — 選択した Rigify リグに BoneCraft のパネルを設定します
- **Re-run Enhancement** — ゼロから再構築します
- **Enable Rigify** はクイック リグにあります。**Generate Control Rig (active metarig)** のトラブルシューティングを展開します ([リグビルダー](06-rig-builder.md) を参照)
- Rigify プロパティ — リグの IK/FK 、ストレッチ、親スペース、および頭/首フォロー スライダー

**場所:** BoneCraft タブ → Setup Rigging → Rigify Tools (および Rigify Properties セクション)

---

### リターゲット

**機能:** アニメーションをあるスケルトンから別のスケルトンに移動します。たとえば、モーション キャプチャ クリップをアバターに移動します。ボーンは名前と方向で一致するため、手足の方向は維持されます。鎖骨は緩めに合わせられているため、肩が回転しすぎません。

**キーコントロール:**
- **Import Clip** および**Browse Library** — クリップをロードするか、ライブラリ フォルダーを設定します。クリップの名前をクリックして選択します
- **Auto-Match Bones** (クリップの行のチェック マーク) — ソース ボーンとターゲット ボーンをペアにします (パネルのボーン マッピング リストにペアが表示されます)
- **Preview** および**Stop Preview** — 結果を試してください
- **Apply** — クリップをリグにベイクします

**場所:** BoneCraft タブ → リギングのセットアップ → リターゲット

---

### 補正シェイプキー

**機能:** ボーンが角度に達するとスイッチがオンになるシェイプ キーで、極端なポーズでの挟み込みや潰れを修正します。

**使用例:** キャラクターの肘は完全に曲げられると潰れます。修正された肘をスカルプトして腕のボーンにリンクすると、肘が曲がると自動的に適用されます。

**キーコントロール:**
- 新しい修正 — **Shape Key** 、**Driver Bone** 、回転軸、シェイプが完全にオンになる角度、および徐々にフェードインする方法を選択してから、**Create Corrective**
- 修正のリスト: 修正のシェイプ キー名をクリックして選択します。リストの下の **Edit** および**Delete** は、選択されたものに作用します

編集は修正者の現在値から開始されます。クリック後の「最後の操作を調整」で角度とフォールオフを変更します。

**場所:** BoneCraft タブ → スキン → 修正 (メッシュにはベース シェイプ キーが必要です)

---

### グラフツール

**機能:** キーフレームとカーブのアニメーション調整ツール。

- **Interactive Breakdown** (ブレークダウナー; 3D ビューポートのショートカット**Ctrl+Shift+B**) — 左右にドラッグして、最も近いキーフレーム間の現在のポーズをブレンドします。
- **Apply Delta** (デルタ ムーバー、3D ビューポートのショートカット**Ctrl+Shift+D**) — 選択したボーンを画面空間またはワールド空間の正確なオフセットで微調整します
- **Capture** および**Swap** (バッファ カーブ) — カーブのコピーを保持し、編集内容との間で交換します。
- **Smart Bake** — コンストレイント駆動のアニメーションをキーにベイクし、冗長なキーを削除します (**Tol** でその量を設定します)
- **Euler Filter** — ジンバル ロックによって引き起こされる回転反転を修正します
- 接線ハンドル — 選択したキーのハンドル タイプを設定します: **Auto** 、**Vector** 、**Aligned** 、**Free** 、または**Auto Clamped**

**場所:** BoneCraft タブ → レビュー → グラフ ツール

---

## ウェイトツール

これらのツールは、ボーンが移動したときにメッシュがどのように変形するかを制御します。ウェイトは、メッシュの各部分にどのボーンをどれくらい従うかを指示します。

---

### ボーンウェイトの自動再計算

**機能:** メッシュを変更せずに、既存のリグからメッシュのウェイトを再計算します。高密度のメッシュでは、より軽いプロキシ メッシュを通じて機能するため、サイレントに失敗することはありません。

**キーコントロール:** ターゲットメッシュとアーマチュアを選択し、次にボディモードまたは衣服モードを選択します。ボディは既存のリグからウェイトを計算します。衣服は、正しくウェイト付けされたソース メッシュからそれらを転送します。方法、ブレンドとスムージング、頂点ごとのボーン インフルエンスの最大数、最小ウェイト、およびバックアップを保持するかどうかを設定して、**Automatic Bone Weight Recalculation** を実行します。これらの設定はボタンの上にあります。 CATS ショートカット**Smart Automatic Weights** は、ターゲット メッシュ、アーマチュア、モード、およびクロージング モードのソース メッシュのダイアログを開きます。

**場所:** BoneCraft タブ → スキン → ウェイト ツール

---

### ウェイトミラー

**機能:** アバターの一方の側からもう一方の側にウェイトをコピーします。左右対称のキャラクターには必須です。

**キーコントロール:**
- **Mirror All Weights** — すべてのボーン グループを反対側にミラーリングします
- **Mirror Active Weight** — アクティブなボーン グループのみをミラーリングします
- 対称軸とミラー方向 (両方向、左から右、または右から左)
- **Topology Mirror** — 位置ではなくメッシュ トポロジによって頂点をペアリングします
- **Search Distance** — 2 つの頂点がどれだけ離れていてもペアとしてカウントされるか (完全に対称ではないメッシュの場合は値を上げます)
- **Select Unmatched** — パートナーのない頂点を選択します。**Normalize Weights** はその後、ウェイトの合計を 1.0 にします。

まずミラー ボタンをクリックし、[最後の操作の調整] で軸、方向、トポロジ モード、検索距離を設定します。 **Mirror Active Weight** は、[ウェイト] → [BoneCraft] および [ウェイト ツール シェルフ] タブにもあります。

**場所:** BoneCraft タブ、ウェイト ペイント モード → ウェイト ミラー

---

### ウェイト転送

**機能:** ソース メッシュからアクティブ メッシュにウェイトをコピーします。衣服を体に取り付ける場合、またはウェイトを高解像度メッシュから低いメッシュに移動する場合に使用されます。

**キーコントロール:**
- 転送する前にソース メッシュを選択してください
- クリック後、「最後の操作を調整」で転送方法とボーンフィルターを設定します
- 最後の操作を調整の **Normalize** — ウェイトの合計を 1.0 に保ちます
- **Transfer Weights** — 実行します。結果には平均距離と最大距離が表示され、**Select Problem Vertices** は一致度の低い頂点を選択します。

**場所:** BoneCraft タブ、ウェイト ペイント モード → ウェイト転送(スキン → ウェイト ツールの下にもあります)

---

### ウェイトテーブル

**機能:** 各ボーンの選択した頂点の正確なウェイトを表示し、正確な値を設定できます。

**使用方法:** ウェイト ペイント モードで頂点を 1 つ選択します。表にはそのボーンとウェイトがリストされています。ボーンの行にある手のアイコンをクリックし、[最後の操作の調整] で**Weight** を設定します。 [影響を追加] では、選択したボーンが使用されます。最後の操作の調整でも新しいウェイトを設定します。複数の頂点を選択すると、**Normalize All Vertices** はそれらすべてを正規化します。

**場所:** BoneCraft タブ、ウェイト ペイント モード → ウェイト テーブル

---

### フラッドフィル

**機能:** ワンクリックで選択した頂点にアクティブ グループのウェイトを設定します:**Flood to 0.0** 、**Flood to 1.0** 、または**Flood to Custom**。 Flood to Custom 後、Adjust Last Operation で**Value** と**Normalize** を設定します。 Weights メニューとシェルフでは、固定値ボタン Flood to Zero および Flood to One を呼び出します。

**場所:** BoneCraft タブ → スキン → ウェイト ツール;また、ウェイト → BoneCraft およびツール シェルフ → ウェイト → BoneCraft

---

### デフォームvs コントロール

**機能:** リグのボーンを変形ボーン (メッシュを移動する) とコントロール ボーン (アニメーターが移動する) に分類し、変形ボーンにタグを付け、それらの名前を変形命名に変更し、変形のみのスケルトンをエクスポートします。

**場所:** BoneCraft タブ、ポーズ モード → Deform vs Control

---

### デルタマッシュ

**機能:** 関節での挟み込みを軽減する滑らかな変形。メッシュは静止しているときはその形状を保ちますが、動いているときはよりきれいに変形します。

**使用方法:** **Add Delta Mush** をクリックしてモディファイアを追加し、残りのシェイプにバインドします。直後に「最終操作の調整」で**Iterations** 、**Smooth Strength** 、**Pin Borders** 、**Only Smooth Deform** を設定します。モディファイアが存在すると、パネルには**Rebind** と**Remove** が表示され、モディファイアの反復、スムージングの強さ、境界線の固定コントロールを含む [設定] フォールドが表示されます。

**場所:** メッシュが選択されたオブジェクト モードの BoneCraft タブ → Delta Mush

---

### プロキシミティラップ

**機能:** 2 番目のスキンのように、1 つのメッシュを別のメッシュのサーフェスに追従させます。体に密着する衣類に便利です。

**使用方法:** ターゲット メッシュを選択し、別の**Driver Mesh** を選択して、**Bind Proximity Wrap** をクリックします。バインド中はドライバーのアーマチュアをレスト ポーズに保ちます。オプションはボタンリスト**Falloff Type** および**Max Distance** の下にあります。 9.1.2 では、これらの値はセットアップとともに保存されますが、そのサーフェス変形バインディングは変更されません。バインドされると、パネルには**Rebind** と**Unbind** が表示されます。アンバインドすると、ビューポートおよびレンダリング内のモディファイアが無効になります。それは削除されません。

**場所:** メッシュが選択されたオブジェクト モードの BoneCraft タブ → 近接ラップ

---

## リグコントロール

これらのツールは、ポーズ モードの BoneCraft タブに表示されます。

---

### スペーススイッチ

**機能:** アニメーション中にボーンが従うスペースを変更します。プロップを持っている手は、ワンクリックで体に従う状態からワールド内で静止する状態に切り替えることができます。

**キーコントロール:**
- **Add Space** および**Remove Space** (スペースの管理の下の X アイコン) — ボーンが従うことができるスペース (ワールド、原点、または別のボーン)
- スペースごとに 1 つのボタンがあり、その名前にちなんで付けられます。現在のスペースには●がマークされています。別のスペースのボタンをクリックしてボーンをそのスペースに切り替えます

**場所:** BoneCraft タブ、ポーズ モード → スペース スイッチ

---

### スプラインIK

**機能:** ボーンのチェーンを曲線に沿って作成します。スムーズなスイープ動作が必要な尾、触手、ロープ、長い髪、脊椎に使用されます。

**使用方法:** 開始ボーンをアクティブにして、**Generate Spline IK** をクリックします。最終操作の調整に**Chain Length** 、**Curve Resolution** 、**Stretch** 、**Volume Preservation** を設定します。**Remove Spline IK** はセットアップを削除します。

**場所:** BoneCraft タブ、ポーズ モード → スプライン IK

---

### チェインダイナミクス

**機能:** ボーン チェーン上の物理学のような二次モーション: 親が動くとボーンは遅れ、停止すると跳ね返ります。髪の毛、尻尾、アクセサリーなどに使用されます。

**使用方法:** ボーン チェーンを選択し、**Add Chain Dynamics** をクリックします。最終操作の調整に**Stiffness** 、**Damping** 、**Mass** 、**Gravity Scale** を設定します。このパネルには、アクションの下の [設定] フォールドにパラメータもリストされます。ダイナミクスが存在すると、**Bake** と**Remove** が表示されます。衝突では単純化された球形状が使用されるため、凹面は正しく衝突しない可能性があります。

**場所:** BoneCraft タブ、ポーズ モード → チェーン ダイナミクス

---

### リボン

**機能:** 唇、眉毛、ベルト、その他の柔らかい曲面領域に、Bendy Bones (滑らかに湾曲してねじれるボーン) のリボンを作成します。

**使用方法:** ボーン チェーンを選択し、**Generate Ribbon** をクリックし、最後の操作の調整で**Control Bones** と**Ribbon Width** を設定します。**Remove Ribbon** はセットアップを削除します。

**場所:** BoneCraft タブ、ポーズ モード → リボン

---

### ビジェームライブラリ

**機能:** シェイプ キーにリンクされた口形素 (口の形) のセットを作成および管理し、テキストからリップシンク キーを生成します。 VRChat 口形素マッピングの場合は、VRChat 口形素マッピングを使用します。口形素を最初から生成するには、CATS 口形素セクションを使用します。

**キーコントロール:**
- **New Set** および**Delete** — 口形素セットの作成または削除
- 各セットでは、口形素ごとに 1 つのボタン (スピーカー アイコン付き) でプレビューします。
- リップシンク — 音素ごとのフレームとスムージングを使用した、テキストから口形素キーへの変換

**場所:** アーマチュアが選択された BoneCraft タブ → 口形素ライブラリ

---

### セットドリブンキー

**機能:** Python 式を使用せずに、ある値を別の値にリンクします。ドライバー (眉骨など) のポーズを設定し、駆動値 (「眉を上げた」シェイプ キーなど) を設定し、ポイントを記録します。 BoneCraft はドライバー カーブを構築します。

**キーコントロール:**
- **Driver Bone** および**Driver Attribute** — 何が原動力となるのか
- **Target Bone** および**Target Attribute** — 駆動されるもの
- **Set Value** および**Record Point** — 曲線上の点を記録します
- **Create SDK** — ドライバーをビルドします

**場所:** BoneCraft タブ、ポーズ モード → ドリブン キーの設定

---

### リグバリデーター

**機能:** 一連のルールに照らしてリグをチェックし、名前付け、欠落しているボーン、壊れた制約、階層、ウェイト、Python を必要とするドライバー、メカニズム ルールなどの問題を報告します。ハイフンを含むボーン名 (`DEF-upper_arm.L` など) は合格します。

**キーコントロール:**
- **Run Validation** — すべてのチェックを実行し、結果をリストします。
- **Export Report** — 結果をファイルに保存します

タスク ボード (BoneCraft タブ → 概要 → タスク ボード) には、チェックが失敗した場合の検証タスクが表示されます。

**場所:** BoneCraft タブ → レビュー → Rig Validator

---

### リグノート

**機能:** リグのボーンに添付されたメモ — 設定内容、リマインダー、共同作業者向けのメモ。

**キーコントロール:** 各ノートの**Add Note** および**Remove**。 Rig Readme には、リグのメモが読み取り専用ページとして表示されます。

**場所:** BoneCraft タブ → 概要 → Rig Notes、および Review → Rig Readme
