# リグツール

[← 目次](index.md)

この章では、BoneCraft のリギング、アニメーション、ウェイトのツールを詳しく説明します。機能をより深く理解したいときや、ガイドが自分の状況にぴったり合わないときに使ってください。

各項目では、ツールの働き、使う場面、主な操作、場所を説明します。特定のモードでだけ表示されるツールもあり、そのモードは各項目の「場所」に書いてあります。たとえば、リグコントロールはポーズモードで、ウェイトミラーとウェイト転送はウェイトペイントモードで、デルタマッシュはオブジェクトモードで表示されます。

---

## リグ UI ツール

アーマチュアを扱うときの見た目の面を管理するツールです。どのボーンを表示するか、どう整理するか、すばやい呼び出しを扱います。

---

### ボーンコレクション

**できること：** スケルトンのボーンコレクションを行として表示します。コレクションの名前をクリックするとそのボーンを選択し、目のアイコンで表示・非表示を切り替えます。

> ボーンコレクションは、名前の付いたボーンのグループです（例：「IK Controls」「Face Bones」「Deform Bones」）。コレクションを非表示にするとそのボーンがビューポートで隠れるので、リグの一部分に集中できます。

**主な操作：**
- 各行：アクセントカラー、**Toggle Collection Visibility**（コレクションの表示を切り替え。目のアイコン）、コレクションの名前（ボーンを選択）、**Solo Collection**（コレクションをソロ表示。S のアイコン）、**Rename Collection Display**（コレクションの表示名を変更。歯車のアイコン。行の表示名を設定します）
- **Show All Collections**（すべてのコレクションを表示）と **Hide All Collections**（すべてのコレクションを非表示）（一覧の上の開いた目と閉じた目のアイコン）— すべてを一度に切り替える
- セクション — 複数のコレクションを折りたためる見出しの下にまとめる

**場所：** BoneCraft タブ → レビュー → コレクション

---

### 表示ブックマーク

**できること：** どのボーンコレクションを表示しているかを保存し、保存した表示をすぐに切り替えられるようにします。

**使用例：** 表情の作業用に顔のボーンだけを表示し、「Face Only」として保存します。次にウェイトペイント用にすべてを表示し、「Full Rig」として保存します。これで 1 クリックで 2 つを切り替えられます。

**主な操作：** スロットごとに 1 行です。
- ブックマークの名前 — クリックすると保存した表示を適用する
- **Save Bookmark**（ブックマークを保存。ディスクのアイコン）— 現在の表示状態をスロットに保存する
- 色の見本 — ブックマークを色分けする
- **Clear Bookmark**（ブックマークをクリア）と **Remove Bookmark**（ブックマークを削除。閉じるアイコン）— スロットを空にする、または追加したスロットを削除する
- **ブックマークを追加** — スロットを追加する

**標準のブックマーク：** FK Arms、IK Body、Face Only、Full Rig

**場所：** BoneCraft タブ → レビュー → コレクション → 表示ブックマーク

---

### ホットキーのクイックパネル

**できること：** BoneCraft のリグパネル（コレクションとブックマーク）を、カーソルの位置にポップアップとして開きます。

**使い方：** 3D ビューポートで **Ctrl+Shift+R** を押します。ポップアップの外をクリックすると閉じます。

**場所：** 3D ビューポートのショートカット **Ctrl+Shift+R**（専用のパネルはありません）

---

## アニメーションツール

---

### ポーズライブラリ

**できること：** 名前とサムネイルの付いたポーズを保存し、1 クリックでリグに適用できるようにします。

**主な操作：**
- **保存** — 現在のボーンの位置を名前付きのポーズとして、ビューポートのサムネイルと一緒に保存する
- **適用** — ボーンを保存したポーズに合わせる
- **ブレンド** — ポーズを一部の強さで、現在の位置と混ぜて適用する
- **ミラー** — ポーズを左右反転して適用する
- **削除**、**名前を変更**、**カテゴリ** — 一覧を管理する。**フィルター** は 1 つのカテゴリだけを表示する
- **エクスポート** と **インポート** — `.bfpose` ファイルに保存する、またはそこから読み込む

**場所：** BoneCraft タブ → レビュー → ポーズライブラリ

---

### Control Picker（コントロールピッカー）

**できること：** リグのコントロールをクリックできる図です。形をクリックするとそのボーンを選択し、選択中のものが強調表示されます。

**主な操作：**
- **Generate Picker**（ピッカーを生成）— リグから配置を作る
- **Edit Layout**（配置を編集）— コントロールを移動、拡大縮小、ラベル変更する（**Move Picker Control**（ピッカーのコントロールを移動）、**Resize Picker Control**（ピッカーのコントロールの大きさを変更）、**Relabel Picker Control**（ピッカーのコントロールのラベルを変更）は各コントロールの行にアイコンで表示されます）。**Snap**（スナップ）でグリッドに合わせ、**レイアウトを再構築** で作り直します
- **選択をミラー** — ミラー側のコントロールを選択する
- **ポップアップピッカー** — ピッカーを浮動ウィンドウで開く。そこには **Add Selection Set**（選択セットを追加）もあります

**場所：** BoneCraft タブ → レビュー → Control Picker

---

### Control Layer（コントロールレイヤー、IK/FK）

**できること：** **コントロールリグを構築** で作ったリグの手足のための、アニメーター向けの操作です。手足を跳ねさせずに IK と FK を切り替え、フレーム範囲にわたって一方を他方にベイクします。

**主な操作：**
- **IK** と **FK** — 手足を切り替え、新しいコントロールを手足の今の位置に合わせるので、ひじやひざが跳ねません
- **Bake IK**（IK にベイク）と **Bake FK**（FK にベイク）— フレーム範囲のアニメーションを IK または FK に変換する
- **Pole Follow**（ポールの追従）、**Pin**（固定）、**Lock-Free**（ロック解除）、保護されたロックを保つ **Global Rig Scale**（リグ全体のスケール）

**場所：** BoneCraft タブ → レビュー → Control Layer（**コントロールリグを構築** で作ったリグを選択しているとき。[リグビルダー](06-rig-builder.md) を参照）

---

### Rigifyツール

**できること：** Rigify のコントロールリグを検出し、BoneCraft のコレクションパネル、ブックマーク、プロパティのスライダーを Rigify の標準のコントロールにつなぎます。

> Rigify は、アニメーション用のリグを生成する Bforartists 組み込みの仕組みです。Rigify でリグを作った場合、BoneCraft の UI を Rigify の IK/FK コントロールにつなぎます。

**主な操作：**
- **自動強化** — 選択した Rigify リグ用に BoneCraft のパネルを設定する
- **強化を再実行** — それを最初から作り直す
- **Rigifyを有効化** と **コントロールリグを生成（アクティブメタリグ）** は Quick Rig にあります（[リグビルダー](06-rig-builder.md) を参照）
- Rigifyプロパティ — リグの IK/FK、ストレッチ、親空間、頭と首の追従のスライダー

**場所：** BoneCraft タブ → リギング設定 → Rigifyツール（と Rigifyプロパティ のセクション）

---

### リターゲット

**できること：** あるスケルトンのアニメーションを別のスケルトンに移します（例：モーションキャプチャのクリップを自分のアバターへ）。ボーンは名前と向きで対応付けられるので、手足の向きが保たれます。鎖骨はゆるく対応付けられるので、肩が回りすぎません。

**主な操作：**
- **クリップをインポート** と **ライブラリを参照** — クリップを読み込む、またはライブラリのフォルダーを設定する。クリップの名前をクリックすると選択します
- **Auto-Match Bones**（ボーンを自動対応付け。クリップの行のチェックマーク）— 元と先のボーンを組にする（パネルのボーンマッピングの一覧に組が表示されます）
- **プレビュー** と **プレビューを停止** — 結果を試す
- **適用** — クリップを自分のリグにベイクする

**場所：** BoneCraft タブ → リギング設定 → リターゲット

---

### 補正シェイプキー

**できること：** ボーンがある角度に達すると有効になるシェイプキーです。極端なポーズでのつぶれやへこみを直します。

**使用例：** キャラクターのひじを完全に曲げるとつぶれます。直したひじをスカルプトし、腕のボーンにつなぐと、ひじを曲げるにつれて自動的に適用されます。

**主な操作：**
- 新しい修正 — **シェイプキー**、**ドライバーボーン**、回転軸、形が完全に有効になる角度、徐々に効き始める度合いを選び、**補正を作成** をクリックする
- 補正の一覧：補正のシェイプキーの名前をクリックして選択します。一覧の下の **編集** と **削除** は、選択した補正に対して働きます

**場所：** BoneCraft タブ → スキン → 補正（メッシュに基準のシェイプキーが必要です）

---

### グラフツール

**できること：** キーフレームとカーブを仕上げるアニメーションのツールです。

- **インタラクティブブレークダウン**（ブレークダウナー。3D ビューポートのショートカット **Ctrl+Shift+B**）— 左右にドラッグして、現在のポーズを前後のキーフレームの間でブレンドする
- **デルタを適用**（デルタムーバー。3D ビューポートのショートカット **Ctrl+Shift+D**）— 選択したボーンを、スクリーン空間またはワールド空間で正確な量だけずらす
- **キャプチャ** と **スワップ**（バッファカーブ）— カーブのコピーを取っておき、それと編集後のカーブを入れ替える
- **スマートベイク** — コンストレイントで動くアニメーションをキーにベイクし、余分なキーを減らす（**許容値** で度合いを設定）
- **オイラーフィルター** — ジンバルロックによる回転の反転を直す
- タンジェントハンドル — 選択したキーのハンドルの種類を設定する：**Auto**（自動）、**Vector**（ベクトル）、**Aligned**（整列）、**Free**（フリー）、**Auto Clamped**（自動クランプ）

**場所：** BoneCraft タブ → レビュー → グラフツール

---

## ウェイトツール

ボーンが動いたときにメッシュがどう変形するかを制御するツールです。ウェイトは、メッシュの各部分がどのボーンにどれだけ付いて動くかを決めます。

---

### ボーンウェイトの自動再計算

**できること：** メッシュを変えずに、既存のリグからメッシュのウェイトを計算し直します。高密度のメッシュでは軽い代理メッシュを通して処理するので、何も言わずに失敗することはありません。

**主な操作：** 対象のメッシュとアーマチュア、方式、ブレンドとスムージング、1 頂点あたりのボーンの影響の最大数、最小ウェイト、古いウェイトのバックアップ。**Automatic Bone Weight Recalculation**（ボーンウェイトの自動再計算）を実行します。CATS タブには近道の **Smart Automatic Weights**（スマート自動ウェイト）があります。

**場所：** BoneCraft タブ → スキン → ウェイトツール

---

### ウェイトミラー

**できること：** アバターの片側のウェイトを反対側にコピーします。左右対称のキャラクターには欠かせません。

**主な操作：**
- **全ウェイトをミラー** — すべてのボーングループを反対側にミラーする
- **アクティブウェイトをミラー** — アクティブなボーングループだけをミラーする
- 対称の軸とミラーの方向（両方向、左から右、右から左）
- **トポロジーミラー** — 位置ではなくメッシュのトポロジーで頂点を組にする
- **検索距離** — 2 つの頂点をどこまで離れていても組とみなすか（完全に対称でないメッシュでは大きくする）
- **一致しないものを選択** — 相手のない頂点を選択する。**ウェイトを正規化** はその後でウェイトの合計を 1.0 にする

**場所：** BoneCraft タブ、ウェイトペイントモード → ウェイトミラー

---

### ウェイト転送

**できること：** 元のメッシュからアクティブなメッシュにウェイトをコピーします。衣装を体に取り付けるときや、高解像度のメッシュから低解像度のメッシュにウェイトを移すときに使います。

**主な操作：**
- 元のメッシュ、転送の方式、ボーンのフィルター
- **転送後に正規化** — ウェイトの合計を 1.0 に保つ
- **ウェイトを転送** — 実行する。結果には平均と最大の距離が表示され、**問題のある頂点を選択** はうまく対応しなかった頂点を選択する

**場所：** BoneCraft タブ、ウェイトペイントモード → ウェイト転送（スキン → ウェイトツール にもあります）

---

### ウェイトテーブル

**できること：** 選択した頂点の各ボーンに対する正確なウェイトを表示し、正確な値を入力できるようにします。

**使い方：** ウェイトペイントモードで頂点を 1 つ選択します。表にその頂点のボーンとウェイトが並びます。複数の頂点を選択しているときは、**すべての頂点を正規化** で全部を正規化します。

**場所：** BoneCraft タブ、ウェイトペイントモード → ウェイトテーブル

---

### フラッドフィル

**できること：** 選択した頂点に、アクティブなグループのウェイトを 1 クリックで設定します。**0.0にフラッド**、**1.0にフラッド**、または **カスタム値** を使う **フラッド**（**カスタム正規化** 付き）があります。

**場所：** BoneCraft タブ → スキン → ウェイトツール

---

### デフォームvs コントロール

**できること：** リグのボーンを、デフォームボーン（メッシュを動かす）とコントロールボーン（アニメーターが動かす）に分けます。デフォームボーンに印を付け、デフォーム用の命名に名前を変え、デフォームボーンだけのスケルトンをエクスポートします。

**場所：** BoneCraft タブ、ポーズモード → デフォームvs コントロール

---

### デルタマッシュ

**できること：** 関節のつぶれを減らすスムージングの変形です。メッシュはレスト状態の形を保ちつつ、動いたときによりきれいに変形します。

**主な操作：** 反復回数、スムージングの強さ、境界の固定、変形のみのスムージング、アーマチュアより前に実行するかどうか。追加ボタンでモディファイアーを追加し、レスト状態の形にバインドします。

**場所：** BoneCraft → Skin → Delta Mush (Object Mode; Mesh)

---

### プロキシミティラップ

**できること：** あるメッシュを別のメッシュの表面に、第二の皮膚のように付いて動かします。体に密着する衣装に便利です。

**主な操作：** 付いて動く先のドライバーメッシュ、減衰の種類、最大距離。バインドボタンでメッシュを取り付けます。

**場所：** BoneCraft → Skin → Proximity Wrap (Object Mode; Mesh)

---

## リグコントロール

これらのツールは、ポーズモードの BoneCraft タブに表示されます。

---

### スペーススイッチ

**できること：** アニメーション中にボーンがどの空間に付いて動くかを変えます。小道具を持った手を、1 クリックで体に付いて動く状態からワールドに静止した状態に切り替えられます。

**主な操作：**
- **スペースを追加** と **Remove Space**（スペースを削除。スペースを管理の下の X のアイコン）— ボーンが付いて動ける空間（ワールド、原点、または別のボーン）
- 空間ごとに、その名前のボタンが 1 つあります。今の空間には ● が付きます。別の空間のボタンをクリックすると、ボーンがその空間に切り替わります

**場所：** BoneCraft タブ、ポーズモード → スペーススイッチ

---

### スプラインIK

**できること：** ボーンのチェーンをカーブに沿わせます。なめらかで大きくうねる動きが必要なしっぽ、触手、ロープ、長い髪、背骨に使います。

**主な操作：** **チェーン長**、**カーブ解像度**、**ストレッチ**、**ツイストモード**、**ボリューム保持**。**スプラインIKを生成** と **スプラインIKを削除**。

**場所：** BoneCraft タブ、ポーズモード → スプラインIK

---

### チェインダイナミクス

**できること：** ボーンのチェーンに物理演算のような二次的な動きを付けます。親が動くとボーンが遅れて付いてきて、止まると跳ね返ります。髪の房、しっぽ、アクセサリーに使います。

**主な操作：** 硬さ、減衰、質量、重力。選択したチェーンにダイナミクスを追加します。衝突は単純な球の形で計算するので、へこんだ面では正しく衝突しないことがあります。

**場所：** BoneCraft タブ、ポーズモード → チェインダイナミクス

---

### リボン

**できること：** なめらかに曲がりねじれるボーンであるベンディボーンでリボンを作ります。唇、眉、ベルトなど、柔らかく曲がる部分に使います。

**主な操作：** **コントロールボーン** と **リボン幅**。**リボンを生成** と **リボンを削除**。

**場所：** BoneCraft タブ、ポーズモード → リボン

---

### ビジェームライブラリ

**できること：** シェイプキーにつながったビジェーム（口の形）のセットを作って管理し、テキストからリップシンクのキーを生成します。VRChat 用のビジェームの対応付けには VRChat Viseme Mapping を、ビジェームを一から作るには CATS のビジェームのセクションを使います。

**主な操作：**
- **新しいセット** と **削除** — ビジェームセットを作る、または削除する
- 各セットには、ビジェームごとに 1 つのボタン（スピーカーのアイコン）があり、クリックするとそのビジェームをプレビューします
- リップシンク — テキストからビジェームのキーへ。音素あたりのフレーム数とスムージングを設定できる

**場所：** CATS → Avatar Tools → Viseme Library (Armature); Lip Sync (Pose Mode)

---

### セットドリブンキー

**できること：** Python の式を使わずに、ある値を別の値につなぎます。ドライバー（例：眉のボーン）のポーズを取り、動かされる値（例：「Brow Raised」のシェイプキー）を設定して、ポイントを記録します。BoneCraft がドライバーのカーブを作ります。

**主な操作：**
- **ドライバーボーン** と **ドライバー属性** — 動かす側
- **ターゲットボーン** と **ターゲット属性** — 動かされる側
- **値を設定** と **ポイントを記録** — カーブ上にポイントを記録する
- **SDKを作成** — ドライバーを作る

**場所：** BoneCraft タブ、ポーズモード → セットドリブンキー

---

### リグバリデーター

**できること：** リグを一連のルールで確認し、問題を報告します。命名、足りないボーン、壊れたコンストレイント、階層、ウェイト、Python が必要なドライバー、Mechanisms のルールを確認します。ハイフンを含むボーン名（`DEF-upper_arm.L` など）は合格します。

**主な操作：**
- **検証を実行** — すべての確認を実行し、結果を一覧表示する
- **Export Report**（レポートをエクスポート）— 結果をファイルに保存する

確認に失敗すると、タスクボード（BoneCraft タブ → 概要 → タスクボード）にバリデーターのタスクが表示されます。

**場所：** BoneCraft タブ → レビュー → リグバリデーター

### リグノート

**できること：** リグのボーンに付ける書き込みのメモです。設定した内容、覚え書き、共同作業者へのメモに使います。

**主な操作：** **ノートを追加** と、各メモの **削除**。リグREADME は、リグのノートを読み取り専用のページとして表示します。

**場所：** BoneCraft タブ → 概要 → リグノート、および レビュー → リグREADME
