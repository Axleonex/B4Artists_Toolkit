| Unity や Unreal でマテリアルが灰色になる | **Embed Textures**（テクスチャを埋め込む）をオンにしてエクスポートし、Unity のマテリアルのインポート / 抽出のオプションか、Unreal の FBX マテリアルのインポートを使う |
| ウェイトがすべて違うボーンに付いている | ウィザードの「リグを生成」をやり直すか、[ウェイト転送](05-rig-tools.md#ウェイト転送) を使うか、CATS タブの **Smart Automatic Weights**（スマート自動ウェイト）を使う |
| 2 つのリグを 1 つにしたい | [ガイド 11：2 つのリグを 1 つにまとめる](03-guides-b.md#ガイド-112-つのリグを-1-つにまとめる) |

| CATS のツールが「Run Fix Model first」と警告する | 「モデルを修正」を実行する — [CATS パイプライン](04-cats-pipeline.md) |
| 話すと口が裂ける、割れる | 「モデルを修正」が飛ばされた — フェーズ 1 からやり直す — [ガイド 13、フェーズ 1](03-guides-b.md#フェーズ-1--モデルを修正) |
| VRChat でアバターの目が下を向いたまま | 「モデルを修正」の前にアイトラッキングを実行した — 「モデルを修正」からやり直す — [CATS：アイトラッキング](09-cats.md#アイトラッキング) |
| シェイプキーを有効にするとメッシュが爆発する | 「モデルを修正」の前に「ポーズをシェイプキーに」を実行した — 「モデルを修正」からやり直す — [CATS：ポーズとシェイプキー](09-cats.md#ポーズとシェイプキー) |
| VRChat でアバターが違う大きさで出現する | パイプラインが終わる前にトランスフォームを適用した — 元のファイルから再インポートし、「モデルを修正」からやり直す |
| ボーン名が日本語 / 中国語 / 韓国語 | [CATS：ボーン名を翻訳](09-cats.md#ボーン名を翻訳) |
| アバターにリップシンクも口のシェイプキーもない | [CATS：ビジェーム](09-cats.md#ビジェーム) — 3 つの基本の形から 15 個のビジェームを作る |
| メカニズムに「changed by hand」と表示される | [Mechanisms（メカニズム）](07-mechanisms.md) — **Keep mine**（自分の編集を残す）か **復元** を使う |

## 用語集

**アーマチュア（Armature）：** Bforartists でのスケルトンの呼び方。ポーズを付けてアニメーションできるボーンの集まりです。

**ブレンドシェイプ（Blend shape）：** シェイプキーを参照してください。

**ボーン（Bone）：** スケルトンの 1 区間。ボーンは階層（親 → 子）をなし、子のボーンは親に付いて動きます。

**ボーンコレクション（Bone collection）：** 名前の付いたボーンのグループ。コレクション全体を一度に表示・非表示にできます。

**CATS：** CATS のツール。案内付きのパイプライン（クリーンアップ、ビジェーム、アイトラッキング、トランスフォーム）で、VRChat 用にモデルを準備します。CATS タブにあります。

**CATS パイプライン（CATS pipeline）：** CATS のツールの 6 つのフェーズの順番：モデルを修正 → マテリアルアトラス → ビジェーム → アイトラッキング → ポーズをシェイプキーに → トランスフォームの適用。依存する前のフェーズが済んでいないと、ツールが警告します。

**補正シェイプキー（Corrective shape key）：** ボーンがある角度に達すると有効になるシェイプキー。極端なポーズでメッシュを直します。

**デフォームボーン（Deform bone）：** メッシュを動かすボーン。すべてのボーンがメッシュを変形するわけではなく、操作用だけのボーンもあります。

**アイトラッキング（Eye tracking）：** 目のボーン（`LeftEye`、`RightEye`）と、VRChat が目を動かすのに使う回転のコンストレイントを設定する CATS のツール。

**FBT（フルボディトラッキング、Full Body Tracking）：** 追加の機器（Vive トラッカーなど）で、腰や足を含む体全体を追跡する VRChat の機能。「FBTを修正」は、そのためにルートボーンを調整します。

**FBX：** 3D モデル、スケルトン、アニメーションをプログラム間で受け渡すファイル形式。VRChat の標準の形式です。

**モデルを修正（Fix Model）：** CATS のクリーンアップ。重複した頂点、ばらばらの形状、悪い法線を直します。常に CATS の最初の手順です。

**FK（フォワードキネマティクス、Forward Kinematics）：** チェーンの各ボーンを順に回してポーズを付ける方法。肩、次にひじ、次に手首。体全体の大きなポーズに向いています。

**IK（インバースキネマティクス、Inverse Kinematics）：** チェーンの先端（手や足）を置いてポーズを付ける方法。間のボーンが付いて動きます。手や足を正確に置くのに向いています。

**ヒューマノイド（Humanoid）：** ボーンを標準の体のスロットに対応付ける VRChat のアバターの仕組み。どのアバターも同じ動きの操作を使えるようにします。

**メカニズム（Mechanism）：** 小道具や機械の部品のためのリグ。ジョイント（Hinge、Slide、Telescope）かリンク（Piston、Gear Link、Follow）で、普通のボーンとコンストレイントで作られます。[Mechanisms（メカニズム）](07-mechanisms.md) を参照してください。

**メッシュ（Mesh）：** アバターの見える体を形づくる 3D の表面。

**MMD（MikuMikuDance）：** 日本やアニメのコミュニティで人気の無料の 3D アニメーションソフト。モデルには `.pmx`、アニメーションには `.vmd` のファイルを使います。

**モーフターゲット（Morph target）：** シェイプキーを参照してください。

**操作台帳（Operation Ledger）：** 実行したすべての操作を、時刻と結果とともに並べた CATS の一覧。

**PhysBone：** ボーンを揺らし、弾ませ、衝突させる VRChat のコンポーネント。髪、しっぽ、ぶら下がるアクセサリーに使います。

**パイプラインステータス（Pipeline Status）：** CATS の 6 つのフェーズの一覧。済んだフェーズにはチェックマークが付きます。

**PMX：** MikuMikuDance の主な 3D モデルの形式。

**ポーズモード（Pose Mode）：** ボーンにポーズを付け、アニメーションするためのモード。アーマチュアを選択して Ctrl+Tab を押すか、ビューポートの左上にあるモードのドロップダウンを使います。

**リグ / リギング（Rig / rigging）：** 3D モデルの中にスケルトンを作り、メッシュをそれにつないで、ポーズやアニメーションを付けられるようにすること。

**シェイプキー（Shape key）：** 変形した状態のメッシュを保存したもの。シェイプキーはさまざまな強さで混ぜ合わせられ、表情、リップシンク、体の形の変化を動かします。

**SDK（ソフトウェア開発キット、Software Development Kit）：** VRChat では、アバターをアップロードするための VRChat Creator Companion とその Unity のツール。

**スプラインIK（Spline IK）：** カーブに沿うボーンのチェーン。しっぽ、触手、長い髪、背骨に使います。

**T ポーズ（T-pose）：** 基準のポーズ。まっすぐ立ち、腕を横に広げた姿勢です。

**ツールシェルフ（Tool Shelf）：** 3D ビューポートの左側のパネル（T キー）。標準では BoneCraft タブと Rig Builder タブがここにあります。

**頂点（Vertex）：** 3D 空間の 1 つの点。メッシュは、辺と面でつながった多くの頂点でできています。

**頂点グループ（Vertex group）：** 名前の付いた頂点の集まり。ボーンがどの頂点を動かすかを決めます。

**ビジェーム（Viseme）：** 話す音に対応する口の形。VRChat はリップシンクに 15 個のビジェームを使います。

**ウェイト / ウェイトペイント（Weight / weight painting）：** 各ボーンが各頂点をどれだけ強く動かすかを示す 0.0 から 1.0 の値。ウェイトペイントは、それを目で見ながら調整する方法です。

**ウィザード（Wizard）：** リグビルダーのオートリグウィザード。メッシュにマーカーを置き、そこからリグを作ります。

**ゼロウェイトのボーン（Zero-weight bone）：** どの頂点も動かさないボーン。アバターの見た目を変えずにパフォーマンスを下げます。「モデルを修正」とパフォーマンスの最適化が取り除きます。
