BoneCraft 9.2.5. BoneCraft é um kit de ferramentas de rigging e avatares para o Bforartists.

Esta edição cobre a interface 9.2.5: Starter Rigs, Setup Rigging, Skin, Avatar Tools e Facial. Primeiros passos mostra a localização e as configurações de visibilidade.

O tutorial Crescent Rose inclui oito etapas FBX, 30 passos Mechanisms e 52 capturas anotadas verificadas na interface 9.1.2.

Este manual foi traduzido automaticamente a partir da edição em inglês.

As abas selecionam grupos de ferramentas. Setup Rigging, Skin, Review, Avatar Tools e Facial são seções expansíveis dentro das abas, não abas separadas. Os caminhos abaixo usam os nomes da interface em inglês; a tradução depende de Language.
