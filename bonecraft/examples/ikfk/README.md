# IK/FK practice file

[Download BoneCraft-IK-FK-Practice.blend](BoneCraft-IK-FK-Practice.blend) and open it in Bforartists with BoneCraft and Rigify enabled.

Follow the [beginner walkthrough](../../docs/tutorials/ikfk-beginner.md), including its narrated video. Use the top-bar scene selector to choose **1 - Quick Rig (Rigify)** or **2 - Auto-Rig Wizard (BoneCraft)**, select the rig and enter Pose Mode.

The file starts with neutral FK poses and contains a `START_HERE.txt` text block. Both scenes preserve their rig drivers and unlocked IK targets. These mannequin examples demonstrate control movement; inspect fitting and weights when using your own character.

Created with BoneCraft 9.1.3 source in Bforartists 5.2.0. The walkthrough describes the tested scope and the observed Rigify twist flip when snapping a backward elbow bend.
