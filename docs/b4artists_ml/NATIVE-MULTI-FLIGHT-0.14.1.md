# Multiple native flights, 0.14.1

Five and sixteen authored flight intervals exceeded the host's single-driver expression length in 0.14.0. The failure was explicit and recovered the source, but prevented these multi-flight previews. Version 0.14.1 retains the compact direct driver for short expressions and splits longer formulas into one native driver per interval plus a final sum. It uses no runtime Python callback or add-on playback dependency.

The new generated properties, drivers and their self-targeted dependencies are copied as part of the existing editable result archive. A sixteen-interval BoneForge result (51 drivers) now passes Keep, source restore, save/reload, reopening an independent candidate and Discard. A separate default Rigify sixteen-flight scene with bound geometry reopens in a fresh host with both the add-on and script auto-execution disabled; all six sampled rig/mesh outputs match exactly.

The options qualification covers zero and half-strength gravity on transformed BoneForge and default Rigify, plus five and sixteen intervals on BoneForge and sixteen on default Rigify. All seven cases pass their COM/acceleration gates, preserve source action/modes and clean up generated IDs. Multiple-interval fixtures deliberately use repeated identical priority poses to isolate the driver graph; they do not establish production motion quality, landing momentum or style preservation.

The final package retains 34 files and both unchanged learned pose models. The earlier 0.14.0 ZIP is preserved. Current regression coverage combines the complete 0.14.0 run with fresh foundation/registration, native integration and ownership suites after the version/native-only change: 229 unique cases, no skips. Source-to-package and module hashes make that composition explicit in native-regression-final-v2.json. Final native offline qualification covers all thirteen native integration tests; the other runtime algorithms are unchanged.

Packaged real-window multi-flight events pass Escape, generation, Undo/Redo, Keep, source restore, saved-result reopen and Discard. See native-ui-v6.json. These automated tests do not count as independent animator assessment. Long single-flight 240-frame cases remain rejected at the frozen acceleration tolerance. The no-add-on host shutdown access violation and canonical S3 inconclusive review remain unresolved.

Evidence under training/b4artists_ml/results: native-options-v1.json (failed long formulas), native-options-v2.json (all seven pass), native-multi-final-v1-regression.json, native-regression-final-v2.json, offline-native-multi-v1.json and native-multi-playback-v1-verify.json. UI/review/package receipts live in docs/b4artists_ml. No code, model or scene is committed or pushed by this milestone.
