# B4Artists Machine Learning execution architecture v4

Status: active execution plan. This does not claim product qualification or Cascadeur parity.

## Judgment

The canonical rig adapter, immutable requests, reversible candidate actions, exact authored-control restoration and separate constraint/physics stages remain the correct product foundation. The learned-motion program is not proven optimal. Its main weakness has been repeated nearby fits against narrow interpolation metrics before broad motion quality, contact behavior and animator correction effort were established.

## Product pipeline

1. Translate BoneForge, Rigify and supported imported humanoids into a versioned canonical representation containing root motion, local joint orientation, proportions, authored masks, contact phases, timing and motion intent.
2. Use a responsive pose-completion backend for the current frame. It must preserve pinned positions and orientations through an exact constraint projection.
3. Generate editable linear/SLERP, contextual Hermite and shape-preserving sequence references.
4. Use a compact local Transformer to select and refine those references for the default interactive inbetweening path. Confidence or ensemble disagreement selects a fixed procedural fallback without hidden target motion.
5. Keep an optional slower diffusion backend for alternate plausible sequences only after data rights, latency and quality are demonstrated.
6. Infer or accept contact phases, then apply deterministic joint, contact, collision, balance, gravity and angular-momentum refinement. Learned smoothness is not evidence of physical validity.
7. Preview in a background computation over immutable arrays, validate on the original rig, then publish ordinary editable F-curves through Keep/Discard/Restore.

## Immediate bounded decision

Run one two-seed reference-mixture Transformer comparison over the fixed 7.158742-hour train-only corpus. It predicts interval-level convex reference weights plus an authored-envelope residual. Training includes best-reference supervision, balanced gap/context/pattern sampling and an upper-tail position penalty. Existing development partitions, controls and every acceptance gate remain unchanged. Confirmation stays sealed.

If either seed fails any development partition or cohort gate, stop this model family. Do not spend another evaluation on changed layer counts, loss weights or selectors. The next learned-motion work must change the evidence-limited factors together: broaden legally usable motion coverage, encode explicit contact and intent/style, and test a root-plus-local-rotation representation against the current semantic representation. Freeze that comparison before training.

## Milestone order

1. Qualify learned humanoid inbetweening on walk, run, jump, land, turn, reach, crouch, aerial and difficult sparse-key transitions.
2. Qualify learned sparse posing across BoneForge, default Rigify and imported humanoids with varied proportions.
3. Qualify automatic contacts and deterministic physical refinement, including angular momentum and collision cases.
4. Measure end-to-end preview latency, cancellation, memory, output editability and source recovery.
5. Run blind animator acceptance/correction-time trials and equivalent direct Cascadeur comparisons.
6. Expand to quadrupeds only after the humanoid representation and evaluation protocol pass.
7. Implement the optional entitlement-aware Cascadeur connector after the standalone core qualifies.

The full original endpoint, goal ID, evaluation ceiling, deadline and regression floors remain unchanged.
