# BoneCraft 9.1.2

Latest repository package: [BoneCraft-BFA-9.1.2.zip](../../../../releases/BoneCraft-BFA-9.1.2.zip). The install package root is `boneforge`. No GitHub Release has been published for this build.

## Changes

Preferences > Tabs gains a Scene Properties Show switch. It shows or hides the BoneCraft Scene-tab sections without disabling the add-on. It starts enabled and leaves viewport tabs and Armature-tab sections alone.

This build includes the earlier 9.1 icon and interface updates, Mechanisms, configurable tab sides, the Rig Builder workflow and CATS Import / Export placement. See the [complete version history](../../../../bonecraft/docs/manual/en/11-whats-new.md).

The current English manual includes the illustrated Crescent Rose tutorial, with verified parts and Mechanisms example files. Six translated editions include 9.1.2 release notes, but their usage chapters and the new tutorial remain deferred. Use the [English manual](../../../../bonecraft/docs/manual/en/index.md) for current controls.
