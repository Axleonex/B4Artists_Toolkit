# BoneCraft 9.2.2

Groups rigging and avatar tools by workflow and removes the Other Tools section.

- Bone Merge moves to BoneCraft → Setup Rigging.
- Delta Mush and Proximity Wrap move to BoneCraft → Skin.
- Viseme Library moves to CATS → Avatar Tools, between Hair Physics and Export.
- VRChat Viseme Mapping and Face Tracking move to CATS → VRChat Tools → Facial, after Clothing and before Naming.
- Removes Other Tools and its registration and tool-toggle grouping hooks.

Install **BoneCraft-BFA-9.2.2.zip** through Edit → Preferences → Add-ons → Install from Disk, then restart Bforartists.
