# Native Timeline tool access coverage

Prepared 2026-10-13. This is a source wiring inventory, not a native application qualification or an AnimBot functional-parity claim. No runtime tests were added or run for this packet. Observed native use remains **not verified** until the compiled application is available.

## Access provided

- The native `DOPESHEET_EDITOR / TOOL_HEADER` provider draws inside the same Timeline area. Commands temporarily target that area's `WINDOW` region. No new Text Editor, private header hook, `area_split`, `area_move` or recurring join/split geometry repair is used.
- A capability check requires `show_region_tool_header`, `timeline_toolbar_hidden_by_user`, and `screen.timeline_toolbar_set`. An unpatched application draws the same catalogue and saved pins in the existing Timeline header.
- Every catalogue action has a stable preference checkbox and a search result with Execute and Pin/Unpin controls. The 70 previous operator/argument mappings, 13 defaults and 17 original quick presets are preserved. The catalogue now has **89 actions**, including **19 additional existing actions**.
- Search is permanently drawn beside Gear. It searches stable catalogue IDs, labels, families, suffixes and original concept aliases. An empty query shows pinned controls; a query searches the complete catalogue. Up to 16 matches are displayed, with a refinement message for larger result sets.
- Family menus retain all variants. Each family has an adjacent Options control. Pinned primary actions execute or invoke their existing modal tool directly. The toolbar wrapper owns no additional Undo step or modal handler; the existing target owns Undo, Redo and modal cleanup.
- Prerequisites keep positions stable and gray unavailable buttons. Hover text includes scope, prerequisite and the actual supported commit/cancel gesture. Pinning is allowed even while a tool is unavailable.
- Width is handled by native header panning. Resizing never creates or replaces editor areas. Lifecycle initialization is separate from sizing: a new Timeline is initialized once; native explicit-user hiding survives loading. Explicit preference changes are allowed to reveal/hide the row. Disable hides the native row without recording a manual user hide.
- Enable/load queues candidate capture for the first unrestricted lifecycle callback, because add-on registration cannot read application screens. Each captured marked Text Editor receives one assessment after native geometry is valid. A directly adjacent pair may be joined once and the Timeline survives. The decision to leave a nonadjacent editor alone is retained even if the user later moves it beside a Timeline. Unmarked editors and later-created editors are untouched; no new marker Text is created.
- Disable uses each active screen's owning window and an ordinary window only for inactive workspace screens. Temporary/maximized active windows receive no explicit screen override. A rejected operation is reported per area; registered classes are cleaned up in a final cleanup block. Lifecycle hiding uses `user_action=False`, preserving the native explicit-user-hide flag.

| Bake | Family Options: existing object bake range/step/channels/reduction tolerance | Existing object/proxy-session operations; evaluated-object scope |
| Motion | Family Options: existing trail scope/sampling/space and live offset mask | Existing world trail backend and live Action Offset session, with existing limitations |

Optional settings access does not change existing algorithm backends. Pinned Save Reference Bookmark runs immediately with the name `Reference <frame>`; Curves Options lets the user rename the saved item. Recall uses the currently selected bookmark index and does not move the playhead. All new rig switches require a configured supported writable numeric property; string enum properties are gray and unsupported. An unconfigured rig is not represented by a working switch button.
