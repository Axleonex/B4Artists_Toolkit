# Anim Assist 12.9.0

## Timeline stage tabs

The bottom Timeline row now starts with stage tabs: **All**, **Block** (Tween, Keys), **Spline** (Curves), **Polish** (Timing, Pose) and **Deliver** (Bake, Motion).

- A stage shows only its families from your active layout. Saved layouts, tool modes and slider settings never change. **All** shows every family.
- Click a tab, hold Ctrl and scroll over the tabs, or use **Timeline > View > Anim Assist Stage**.
- Each workspace keeps its own stage, saved with the .blend file.
- When the row is tight, the tabs collapse into one button that cycles stages before any slider is shortened. Tools outside the stage remain in More and Search.
- **Toolbar Settings** and the Timeline gear popover show a **Row Stage** dropdown. When the family you are configuring is hidden by the current stage, a note names the stage that shows it.

## Timing tooltips

Timing 80% and 90% now say keys sit closer together, so the action plays faster. 110% and 120% say keys spread apart, so it plays slower. Timing Scale describes the same key-spacing effect.

Settings text and the Timeline Tool Row preference description now say the row sits at the bottom of the Timeline. No animation algorithm, dispatch mapping, sidebar or stored preference changes. The Timeline row stays bottom-only.

## Install

Install `b4_anim_assist_v12.9.0.zip` through Preferences → Install from Disk, then restart Bforartists. Existing Timeline layouts and settings are retained; every workspace starts on **All**.

See [qualification](qualification.md) for measured checks and limits.
