## Source checks

- Unit tests (`tests/test_timeline_config.py`, `tests/test_timeline_overlay_layout.py`): 48 pass (Block key types default to Icon; Icon only for tools that have one, also when loading older records; stage defaults and families after the 2026-10-18 review; tooltip wrapping; a stage setup holding a tool whose family moved loads and drops that tool), covering defaults, v1 migration, invalid stage data, round trip, reset, show/hide placement, pin targets, settings entries, forward-compatible tools, 100 saved layouts within the record limit (2,000,000 bytes; a 101-layout library measures about 1.41 MB), stage independence from All and tab behaviour.
- All row compared with the 12.9.1 ZIP by [compare_all_row.py](../../plans/2026-10-17-stage-toolsets/compare_all_row.py) across 2,232 layouts (186 widths 250–2100 px, UI scales 1/1.5/2, two text widths, Recommended and every-12.9.1-tool-visible): tabs-versus-button choice identical in all 2,232. The Recommended All row is unchanged by the 2026-10-18 review (165 of 1,116 differ from 12.9.1, the same as before it: narrow rows where the 10 px stage-button arrow or the shorter 12.10 labels move one tool). All keeps the label Trails, since Hide Trails is not beside it there. With every tool shown, the clearer names (Set Reference, To Reference, Location/Rotation Proxy) move a tool into More in 18 more narrow layouts (438 versus 420). An earlier ad hoc comparison reported 2,034 identical rows with a different label set; this script is the reproducible measure.
- Full `tests/test_*.py` discovery: the same 34 pre-existing failures/errors; none new.
- An independent read-only review of the branch found two medium bugs (All row could lose its tabs to a wide stage; Search pin state for tools outside the stage), a size-limit regression, loss of forward-compatible stage tools, a draw crash on malformed data and wording issues. All were fixed and re-checked before this package was built.

## Limits

- The stage list was driven with simulated pointer events; tab clicks on the wide row, Ctrl+Wheel and Toolbar Settings dialog clicks were exercised through operators and drawing code. The short-Timeline row form of the stage list was not pointer-tested.
- The stage list is drawn by the add-on inside the Timeline (Blender's own menu opened over the stage button, so a second click picked a stage instead of closing it). A click in a region that consumes it, such as a button in another editor, may leave the list open until the next click in the Timeline or Esc.
- A 12.9.x install cannot read a record saved by 12.10.0 (it falls back to Recommended); documented in the release notes.
- After the owner's first preview, Deliver gained the four proxy tools and the compact stage button became a dropdown; after the second, Deliver gained Bake Preview Range, Bake Keys to Integer Frames, One-Click Proxy & Bake and Remove All Proxy Sessions. All were re-checked on this ZIP.
- One-Click Proxy & Bake was fixed before joining the toolbar. The 12.9.x operator constrained the object to a still proxy (world X keys `[0, 0.834, 2, 1, 0]` baked to all `0`) and rolled back the whole active proxy session. It now keys the proxy along the recorded world motion and uses its own session. The bake itself writes world values into the object's own channels, as the other Bake tools do, so a parented object is outside what was checked.
- Bake Keys to Integer Frames rounds keys the same way as Round Key Times; it differs only by saving a timing snapshot for Reset Timing.
- Screenshots use an unselected default scene, so most tools are shown unavailable; at 1,600 px Block overflows into More by design.
- After the third preview (2026-10-18), hover text was fixed and a B4Artists UI/UX review moved Motion to Spline, added To Spline/To Stepped, reordered Deliver and renamed abbreviated labels; a tight row now shortens slider tracks before dropping their names (Spline keeps Neighbors, Ease and Smooth named at a 1,397 px Timeline, [capture](evidence/images/tooltip-spline-ease.png)). All checks above were re-run on this ZIP.
- Not pushed to GitHub; owner walkthrough of 12.10.0 pending.
