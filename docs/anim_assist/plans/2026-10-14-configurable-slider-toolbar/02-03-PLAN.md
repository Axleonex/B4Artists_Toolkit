# Plan 02-03: transactional slider behavior

**Goal:** Eight working slider adapters with honest units and recovery.
**Architecture:** One undoable modal slider operator with a small transaction
interface; reuse existing target capture, snapshots and math. **Tech stack:** bpy,
existing breakdown/curve/retime core helpers. Execute tasks sequentially.

## Task 1: extract reusable session boundaries

**Create:** core/timeline_slider_session.py and tests/test_timeline_slider_session.py.
**Read:** core/breakdown_core.py, core/curve_tools.py, core/p6_retime_math.py,
operators/p3_modal_ops.py, curve_tool_ops.py, p6_modal_ops.py.

**Do:** Define session contract `capture(context, action, config)`, `preview(value)`,
`commit()`, `cancel()`, `is_valid()` and transient feedback data. Capture targets,
settings/reference/pivot and full touched snapshot once. Restore original before
each preview, apply core function, update FCurves and evaluated pose. Don't
duplicate formulas or apply by repeated bpy.ops calls. Snapshot/restore key
coordinates, handles/types/interpolation/selection, added/removed keys, touched
properties and object pose. Release captured references after completion.
Minimal extractions from existing operator helpers are permitted, retaining
their public behavior and operator IDs. Fix touched package-hardcoded preference
lookups by using existing get_prefs. No general modal framework rewrite.

**Verify:** Pure tests/fakes prove preview(a),preview(b) equals only preview(b)
from original; cancel restores original and a vanished target produces a clean
error. Native fixtures are required later; fake sessions do not prove animation math.

**Done means:** Rendering and input can share one safe transaction lifecycle.

## Task 2: implement Breakdown and Smooth adapters first

**Create:** operators/timeline_slider_ops.py. **Modify:** operators/__init__.py
registration and ui/timeline_strip.py scalar dispatch entry.

**Do:** Slider operator accepts stable action ID, mode, track geometry and launch
configuration as hidden operator args. Inline press maps track to absolute value;
Popout press starts relative drag, movement threshold reveals track, release
commits. Zero-motion popout click leaves animation untouched. Add Shift precision,
finite numeric input, Enter, right-click/Esc and one undo registration. Idle
numeric/reset/preset adjustments invoke this same single-operation path.
For Breakdown use factor percent/100 and existing anchor/mask/target semantics;
for Smooth use factor percent/100 with zero neutral, signed roughening correctly
named and tested. Do not run the initial default merely because row is drawn.

**Verify:** Native object/Pose/keyed-anchor/empty-anchor Breakdown and curved
Smooth fixtures: expected numeric value, handles, pose, release commit, Esc
restore and one-step undo/redo. Repeat 30 previews and assert no accumulation.
Confirm old Button/sidebar invoke still works with its existing gestures.

**Done means:** The two default inline sliders are real animation tools.

## Task 3: implement remaining six scalar adapters

**Do:** Add NEIGHBORS, FRAME, EASE, AMPLIFY via existing curve math;
SCALE_DRAG and OFFSET_DRAG via existing retime snapshot/math. FRAME captures
reference value at gesture start; scale captures pivot; offset scope remains
active Action. Percent conversion is explicit; SCALE is absolute multiplier
and AMPLIFY is signed amount. OFFSET_DRAG uses frames. Preserve snap/locked
curve settings. Expose extended range only after backend effect/cancel tests;
do not change algorithms solely to promise limitless sliders.

**Verify:** Compare each adapter against corresponding existing direct tool on
identical fixture at neutral/normal/negative-if-supported/extended range values.
Assert excluded curve/target remains unchanged. Both modes commit/cancel, and
undo/redo restores expected data. SCALE below 1% is rejected; extended >120%
works. Invalid NaN or infinite input fails without mutations.

**Done means:** All eight scalar tools can use either slider presentation.

## Task 4: terminate gestures safely

**Do:** Origin-window/area keyed transient state; cancel on disable, load, lost
area/target, module shutdown and exceptions. Verify focus-loss behavior in stock
host; cancel on observed window deactivation if supported, otherwise require
explicit recovery and mark that cell unverified. Avoid global persistent mouse
interception; only modal during an actual gesture. Settings/layout load cannot
overwrite an active gesture. Clear temporary feedback/cursor/header text.

**Verify:** Native disable/re-enable, area change, undo after commit, invalid
target and multiwindow simultaneous attempts have no stale session/draw state.
Session fails if no live mutation occurs, scope changes or snapshot cannot restore.

**Done means:** An interrupted adjustment cannot leave animation half edited.
