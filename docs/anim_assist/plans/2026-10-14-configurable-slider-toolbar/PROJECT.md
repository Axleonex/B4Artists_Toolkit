# Project: configurable Anim Assist slider toolbar

Core value: artists can adjust animation directly from a compact second row,
choose visible controls and retain named layouts without losing native Timeline
interaction or animation correctness.

Brownfield Bforartists-exclusive add-on; baseline local 12.6.1 at b05f243.
Tech stack: Python, bpy operators/RNA/preferences/native keymaps, gpu and blf.
Use stock Bforartists 5.2.0; no custom application, helper editor or paid API.
Product scope: eight numeric slider tools, all 89 catalogue entries configurable,
native settings dialogs, named layouts, baseline/final functional verification.
Anim Offset stays a session tool. Scene options retain their existing homes.
No invented algorithms, generic slider on nonnumeric tools, global DPI claims,
unrelated Ghost/BoneCraft changes, or owner-profile installation.

Finite endpoint: exact local add-on ZIP and evidence with all mandatory gates
passed, and a separate honest owner usability checkpoint. Public repository and
version publication remain outside this planning/implementation authorization.
