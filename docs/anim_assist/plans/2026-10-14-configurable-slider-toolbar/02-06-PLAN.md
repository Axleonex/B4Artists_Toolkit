# Plan 02-06: regression, qualification and local release

**Goal:** Demonstrate working existing tools and new controls on the exact local
add-on package. **Architecture:** Repeat baseline fixtures, extend native event
cases and record falsifiable gates. **Tech stack:** Existing host/controller,
Python unittest, deterministic ZIP packager. Execute tasks sequentially.

## Task 1: repeat functional effects through the new access routes

**Modify:** tests/check_timeline_toolbar_tools.py, tests/verify_timeline_toolbar.py.

**Do:** Same clean baseline fixtures and tolerances, every immediate catalogue
effect and nine original interactive workflows. Exercise all recommended row
controls plus every configured scalar in BOTH Inline and Popout modes through
native pointer events. Compare before/after against baseline/direct dispatch,
including selection/masks/anchors/playhead invariance and locked/excluded targets.
Scalar cases: regular value, neutral, extended verified range, snapping, Shift,
numeric entry, reset and custom presets. Exercise undo/redo after successful
commit and exact snapshot on Esc/right-click. Count by action/mode/case, not
one inflated overall step number. FINISHED with no expected effect fails.

**Verify:** Final coverage has no missing 89 action IDs, all current/new default
route checks, and eight-by-two slider modes; compare animation/handle/pose/time
outcomes. Identify any changed intentional gesture separately from math/scope
regression. Recheck B50 Redo and trail world-space geometry explicitly.

**Done means:** New access does not hide a broken or behaviorally different tool.

## Task 2: persistence, misuse and lifecycle regression

**Do:** Fresh recommended, migrated custom/empty/hidden row, legacy settings
import, renamed extension preferences, two named layouts, failed imports,
normal full restart, saved scene reload, disabled module, wrong mode/empty
selection, multiwindow, maximize/restore, top/bottom header and addon reload.
Actual keymap/draw handlers match one set enabled and zero disabled; new modal
state clears after interruption. No repeated area resizing, additional editors
or custom binary dependency. Preserve native play/scrub/pan/zoom and context menus
outside covered band. Load/configure/layout editing doesn't alter animation.

**Verify:** Native state records and screenshots corroborate assertions. Record
all host-reachable cells; unsupported actual DPI/window cells remain unverified.
At completely collapsed canvas, acknowledge the known band limitation and
verify expansion produces visible controls without a persistent repair loop.

**Done means:** Saved configurations and the native workspace remain usable.
