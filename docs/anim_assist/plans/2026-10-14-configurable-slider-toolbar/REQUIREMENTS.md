# Requirements

Checkboxes mean evidence-backed completion, not agreement to the design.

- [x] ST-01: Fresh exact 12.6.1 baseline records defects and measured repairs; repaired baseline/final ZIP prove expected effects for current default controls and all 80 immediate actions in stock Bforartists.
- [x] ST-02: All nine interactive catalogue tools have measured preview, commit, cancellation, target-scope and recovery outcomes; Anim Offset uses its real session workflow.
- [x] ST-03: All eight scalar tools offer Hidden/Button/Popout/Inline modes; ordinary tools offer Hidden/Button, with no invented scalar semantics.
- [x] ST-04: Recommended layout has Breakdown and Smooth inline, three breakdown presets, Timing nudges/Scale popout, Copy/Paste, Mirror Selected, Bake Object and Show Trails.
- [x] ST-05: Toolbar order is Tween/Timing/Curves/Keys/Pose/Bake/Motion, utilities right; user ordering works within families; existing explicit choices survive upgrade.
- [x] ST-06: Drag starts immediately on the control, previews absolute values from a captured snapshot, releases to one undoable commit, and Esc/right-click restores exact state.
- [x] ST-07: Each scalar tool has supported range/default/sensitivity/precision/snapping/preset controls and an idle settings window; existing scene masks/anchors/scope are clearly identified and reused.
- [x] ST-08: Ranges can extend within verified backend limits; negative Smooth means roughen, timing scale is positive, and offsets are frames rather than percentages.
- [x] ST-09: Save As/Load/Update/Rename/Delete user-named layouts persists presentation and slider configuration; invalid/duplicate names and malformed records cannot destroy existing layouts.
- [x] ST-10: Layout load/restore/configuration makes no animation change; Recommended cannot be overwritten/deleted; reset leaves saved layouts intact; normal restart restores the active layout and library.
- [x] ST-11: Width/scale adaptation preserves saved modes and order; no repeated resize/split/join, no helper editor, no native-header expansion, and no unnecessary horizontal panning.
- [ ] ST-12: Outside-row canvas/navigation/playback and other editors retain native input; disabled controls explain prerequisites; load/disable/reload/multiwindow remove stale gestures/handlers.
- [x] ST-13: Final controls reproduce baseline effect/scope behavior; every slider mode passes cancel/undo/redo tests; motion trail geometry is checked against evaluated world positions.
- [ ] ST-14: Exact installed add-on ZIP, source/version identity, screenshots, measured gate results and owner usability checklist are recorded; untested cells stay unverified.

Deferred: cloud/shared layout libraries, new AnimBot-only algorithms, custom
Bforartists binaries, a genuine native second HEADER region, and unrelated
add-on restructuring. Named-layout transfer uses existing settings JSON where
available; it does not add a service or separate file-management product.

ST-12 is partial for renamed extension installation and keyboard-only access.
ST-14 technical evidence is complete; owner usability remains pending.
See 02-VERIFICATION.md for per-requirement scope and unsupported cells.
