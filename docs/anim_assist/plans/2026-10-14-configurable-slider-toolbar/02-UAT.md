# Owner usability checkpoint

Status: **Pending owner use**. Automated checks do not complete this checkpoint.

Install the local 12.6.2 ZIP in your existing Bforartists and restart. Use an
animated object or rig with eligible keys selected.

1. Find Breakdown and drag its track without opening a family menu. Release,
   undo once and redo once. Confirm the direction and displayed amount feel clear.
2. Right-click Smooth while idle. Change its display to Popout; accept. Drag it,
   then cancel with Esc. Confirm animation restores exactly.
3. Open Settings. Choose the visible controls and save a layout named Blocking.
   Add another inline slider and save Polish. Switch between both.
4. Change a working layout without saving, then load another. Confirm the discard
   prompt and Save As option are understandable.
5. Drag Timing Scale and cancel with right-click. Scrub and play outside the row.
6. Reduce the Timeline height and width, then expand it. Confirm the row remains
   easy to find, stable and readable in your own workspace. A completely collapsed
   canvas needs expansion; native add-on APIs do not supply a true second header.
7. Restart. Confirm both named layouts and the active settings remain.

Record each step as Pass/Fail and attach a screenshot for a failure. The user's
reported flashing/hidden-row experience needs this real-workspace confirmation;
synthetic fixtures and still screenshots cannot settle it alone.

Publication approval is separate. No push or main merge is authorized by passing
this checklist.
