# Anim Assist 12.7.1 documentation

[Download the add-on](https://raw.githubusercontent.com/Axleonex/B4Artists_Toolkit/main/releases/b4_anim_assist_v12.7.1.zip) | [Installation and Timeline tools](releases/12.7.0/RELEASE-NOTES.md) | [12.7.1 fix](releases/12.7.1/RELEASE-NOTES.md)

The current version is **12.7.1**, a repository build installed as an add-on in existing Bforartists. Standalone GitHub Release publication is pending.
Quick tools occupy a row inside the Timeline beside its native header. The
frame ruler is preserved when the header is at the top. Standard Blender is
unsupported. Breakdown and Smooth start inline; Settings configures all eight
numeric controls and saves user-named layouts. Right-click idle numeric tools
for their individual settings.

The [quick-tool guide](releases/12.5.0/USAGE.md) explains tool selection and
Breakdown anchors; its separate-strip layout screenshots are historical.
Detailed help is available inside the add-on.

The [core suite guide](AnimAssist_User_Manual.md) and
[core suite PDF](AnimAssist_User_Manual.pdf) were written for 12.1.3.
The earlier 12.0.1 PDF is retained under [archive/](archive/).

the [qualification](releases/12.7.0/qualification.md) for host-specific evidence.
