- [User manual](AnimAssist_User_Manual.md) · [Download PDF](AnimAssist_User_Manual.pdf)

The manual covers the configurable bottom Timeline row, inline/popout sliders, named layouts, editor-specific Graph/Dope Sheet sidebars and new NLA sidebar. Clip arrangement and corrections are available together, with separate instructions for source editing, shared Actions and preserved-output baking.

This is an add-on for your existing Bforartists installation. Standard Blender is unsupported. The Timeline row remains bottom-only, retaining the 12.7.1 placement fix. It is a canvas overlay rather than a second native header or separate application.

The [12.5.0 quick-tool guide](releases/12.5.0/USAGE.md) and its separate-strip screenshots are historical. Use the current manual for slider configuration and named layouts. The [archive](archive/) retains the earlier 12.0.1 PDF.

See the [release index](../../releases/VERSIONS.md) for publication status. Rebuild the current PDF with `python docs/anim_assist/build_manual_pdf.py` from the repository root (requires ReportLab).

[Manual review, October 15, 2026](../releases/2026-10-15/manual-review.md) records source comparisons, PDF checks and remaining limits across all three add-ons.
