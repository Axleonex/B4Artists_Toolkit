# Anim Assist 12.6.0 documentation

[Download the add-on](https://github.com/Axleonex/B4Artists_Toolkit/releases/download/v12.6.0/b4_anim_assist_v12.6.0.zip) | [Installation and Timeline tools](releases/12.6.0/RELEASE-NOTES.md)

The current version is **12.6.0**, installed as an add-on in existing Bforartists.
Quick tools use the existing Timeline header. A second native row is not
included in this add-on-only distribution. Standard Blender is unsupported.

The [quick-tool guide](releases/12.5.0/USAGE.md) explains tool selection and
Breakdown anchors; its separate-strip layout screenshots are historical.
Detailed help is available inside the add-on.

The [core suite guide](AnimAssist_User_Manual.md) and
[core suite PDF](AnimAssist_User_Manual.pdf) were written for 12.1.3.
The earlier 12.0.1 PDF is retained under [archive/](archive/).

See the [release index](../../releases/VERSIONS.md) for publication status and
the [historical qualification](releases/12.6.0/qualification.md) for host-specific evidence.
