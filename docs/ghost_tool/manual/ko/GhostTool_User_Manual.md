# Ghost Tool 4.3.1 사용자 가이드

영문 4.3.1의 기계 번역이며 전문 번역 인증을 받은 문서가 아닙니다. 화면과 맞춰 볼 수 있도록 컨트롤 이름은 영어로 유지했습니다. [영문 원본](../../GhostTool_User_Manual.md).

Bforartists용 Ghost Tool은 고스트 메시, 모션 경로, 편집 가능한 모션 마커를 표시합니다. 4.3.1 가이드는 뷰포트의 직접 조작 도구 모음, 독립적인 Before/Ahead 개수, 길게 누르기 설정, 마커 연속 드래그, 스냅샷 마커 복원 후 표시 갱신을 다룹니다.

이 가이드는 [Ghost Tool 4.3.1 설치 ZIP](https://github.com/Axleonex/B4Artists_Toolkit/releases/download/ghost-v4.3.1/b4_ghost_tool_v4.3.1.zip)에 대응합니다. 저장소 소스를 갱신해도 설치된 애드온은 자동으로 갱신되지 않습니다. 새 ZIP을 설치하고 Bforartists를 다시 시작하세요. 버전과 체크섬은 [릴리스 노트](../../releases/4.3.1/RELEASE-NOTES.md)와 [패키지 기록](../../releases/4.3.1/package-receipt.json)을 참고하세요.

## 설치 및 Ghost Tool 위치 찾기

`b4_ghost_tool_v4.3.1.zip`을 내려받아 Edit > Preferences > Add-ons > Install from Disk로 설치합니다. Ghost Tool을 활성화하고, 설치된 버전을 교체했다면 Bforartists를 다시 시작합니다. Preferences에 4.3.1이 표시되는지 확인하세요. 이전 ZIP은 원래 버전을 그대로 설치합니다.

기본 위치는 3D 뷰포트의 기본 Tool Settings 행에 있는 Top Toolbar입니다. 기본 헤더가 위에 있으면 이 행은 주 뷰포트 헤더 바로 아래에 표시되며 헤더 정렬을 따릅니다. 환경설정에는 Right Sidebar (N)와 Left Tool Shelf (T)도 있습니다. 저장된 이전 Top Header 선택은 보이는 도구 모음으로 이전되며, 설정 이름은 이제 Top Toolbar입니다.

기본 도구 및 모드 컨트롤은 계속 사용할 수 있습니다. 좁거나 분할된 뷰포트에서도 모든 Ghost 도구의 순서는 유지됩니다. 마우스 가운데 버튼으로 기본 행을 가로로 드래그해 보이는 폭 밖의 도구에 접근하세요. 컨트롤이 숨겨졌다면 View > Show Ghost Toolbar를 선택합니다. 표시 설정을 유지하려면 평소처럼 환경설정을 저장하세요.

## 빠른 시작: 애니메이션 대상 살펴보기

애니메이션이 있는 오브젝트나 포즈 본을 선택하고 첫 고스트 아이콘을 켭니다. Ghosts를 클릭해 메시 미리보기를 표시하고 Before와 Ahead를 각각 설정합니다. Wire 또는 Solid로 모양을 선택합니다. Ghosts를 길게 눌러 프레임 간격 또는 키프레임 샘플링을 선택하고 Opacity, Fade, In Front를 조정합니다.

Paths를 클릭해 모션 선을 표시합니다. 경로 대상이 없다면 이 동작으로 선택한 애니메이션 대상을 추가할 수 있습니다. 다른 대상에는 Add Selected Path를, 현재 선택을 따라가는 미리보기에는 Follow Selection을 사용합니다. Markers Display를 켜면 목록에 유지된 경로의 편집 가능한 점이 표시됩니다.

Drag를 클릭한 뒤 3D 뷰포트에서 마커를 선택하고 이동합니다. 이동을 확정하면 Drag를 다시 시작하지 않고 다음 마커를 선택할 수 있습니다. Drag를 다시 클릭하거나 Escape로 종료합니다. 편집 전에 Drag를 길게 눌러 마커를 놓았을 때 애니메이션에 미칠 효과를 선택합니다.

## 위쪽 도구 모음을 왼쪽부터 읽기

**Ghost Tool:** 첫 아이콘은 전체 도구를 켜고 끄며 메시 표시 버튼 Ghosts와는 별개입니다. 도구를 끄면 마커와 핸들 편집 모드도 해제됩니다. 길게 누르면 Update Meshes While Scrubbing, Update Markers While Scrubbing, Freeze Updates를 설정합니다.

**Ghosts:** 고스트 메시를 표시하거나 숨깁니다. 옆의 Before와 Ahead 숫자에는 각각 빼기와 더하기 버튼이 있습니다. Wire Ghosts와 Solid Ghosts는 명시적인 스타일 선택입니다. 메시를 숨겨도 선택한 스타일은 유지되며, 스타일 선택은 표시 전환을 대신하지 않습니다.

**Paths:** 모션 경로를 표시하거나 숨깁니다. 자체 Before/Ahead 숫자 다음에 Add Selected Path와 Follow Selection이 있습니다. 다른 오브젝트나 본을 선택해도 추가한 대상은 남습니다. Follow Selection은 현재 선택의 미리보기를 추가합니다. 경로 대상과 고정된 편집 마커는 서로 다른 개념입니다.

**Drag:** 연속 Drag Markers 모드를 시작합니다. **Pin:** 클릭한 마커를 고정하거나 해제하는 선택 동작을 시작합니다. **Markers Display:** Pin 바로 오른쪽의 마름모로 편집 가능한 경로 마커를 표시하거나 숨깁니다. 마우스를 올리면 도구 이름을 확인할 수 있습니다.

**Arc Style:** 클릭 한 번으로 Solid, Speed Colored, Fade를 직접 엽니다. 고스트의 모션 아크를 제어하며 메시의 Wire/Solid 표시를 선택하지 않습니다. Paths에는 길게 누르기 메뉴에 별도 Line Style이 있습니다. **Spacing Ticks:** 간격 표시를 전환하며, 길게 누르면 Acceleration Indicators가 나옵니다.

**Settings:** 마커 생성, 대상, 범위, 편집, 비교, 물리, 외형 등 고급 컨트롤을 엽니다. 위쪽 행에는 독립 Generate/Clear 아이콘을 중복 배치하지 않지만 고급 컨트롤에서 계속 사용할 수 있습니다.

## Before와 Ahead 개수 설정

Ghosts와 Paths 옆에 각각 두 숫자가 있습니다. 첫 Before는 현재 프레임 이전, 두 번째 Ahead는 이후의 샘플 개수입니다. 하나로 합친 밀도가 아니라 독립 개수입니다. 직접 입력하거나 위쪽 도구 모음의 빼기/더하기를 사용합니다. 0이면 해당 쪽 샘플을 끕니다.

개수는 요청할 샘플 수를, 샘플링은 위치를 결정합니다. 재생 헤드가 20이고 Ghosts Before 3, Ahead 2, 프레임 간격 2이면 이전 18, 16, 14와 이후 22, 24를 요청합니다. 실제 결과는 사용 가능한 애니메이션과 범위 제한을 따릅니다. 재생 헤드의 현재 포즈는 이 전후 샘플에 포함되지 않습니다.

By Keyframe은 균등한 프레임 대신 대상의 애니메이션 키를 사용하며, 간격 설정으로 키를 건너뛸 수 있습니다. Paths 개수 필드를 편집하면 재생 헤드 주변의 개수 기반 창을 선택합니다. 고급 프레임 범위 모드는 Settings에 남아 있으며 자체 범위 규칙을 사용합니다.

## 도구를 길게 눌러 설정 열기

일반 클릭은 주 동작을 실행하고, 지원하는 버튼을 길게 누르면 매개변수 메뉴가 열립니다. Arc Style은 예외로 일반 클릭 즉시 세 선택지를 엽니다. Settings는 일반 클릭으로 고급 팝오버를 엽니다.

**Ghosts 길게 누르기:** 프레임 간격 또는 키프레임 샘플링을 선택합니다. 프레임 간격의 Every (Frames)를 1로 설정하면 매 프레임입니다. 키프레임은 사용자 지정 간격도 가능한 Keyframe Interval을 표시합니다. 외형에는 Opacity, In Front, Fade가 있습니다.

**Paths 길게 누르기:** 샘플링 방식과 프레임 또는 키 간격을 선택합니다. Line Style, Frame Numbers, Bezier Handles가 경로 표시를 제어합니다. 곡선 핸들을 살피거나 편집하려면 Bezier Handles를 켭니다.

**Markers Display 길게 누르기:** Motion Paths와 공유하는 샘플링을 바꾸고, 키프레임 점과 마커 프레임 번호를 설정합니다. 이 메뉴는 위쪽 도구 모음에 있습니다. 마커 전용의 세 번째 샘플링 모드는 없으며 여기서 바꾸면 Paths 샘플링도 바뀝니다.

**Drag 길게 누르기:** 모드에 따라 When Released, Curve Shape 또는 Smooth Neighbours와 Nearby Frame Reach, Falloff를 설정합니다. **Pin:** 안내 또는 Unpin All Markers. **Follow Selection:** Highlight Active Path. **Spacing Ticks:** Acceleration Indicators.

## 아래쪽 Timeline 도구 모음 사용

작은 Ghost 도구 띠는 기본 Timeline 버튼과 같은 행에 있습니다. 그 아래에 추가한 두 번째 사용자 행이 아닙니다. 4.3.1 문서 갱신에서는 이 띠를 재설계하지 않았습니다.

순서는 전체 켜기/끄기, Ghosts 메시 표시, 이전/이후 메시 개수, Wire와 Solid, Drag Markers, 편집 마커 마름모, Paths 표시, 이전/이후 경로 개수입니다. 각 숫자 쌍은 위쪽과 같은 이전/이후 순서입니다.

Timeline의 Ghosts 또는 Paths를 길게 눌러 Frame by Frame, By Keyframe, 샘플링 간격과 표시 설정을 엽니다. More Ghost Settings는 전체 옵션을 엽니다. 아래 마름모는 직접 마커 전환이며, 별도 길게 누르기 메뉴는 위쪽 Markers Display에 있습니다. 스냅샷은 고급 설정의 Compare에 있으며 아래쪽 버튼에는 없습니다.

## 마커를 연속해서 드래그하기

Ghost Tool을 켜고 애니메이션 대상의 편집 마커를 표시합니다. Drag를 클릭하면 선택 대기 상태가 되고 3D 뷰포트에서 마커를 클릭하라는 상태 문구가 나옵니다. 빈 공간을 클릭하면 계속 기다리므로 보이는 마커 가까이 이동하세요. 이동을 확정해도 Drag는 다음 편집을 위해 유지됩니다. Drag Markers를 실행하는 모든 버튼은 같은 모드를 공유합니다.

Drag를 다시 클릭하거나 Escape로 끕니다. 이동 중 Escape는 해당 이동을 취소하고 원래 곡선과 마커 위치를 복원합니다. 앞서 확정한 이동은 별도 편집이므로 Undo로 되돌립니다. 도구 끄기, 대상 상실, 파일/히스토리 변경, 애드온 종료도 관련 편집 세션을 끝내거나 취소합니다.

경로 핸들 드래그도 연속 대기 모드를 지원합니다. Bezier Handles를 표시하고 핸들 드래그를 시작한 뒤 보이는 핸들을 차례로 선택합니다. Shift+G도 계속 사용할 수 있습니다. 드래그 중 Alt는 정렬 핸들 동작을 전환합니다. Escape는 진행 중인 이동을 취소하고 모드를 종료합니다.

## 부드럽거나 날카로운 모션 편집 선택

Drag를 길게 눌러 When Released를 확인합니다. Reshape Handles는 기존 베지어 핸들을 바꿔 키프레임 추가 없이 이동한 샘플을 곡선이 지나도록 합니다. Curve Shape의 Free는 자유 조정, Locked는 핸들 각도 유지, Smooth는 구간 전체에 핸들 영향을 재분배합니다.

Insert Keyframe은 마커 프레임에 실제 키를 씁니다. Smooth Neighbours는 삽입 후 인접 키의 핸들을 부드럽게 할 수 있습니다. Nearby Frame Reach와 Falloff는 주변 프레임이 조형 편집에 참여하는 범위와 감쇠를 제어합니다.

보이는 선은 샘플 밀도에도 영향을 받습니다. 샘플이 멀리 떨어지면 실제 애니메이션이 곡선이어도 선은 거칠게 보입니다. 결과를 살피려면 프레임 간격을 줄이세요. 급한 꺾임은 보간, 핸들, 편집 모드에서 생길 수 있으며 표시 샘플만 늘려서는 애니메이션 곡선 모양이 바뀌지 않습니다.

## 마커 고정과 경로 대상 관리

Pin을 클릭한 다음 보이는 마커를 클릭해 고정을 전환합니다. Pin은 한 번의 선택 동작이며 Drag처럼 지속되는 토글이 아닙니다. 다른 마커에는 다시 실행하세요. 여러 마커를 고정할 수 있으며 하나로 제한되지 않습니다. 고정 마커는 곡선 재조정 중 움직이지 않고, 갱신 시 일치하는 고정 마커 기록을 보존합니다. Pin을 길게 눌러 Unpin All Markers로 모두 해제합니다.

경로 대상 추가는 오브젝트나 본을 경로 목록에 유지하는 것이며 모든 애니메이션 샘플을 얼리는 것이 아닙니다. Follow Selection은 선택 미리보기를 바꾸지만 명시적으로 추가한 대상은 유지합니다. Settings의 경로 목록에서 관리하세요. 유지된 경로의 편집점에는 Markers Display를 사용합니다. Keyframe Dots는 별도 표시 보조입니다.

## 실시간 갱신과 기본 애니메이션 편집

Live Update Markers와 Live Update Skin은 기본으로 꺼져 있으며 기존 장면은 저장된 값을 유지합니다. 꺼져 있으면 프레임을 훑을 때 마지막 갱신 미리보기가 남습니다. 주 고스트 아이콘 아래 갱신 옵션으로 바꿉니다. Freeze Updates도 자동 갱신을 멈춥니다.

기본 이동, 회전, 크기 조정, 기즈모 조작 중 Ghost는 애니메이션 프레임을 순회하지 않고 마지막 미리보기를 유지합니다. 확정하거나 취소한 뒤 편집이 안정되기를 기다리고 기존 고스트를 갱신합니다. Auto-key는 켜 두어도 됩니다. 꺼져 있다면 포즈를 확정한 다음 원하는 키를 삽입하세요. 고급 마커 컨트롤의 Generate로 필요할 때 명시적으로 다시 생성합니다.

고급 컨트롤은 Marker Targets, 어니언 스킨 소스, 범위, 세분화, 외형을 계속 제공합니다. 캐시 마커와 캐시 스킨의 가시성은 재생성 없이 기존 미리보기를 보이거나 숨깁니다. Clear All Ghosts는 마커와 어니언 스킨을 삭제합니다. 숨기기만 하려면 가시성을 사용하세요. 숨긴 마커는 클릭이나 박스 선택으로 고를 수 없습니다.

## 스냅샷 저장, 비교, 복원

Settings에서 Compare를 엽니다. Save Snapshot 전에 Active Object / Selected Bones, Selected Path, 선택한 마커 채널 또는 명시적인 장면 범위를 선택하고 표시된 대상을 확인합니다. 스냅샷은 고정 샘플과 캡처한 키/핸들을 장면에 저장하며 저장/재열기와 애드온 비활성화/재활성화 후에도 유지됩니다.

Hide/Show는 애니메이션 변경 없이 오버레이만 바꿉니다. Save Variant는 원본이 기록된 독립 대안을 만들며 부모를 삭제해도 남습니다. 열 개를 유지 중이면 불필요한 기록을 지운 뒤 추가하세요. 캡처, 변형본, 바인딩, 가시성, 삭제, 복원은 기본 Undo/Redo에 참여합니다.

Restore는 쓰기 전에 장면, 오브젝트, 액션, 슬롯, 본, 채널의 동일성을 검증합니다. 캡처 범위의 곡선과 마커 기록을 복원하고 실시간 갱신이 꺼지거나 동결되어도 표시를 갱신합니다. 무관한 오브젝트나 임의의 Action 모디파이어는 복원하지 않습니다. 샘플만 있는 이전 참조는 재조정 가능한 곡선에 적절한 샘플 값을 복원합니다.

교체된 대상은 의도적인 바인딩이 필요합니다. 공유 액션 슬롯은 거부되므로 먼저 애니메이션을 단일 사용자로 만드세요. Bind to Active Target은 참조 하나당 원본 오브젝트 하나와 이름 있는 본 채널을 지원합니다. 여러 오브젝트를 가진 가져온 참조는 한 대상으로 합치지 않고, 보이지만 바인딩되지 않은 상태로 둡니다. 본 이름 변경은 추적합니다. 재열기 후 채널 식별 정보로 곡선을 찾으며, 조작 중 교체된 곡선에는 원래 곡선을 위한 롤백 쓰기를 적용하지 않습니다.

## 스냅샷 전송과 고급 도구

비교 데이터를 전송하려면 스냅샷을 JSON으로 내보냅니다. 가져오기는 기록을 검증·병합하고 ID 충돌을 재매핑하며, 지원하지 않는 버전이나 용량 초과를 원자적으로 거부합니다. 가져온 참조와 이전 참조는 계속 볼 수 있지만 JSON은 원본 오브젝트 동일성을 증명하지 못하므로 복원에는 명시적 바인딩이 필요합니다. 가져오기 실패 시 기존 장면의 읽을 수 없는 기록도 보존합니다.

Edit Motion에는 이징 프리셋과 사용자 지정 이징 컨트롤이 남아 있습니다. Draw to Keys는 가장 긴 주석 스트로크를 위치 경로로 바꾸고, 가로지르는 짧은 선으로 키를 지정합니다. 대화상자는 선택 대상을 유지합니다. Physics Feel, Look, Compare 등 고급 도구는 Settings와 대체 사이드바/셸프 위치에서 계속 사용할 수 있습니다.

## 문제 해결 및 버전 참고

아무것도 보이지 않으면 첫 아이콘, 대상 애니메이션, 관련 표시 활성화, 0보다 큰 개수를 확인하세요. 편집점이 없다면 대상을 Paths에 추가하고 Markers Display를 켭니다. 샘플을 더 보려면 프레임 간격을 줄이거나 키 간격을 바꿔야 할 수 있습니다. 마커 샘플링은 Paths를 따릅니다.

도구 모음이 없으면 Ghost 환경설정에서 Top Toolbar를 선택하고 View > Show Ghost Toolbar를 사용합니다. 분할 뷰에서 잘리면 기본 행을 가로로 스크롤합니다. 왼쪽 셸프 폭 설정은 남아 있지만 4.2.11에서 전체 폭/배율 검증이 미완료였습니다. 이번 릴리스도 모든 셸프 폭 사례의 수정을 약속하지 않습니다.

직접 도구 구현은 이 버전/문서 갱신 전에 도구 모음, 편집, 경로, 스냅샷, 시작, 표시 위치, 캐시 표시를 다루는 188개 대상별 백그라운드 검사를 받았습니다. 이 결과는 이전에 테스트한 구현에 해당합니다. 4.3.1 압축 파일은 ZIP 무결성, 버전 메타데이터, 소스와 바이트 단위 일치를 별도로 확인했으며, 이번 패키징에서 새로운 기능 테스트를 실행했다고 주장하지 않습니다. [이슈 추적기](https://github.com/Axleonex/B4Artists_Toolkit/issues)에 대상, 작업, 실패한 단계를 알려 주세요.
