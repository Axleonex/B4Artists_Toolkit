# Ghost Tool 4.3.1 ユーザーガイド

英語版 4.3.1 からの機械翻訳で、専門翻訳の認証はありません。画面と照合できるよう操作名は英語のままです。[英語原文](../../GhostTool_User_Manual.md)。

Bforartists 用 Ghost Tool は、ゴーストメッシュ、モーションパス、編集可能なモーションマーカーを表示します。4.3.1 のガイドでは、ビューポートの直接操作ツールバー、独立した Before/Ahead 数、長押し設定、マーカーの連続ドラッグ、スナップショットのマーカー復元と表示更新を説明します。

本ガイドは [Ghost Tool 4.3.1 インストール ZIP](https://github.com/Axleonex/B4Artists_Toolkit/releases/download/ghost-v4.3.1/b4_ghost_tool_v4.3.1.zip)に対応します。リポジトリのソースを更新しても、インストール済みアドオンは自動更新されません。新しい ZIP をインストールして Bforartists を再起動してください。バージョンとチェックサムは[リリースノート](../../releases/4.3.1/RELEASE-NOTES.md)と[パッケージ記録](../../releases/4.3.1/package-receipt.json)を参照してください。

## インストールと表示場所

`b4_ghost_tool_v4.3.1.zip` をダウンロードし、Edit > Preferences > Add-ons > Install from Disk からインストールします。Ghost Tool を有効にし、既存版を置き換えた場合は Bforartists を再起動します。Preferences の表示が 4.3.1 であることを確認してください。古い ZIP は元のバージョンをインストールします。

既定の表示場所は、3D ビューポートの標準 Tool Settings 行にある Top Toolbar です。標準ヘッダーが上部にある場合、そのすぐ下に表示され、標準ヘッダーの配置に従います。設定には Right Sidebar (N) と Left Tool Shelf (T) もあります。保存済みの旧 Top Header 設定は表示可能なツールバーへ移行し、名称は Top Toolbar になります。

標準のツールとモードの操作は引き続き使用できます。狭い、または分割したビューポートでも Ghost ツールの順序は変わりません。行をマウス中ボタンで横にドラッグして、幅に収まらないツールへ移動してください。非表示の場合は View > Show Ghost Toolbar を選びます。表示設定を保持するには通常どおりプリファレンスを保存します。

## クイックスタート：アニメーション対象を確認する

アニメーションのあるオブジェクトまたはポーズボーンを選び、最初のゴーストアイコンを有効にします。Ghosts をクリックしてメッシュプレビューを表示し、Before と Ahead を個別に設定します。Wire または Solid で見た目を選びます。Ghosts の長押しで、フレーム間隔またはキーフレームによるサンプリングと、Opacity、Fade、In Front を設定できます。

Paths をクリックしてモーションラインを表示します。パス対象がまだない場合、この操作で選択中のアニメーション対象を追加できます。別の対象には Add Selected Path、現在の選択に追従するプレビューには Follow Selection を使います。Markers Display を有効にすると、登録済みパスの編集可能な点が表示されます。

Drag をクリックし、3D ビューポートでマーカーを選んで移動します。移動を確定したら、Drag を再起動せず次のマーカーを選べます。再度 Drag をクリックするか Escape で終了します。編集前に Drag を長押しし、マーカーを離したときにアニメーションへ与える効果を選びます。

## 上部ツールバーを左から読む

**Ghost Tool：**最初のアイコンでツール全体を有効・無効にします。メッシュ表示の Ghosts とは独立しています。無効化するとマーカーとハンドルの編集モードも解除されます。長押しで Update Meshes While Scrubbing、Update Markers While Scrubbing、Freeze Updates を設定します。

**Ghosts：**ゴーストメッシュの表示・非表示を切り替えます。隣の Before と Ahead の数値には、それぞれマイナスとプラスがあります。Wire Ghosts と Solid Ghosts は明示的なスタイル選択です。非表示にしても選択スタイルは保持され、スタイル選択は表示切り替えの代わりにはなりません。

**Paths：**モーションパスの表示・非表示を切り替えます。専用の Before/Ahead 数に続いて Add Selected Path と Follow Selection があります。別のオブジェクトやボーンを選んでも追加済み対象は残ります。Follow Selection は現在の選択のプレビューを追加します。パス対象の登録と編集マーカーのピン留めは別の概念です。

**Drag：**連続する Drag Markers モードを開始します。**Pin：**クリックしたマーカーをピン留め・解除するための選択を開始します。**Markers Display：**Pin のすぐ右のひし形で、編集可能なパスマーカーを表示・非表示にします。ホバー時の名前でツールを確認できます。

**Arc Style：**クリックで Solid、Speed Colored、Fade を直接開きます。ゴーストのモーションアークを制御し、メッシュの Wire/Solid は選びません。Paths には長押しメニュー内に別の Line Style があります。**Spacing Ticks：**間隔表示を切り替え、長押しで Acceleration Indicators を設定します。

**Settings：**マーカー生成、対象、範囲、編集、比較、物理、外観などの詳細設定を開きます。上部行に独立した Generate/Clear アイコンは重複表示されませんが、詳細設定から使用できます。

## Before と Ahead の数を設定する

Ghosts と Paths の横に、それぞれ二つの数があります。最初の Before は現在フレームより前、次の Ahead は後のサンプル数です。独立した数であり、一つにまとめた密度ではありません。直接入力するか、上部ツールバーのマイナス・プラスを使います。0 にするとその側のサンプルを無効にします。

数は要求するサンプル数、サンプリングはその位置を決めます。再生ヘッドがフレーム 20、Ghosts Before 3、Ahead 2、フレーム間隔 2 なら、前の 18、16、14 と後の 22、24 を要求します。実際にはアニメーションの有無と範囲制限に従います。再生ヘッド上のポーズは前後サンプルに含まれません。

By Keyframe は等間隔フレームではなく対象のアニメーションキーを使い、間隔設定でキーを飛ばせます。Paths の数値を編集すると、再生ヘッド周辺の個数ベースの範囲を選びます。高度なフレーム範囲モードは Settings に残り、独自の範囲規則に従います。

## 長押しでツールの設定を開く

通常クリックは主操作を実行し、対応ボタンの長押しはパラメーターメニューを開きます。Arc Style は例外で、通常クリックで三つの選択肢を即座に表示します。Settings は通常クリックで詳細ポップオーバーを開きます。

**Ghosts の長押し：**フレーム間隔またはキーフレームでサンプリングします。フレーム間隔では Every (Frames) を表示し、1 は毎フレームです。キーフレームでは Keyframe Interval を表示し、カスタム間隔も使えます。外観は Opacity、In Front、Fade で設定します。

**Paths の長押し：**サンプリング方法とフレームまたはキーの間隔を選びます。Line Style、Frame Numbers、Bezier Handles がパス表示を制御します。曲線ハンドルを確認・編集する場合は Bezier Handles を有効にします。

**Markers Display の長押し：**Motion Paths と共有するサンプリング、キーフレームの点、マーカーのフレーム番号を設定します。このメニューは上部ツールバーにあります。マーカー専用の第三のサンプリングモードはなく、ここで変更すると Paths も変わります。

**Drag の長押し：**モードに応じて When Released、Curve Shape または Smooth Neighbours、Nearby Frame Reach、Falloff を設定します。**Pin の長押し：**説明または Unpin All Markers。**Follow Selection の長押し：**Highlight Active Path。**Spacing Ticks の長押し：**Acceleration Indicators。

## 下部 Timeline ツールバーを使う

小型の Ghost 操作列は、Timeline の標準ボタンと同じ行に並びます。下に追加する独自の二段目ではありません。4.3.1 の文書更新でこの列は再設計されていません。

順序は、全体の有効・無効、Ghosts メッシュ表示、前後のメッシュ数、Wire と Solid、Drag Markers、編集マーカーのひし形、Paths 表示、前後のパス数です。どちらの数値ペアも上部と同じく「前、後」の順です。

Timeline の Ghosts または Paths を長押しすると、Frame by Frame、By Keyframe、サンプリング間隔、表示設定を開きます。More Ghost Settings で全体設定を開きます。下部のひし形は直接のマーカー切り替えで、独立した長押しメニューは上部の Markers Display にあります。スナップショットは詳細設定の Compare から使い、下部ボタンにはありません。

## マーカーを繰り返しドラッグする

Ghost Tool を有効にし、アニメーション対象の編集可能なマーカーを表示します。Drag をクリックすると選択待ちになり、ステータスに 3D ビューポートのマーカーをクリックするよう表示されます。空白付近のクリックでは待機を続けるため、見えるマーカーに近づけてください。移動確定後も Drag は次の編集を待ちます。Drag Markers を開始するすべてのボタンで同じモードを共有します。

再度 Drag または Escape で終了します。移動中の Escape はその移動を取り消し、元の曲線とマーカー位置を復元します。既に確定した移動は別の編集なので、Undo で戻します。ツール無効化、対象喪失、ファイル・履歴の変更、アドオン終了でも、関係する編集セッションを終了または取り消します。

パスハンドルのドラッグにも連続待機モードがあります。Bezier Handles を表示し、ハンドルドラッグを開始して、見えるハンドルを次々に選びます。Shift+G も引き続き使えます。ドラッグ中の Alt で整列ハンドルの動作を切り替えます。Escape は進行中の移動を取り消してモードを終了します。

## 滑らかな編集と鋭い編集を選ぶ

Drag を長押しして When Released を確認します。Reshape Handles は既存のベジェハンドルを変え、キーを追加せずに移動サンプルを曲線が通るようにします。Curve Shape の Free は自由な調整、Locked はハンドル角度の保持、Smooth は区間全体へのハンドルの影響の再配分です。

Insert Keyframe はマーカーのフレームに実際のキーを作ります。Smooth Neighbours は挿入後に隣接キーのハンドルを滑らかにできます。Nearby Frame Reach と Falloff は周辺フレームがスカルプト編集に参加する範囲と減衰を制御します。

表示線はサンプル密度にも依存します。間隔が広いと、元のアニメーションが曲線でも粗い線になります。確認にはフレーム間隔を小さくします。鋭い曲がりは補間、ハンドル、編集モードから生じる場合があり、表示サンプルを増やすだけではアニメーションの曲線形状は変わりません。

## マーカーのピン留めとパス対象の管理

Pin をクリックし、見えるマーカーをクリックして固定状態を切り替えます。Pin は一回の選択操作で、Drag の連続切り替えではありません。別のマーカーには再度実行します。複数を固定でき、一つだけに限定されません。固定したマーカーは再整形中も動かず、更新時には一致する固定マーカー記録が保持されます。Pin を長押しして Unpin All Markers を選ぶと一括解除します。

パス対象の追加はオブジェクトやボーンをリストに保持することであり、すべてのアニメーションサンプルを凍結する操作ではありません。Follow Selection は選択プレビューを変えますが、明示的に追加した対象は残ります。Settings のパスリストで管理します。登録済みパスの編集点には Markers Display を使います。Keyframe Dots は別の表示補助です。

## ライブ更新と標準のアニメーション編集

Live Update Markers と Live Update Skin は既定でオフです。既存シーンは保存値を保持します。オフではスクラブしても最後に更新したプレビューを維持します。主アイコン下の更新設定で変更します。Freeze Updates も自動更新を停止します。

標準の移動、回転、拡縮、ギズモ操作中、Ghost はアニメーションフレームを巡回せず最後のプレビューを維持します。確定・取消後に編集が落ち着くのを待ち、既存ゴーストを更新します。Auto-key は有効のままで構いません。無効の場合はポーズ確定後に必要なキーを挿入します。必要に応じ、詳細マーカー設定の Generate で明示的に再生成できます。

詳細設定には Marker Targets、オニオンスキンのソース、範囲、分割、外観が残っています。キャッシュ済みマーカーとスキンの可視性は、既存プレビューを再構築せず表示・非表示にします。Clear All Ghosts はマーカーとオニオンスキンを削除します。隠すだけなら可視性を使ってください。非表示のマーカーはクリック選択もボックス選択もできません。

## スナップショットの保存・比較・復元

Settings から Compare を開きます。Save Snapshot の前に Active Object / Selected Bones、Selected Path、選択マーカーのチャンネル、または明示的なシーン範囲を選び、表示された対象を確認します。スナップショットは凍結サンプルと取得したキー・ハンドルをシーンに保存し、保存・再読込やアドオンの無効化・再有効化を越えて保持します。

Hide/Show はアニメーションを変えずオーバーレイだけを変えます。Save Variant は元を記録した独立の代替版を作り、親を削除しても残ります。十件保持している場合は不要な記録を削除してから追加します。取得、バリアント、バインド、可視性、削除、復元は標準 Undo/Redo に対応します。

Restore は書込前にシーン、オブジェクト、アクション、スロット、ボーン、チャンネルの同一性を検証します。取得範囲の曲線とマーカー記録を復元し、ライブ更新がオフ・凍結中でも表示を更新します。無関係のオブジェクトや任意の Action モディファイアーは復元しません。古いサンプルのみの参照は、再整形可能な曲線で適切なサンプル値を復元します。

置き換えた対象には意図的なバインドが必要です。共有アクションスロットは拒否されるため、まずアニメーションをシングルユーザーにします。Bind to Active Target は参照ごとに一つの元オブジェクトと名前付きボーンチャンネルに対応します。複数オブジェクトのインポート参照は一対象に集約せず、表示可能な未バインド状態を維持します。ボーン改名は追跡されます。再読込後はチャンネル識別で曲線を特定し、操作中に置換した曲線には元曲線向けのロールバックを書き込みません。

## スナップショットの転送と高度なツール

比較データの転送にはスナップショットを JSON へエクスポートします。インポートは記録を検証・統合し、重複 ID を再割当てし、非対応バージョンや容量超過を処理全体として拒否します。インポート参照や旧参照は表示できますが、JSON は元オブジェクトの同一性を証明できないため、復元には明示的なバインドが必要です。インポート失敗時も既存シーンの読めない記録は保持されます。

Edit Motion にはイージングプリセットとカスタム設定が残っています。Draw to Keys は最長のアノテーションストロークを位置パスへ変換し、交差する短線でキーを指定します。ダイアログは選択対象を保持します。Physics Feel、Look、Compare などの高度なツールは Settings と代替のサイドバー・シェルフから引き続き利用できます。

## トラブルシューティングとバージョン注記

何も見えない場合は、最初のアイコン、対象のアニメーション、該当表示の有効化、0 より大きい数を確認します。編集点がない場合は対象を Paths に追加して Markers Display を有効にします。表示サンプルを増やすには、より小さいフレーム間隔や別のキー間隔が必要な場合があります。マーカーは Paths のサンプリングに従います。

ツールバーがなければ Ghost 設定で Top Toolbar を選び、View > Show Ghost Toolbar を使います。分割ビューで切れる場合は標準行を横にスクロールします。左シェルフの幅設定は残っていますが、4.2.11 で幅・倍率の完全な検証は未完了でした。本リリースも全ケースの修正を保証していません。
