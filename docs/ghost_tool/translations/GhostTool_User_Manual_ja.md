# Ghost Tool 4.3.1 ユーザーガイド

[英語版 4.3.1 ガイド](../GhostTool_User_Manual.md)の翻訳です。Bforartists 内でボタンを探せるよう、操作名は英語のまま併記しています。専門家による言語校閲は行っていません。

Bforartists 用 Ghost Tool は、ゴーストメッシュ、モーションパス、編集可能なモーションマーカーを表示します。4.3.1 の本ガイドでは、ビューポートの直接操作ツールバー、独立した Before/Ahead 数、長押し設定、継続的なマーカードラッグ、更新されたスナップショットのマーカー復元を説明します。

本ガイドは [Ghost Tool 4.3.1 インストール ZIP](https://github.com/Axleonex/B4Artists_Toolkit/releases/download/ghost-v4.3.1/b4_ghost_tool_v4.3.1.zip)に対応します。リポジトリの更新だけではインストール済みアドオンは更新されません。新しい ZIP をインストールし、Bforartists を再起動してください。バージョンとチェックサムは[リリースノート](../releases/4.3.1/RELEASE-NOTES.md)と[パッケージ記録](../releases/4.3.1/package-receipt.json)で確認できます。

## Ghost Tool のインストールと表示場所

`b4_ghost_tool_v4.3.1.zip` をダウンロードし、Edit > Preferences > Add-ons > Install from Disk でインストールします。Ghost Tool を有効にし、既存版を置き換えたら Bforartists を再起動します。Preferences のバージョン表示が 4.3.1 か確認してください。古い ZIP は元のバージョンをインストールします。

既定の表示場所は、3D ビューポート標準の Tool Settings 行にある Top Toolbar です。ヘッダーが上にある場合はメインヘッダーのすぐ下に表示され、標準ヘッダーの配置に従います。Preferences には Right Sidebar (N) と Left Tool Shelf (T) もあります。以前保存した Top Header は表示されるツールバーに移行され、設定名は Top Toolbar になりました。

標準のツールやモードの操作も引き続き使えます。狭いビューや分割ビューでも Ghost の全ツールと順序は変わりません。マウス中ボタンで標準行を横にドラッグすると、画面外の項目に移動できます。非表示の場合は View > Show Ghost Toolbar を選びます。表示設定を保持するには通常どおり環境設定を保存してください。

## クイックスタート：アニメーション対象を確認する

アニメーションのあるオブジェクトまたはポーズボーンを選択し、最初のゴーストアイコンを有効にします。Ghosts でメッシュプレビューを表示し、Before と Ahead を別々に設定します。Wire または Solid で表示形式を選びます。Ghosts を長押しすると、フレーム間隔またはキーフレームによるサンプリング、不透明度、フェード、In Front を設定できます。

Paths をクリックして軌跡を表示します。パス対象がない場合、この操作で選択中のアニメーション対象を追加できます。別の対象には Add Selected Path、現在の選択を追う表示には Follow Selection を使います。Markers Display を有効にすると、パスリストへ追加したパス上の編集点が表示されます。

Drag をクリックし、3D ビューポートでマーカーを選んで動かします。移動を確定したら、Drag を起動し直さずに次のマーカーを選べます。もう一度 Drag を押すか Escape で終了します。編集前に Drag を長押しすると、離したマーカーがアニメーションをどう変更するか選択できます。

## 上部ツールバーを左から読む

**Ghost Tool：**最初のゴーストアイコンはツール全体の有効・無効を切り替えます。メッシュを表示する Ghosts ボタンとは別です。無効にするとマーカーとハンドルの編集モードも解除されます。長押しすると Update Meshes While Scrubbing、Update Markers While Scrubbing、Freeze Updates を設定できます。

**Ghosts：**ゴーストメッシュの表示・非表示を切り替えます。隣の Before と Ahead には、それぞれ減算・加算ボタンがあります。Wire Ghosts と Solid Ghosts は明示的なスタイル選択です。メッシュを隠しても選んだスタイルは保持され、スタイル選択自体は表示スイッチではありません。

**Paths：**モーションパスの表示を切り替えます。専用の Before/Ahead 数の後に Add Selected Path と Follow Selection があります。別のオブジェクトやボーンを選んでも、追加済み対象は残ります。Follow Selection は現在の選択のプレビューを追加します。パス対象の登録と、編集マーカーの固定は異なります。

**Drag：**継続的な Drag Markers モードを開始します。**Pin：**クリックしたマーカーを固定・解除する選択操作を開始します。**Markers Display：**Pin のすぐ右のひし形ボタンで、パス上の編集マーカーを表示・非表示にします。ホバー時の説明には各ツール名が表示されます。

**Arc Style：**一度のクリックで Solid、Speed Colored、Fade が直接開きます。Ghost のモーションアークを変更するもので、メッシュの Wire/Solid 選択ではありません。Paths には長押しメニュー内に独立した Line Style があります。**Spacing Ticks：**間隔表示を切り替え、長押しで Acceleration Indicators を設定します。

**Settings：**マーカー生成、対象、範囲、編集、比較、物理、外観などの高度な操作を開きます。上部行には Generate と Clear の独立アイコンを重複配置していません。これらの操作は高度な設定内で利用できます。

## Before と Ahead の数を設定する

Ghosts の横と Paths の横には、それぞれ二つの数値があります。最初の Before は現在フレームより前、次の Ahead は後のサンプル数です。単一の密度設定ではなく、独立した二つの数です。直接入力するか、上部ツールバーの減算・加算ボタンを使います。片側をゼロにすると、その側のサンプルは無効になります。

数は要求するサンプルの個数、サンプリング設定はその位置を決めます。再生ヘッドがフレーム 20、Ghosts Before が 3、Ahead が 2、フレーム間隔が 2 なら、前側に 18、16、14、後側に 22、24 を要求します。利用可能なアニメーションと範囲制限の影響を受けます。現在のポーズは、この前後のサンプル数には含まれません。

By Keyframe は等間隔フレームではなく対象のアニメーションキーを使い、間隔設定でキーを間引けます。Paths の数値を変更すると、再生ヘッドを中心に個数で決める範囲が選択されます。高度なフレーム範囲モードも Settings に残り、それぞれの範囲規則で動作します。

## 長押しでツール設定を開く

通常のクリックは主操作を実行します。対応ボタンを長押しするとパラメータメニューを開きます。Arc Style は例外で、一度のクリックですぐ三つの選択肢が出ます。Settings も通常クリックで高度なポップオーバーを開きます。

**Ghosts の長押し：**フレーム間隔またはキーフレームによるサンプリングを選びます。前者の Every (Frames) を 1 にすると毎フレームです。後者の Keyframe Interval にはカスタム間隔もあります。外観設定は Opacity、In Front、Fade です。

**Paths の長押し：**サンプリングとフレームまたはキーの間隔を設定します。Line Style、Frame Numbers、Bezier Handles はパス表示を制御します。曲線ハンドルの確認・編集には Bezier Handles を有効にします。

**Markers Display の長押し：**Motion Paths と共有するサンプリング、キーフレームの点、マーカーのフレーム番号を設定します。上部ツールバーのメニューです。マーカー専用の第三のサンプリング方式はなく、ここで変更すると Paths 側も変わります。

**Drag の長押し：**モードに応じて When Released、Curve Shape または Smooth Neighbours、Nearby Frame Reach、Falloff を選びます。**Pin の長押し：**説明または Unpin All Markers を選びます。**Follow Selection の長押し：**Highlight Active Path を設定します。**Spacing Ticks の長押し：**Acceleration Indicators を選びます。

## 下部 Timeline ツールバーを使う

コンパクトな Ghost 操作は標準 Timeline ボタンの隣に同じ行で並びます。Timeline ツールバーの下に作られた別の二段目ではありません。4.3.1 の文書更新では、この操作列を再設計していません。

順序は、全体のオン・オフ、Ghosts メッシュ表示、前後のメッシュ数、Wire と Solid、Drag Markers、編集マーカーのひし形、Paths 表示、前後のパス数です。数値は上部と同じく各組で前側、後側の順です。

Timeline の Ghosts または Paths を長押しすると、Frame by Frame、By Keyframe、間隔、表示設定を開きます。More Ghost Settings は全オプションを開きます。下部のひし形は直接の切り替えで、独立した長押しメニューは上部の Markers Display にあります。スナップショットは高度な設定の Compare にあり、下部列のボタンではありません。

## マーカーを繰り返しドラッグする

Ghost Tool を有効にし、アニメーション対象の編集マーカーを表示します。Drag を押すと選択待ちになり、ステータスに 3D ビューポートのマーカーをクリックするよう表示されます。空白をクリックしても待機するので、見えているマーカーに近づいてください。一つの移動を確定しても Drag は次の編集に向けて有効です。Drag Markers を起動する全ボタンは同じモードを共有します。

再度 Drag を押すか Escape で無効にします。移動途中の Escape はその移動を取り消し、開始時の曲線とマーカー位置へ戻します。既に確定した移動は別の編集なので Undo で戻します。ツールの無効化、対象の消失、ファイル・履歴の変更、アドオン終了でも、該当する編集セッションは終了またはキャンセルされます。

パスハンドルのドラッグも継続待機に対応します。Bezier Handles を表示してハンドルのドラッグを開始し、見えているハンドルを順に選びます。Shift+G も使えます。ドラッグ中の Alt はハンドルの整列動作を切り替えます。Escape は進行中のハンドル移動を取り消してモードを終了します。

## 滑らかな編集と鋭い編集を選ぶ

Drag を長押しし、When Released を確認します。Reshape Handles は新しいキーを作らず、移動したサンプルを曲線が通るよう既存のベジェハンドルを調整します。Curve Shape の Free は自由調整、Locked は角度維持、Smooth は区間内でのハンドル影響の再配分です。

Insert Keyframe はマーカーのフレームに実際のキーを書き込みます。Smooth Neighbours は挿入後に隣接キーのハンドルを滑らかにできます。Nearby Frame Reach と Falloff は、周辺フレームが動きのスカルプトへどう関与するかを設定します。

見える線はサンプル密度にも依存します。点が離れていると、元のアニメーションが曲線でも表示線が粗くなります。結果の確認にはフレーム間隔を小さくしてください。鋭い折れは補間、ハンドル、編集モードに由来する場合があり、表示サンプルを増やすだけではアニメーション曲線の形は変わりません。

## マーカー固定とパス対象の管理

Pin を押し、見えているマーカーをクリックして固定・解除を切り替えます。Pin は一度の選択であり、継続 Drag モードではありません。次のマーカーを選ぶには再実行します。複数のマーカーを固定でき、一つに制限されません。固定点はリシェイプ中も動かず、更新時にも対応する固定記録が保持されます。Pin を長押しし、Unpin All Markers でまとめて解除できます。

パス対象を追加するとオブジェクトやボーンがパス一覧に残りますが、そのアニメーションサンプル全部が固定されるわけではありません。Follow Selection は現在選択のプレビューを変更し、明示的に追加した対象は残します。Settings のパス一覧で対象を管理します。追加済みパス上の編集点には Markers Display を使い、Keyframe Dots は別の表示補助です。

## ライブ更新と標準のアニメーション編集

Live Update Markers と Live Update Skin は初期状態でオフです。既存シーンは保存値を維持します。オフならスクラブ中も最後に更新したプレビューを保持します。主ゴーストアイコン下の更新設定で変更してください。Freeze Updates も自動更新を停止します。

標準の移動、回転、拡大縮小、ギズモ操作中は、Ghost がアニメーションフレームを巡回せず最後のプレビューを保持します。確定またはキャンセル後、編集が落ち着いてから既存ゴーストを更新します。Auto-key は有効のままで構いません。使わない場合はポーズ確定後に必要なキーを挿入します。必要に応じ、高度なマーカー設定の Generate で明示的に再生成できます。

高度な設定には Marker Targets、オニオンスキンのソース、範囲、分割、外観が残っています。キャッシュ済みマーカーやスキンの表示設定は、再構築せずに既存プレビューを表示・非表示にします。Clear All Ghosts はマーカーとオニオンスキンを削除するので、隠すだけなら表示設定を使ってください。隠れたマーカーはクリック選択やボックス選択できません。

## スナップショットの保存・比較・復元

Settings から Compare を開きます。Save Snapshot の前に、Active Object / Selected Bones、Selected Path、選択マーカーのチャンネル、明示的なシーン範囲から対象範囲を選びます。パネルの対象表示を確認してください。スナップショットは固定サンプルと取得したキー・ハンドルを保持し、シーンとともに保存されるため、再読み込みやアドオンの無効化・再有効化後も残ります。

Hide/Show はアニメーションを変更せずスナップショットの重ね表示を切り替えます。Save Variant は由来を記録した独立案を作り、親を削除しても案は残ります。保存数が十個になったら、不要分を削除してから追加してください。取得、バリアント、バインド、表示、削除、復元は標準 Undo/Redo に対応します。

Restore は書き込む前にシーン、オブジェクト、アクション、スロット、ボーン、チャンネルの同一性を確認します。取得範囲の曲線とマーカー記録を復元し、ライブ更新がオフまたは凍結中でも表示を更新します。無関係なオブジェクトや任意の Action モディファイアは復元しません。サンプルだけの旧参照は、曲線を再形成できる場所に適切なサンプル値を戻します。

対象が置換された場合は明示的なバインドが必要です。共有アクションスロットは拒否されるため、先にアニメーションをシングルユーザーにします。Bind to Active Target は参照ごとに元の一つのオブジェクトと名前付きボーンチャンネルに対応します。複数オブジェクトのインポート参照は、一つの対象に縮約せず、表示可能な未バインド状態を保ちます。ボーン名変更は追跡されます。再読み込み後はチャンネルの同一性で曲線を特定します。操作中に置換された曲線には、元の曲線向けのロールバックを書き込みません。

## スナップショット転送と高度なツール

比較データを移すにはスナップショットを JSON にエクスポートします。インポートは記録の検証・統合、競合 ID の再割り当てを行い、未対応バージョンや容量超過は原子的に拒否します。インポート参照や旧参照は表示できますが、JSON は元のオブジェクト同一性を証明できないため、復元には明示的なバインドが必要です。インポートが失敗しても既存の読み取れないシーン記録は保持されます。

Edit Motion にはイージングのプリセットとカスタム設定が残っています。Draw to Keys は最長の注釈ストロークを位置パスに変換し、交差する短線がキーを指定します。ダイアログは選択対象を保持します。Physics Feel、Look、Compare などは Settings と、サイドバーや左ツールシェルフからも利用できます。

## トラブル対処とバージョン上の注意

何も出ない場合は、最初のゴーストアイコン、対象のアニメーション、必要な表示の有効化、ゼロより大きい数を確認します。編集点がなければ対象を Paths へ追加して Markers Display を有効にします。点を増やすには間隔を小さくするかキーフレーム間隔を変更してください。マーカーのサンプリングは Paths に従います。

ツールバーがない場合は Ghost の環境設定で Top Toolbar を選び、View > Show Ghost Toolbar を使います。分割ビューで切れる場合は標準行を横にスクロールします。左シェルフの幅設定は残っていますが、4.2.11 の幅・スケール全体の検証は未完了でした。この版ですべての幅問題が直ったとはしていません。

直接操作ツールの実装には、この版・文書更新前に 188 件の対象を絞ったバックグラウンド確認が行われました。対象はツールバー、編集、パス、スナップショット、起動、表示場所、キャッシュ表示です。これは以前確認した実装の結果です。4.3.1 アーカイブでは別途 ZIP 整合性、版情報、ソースとのバイト単位一致を確認しており、今回のパッケージ化で新たな機能テストを実施したとはしていません。[問題追跡ページ](https://github.com/Axleonex/B4Artists_Toolkit/issues)に対象、操作、失敗した手順を記載してください。
