# Ghost Tool 4.3.1 사용자 안내서

[영문 4.3.1 안내서](../GhostTool_User_Manual.md)의 번역입니다. Bforartists에서 해당 버튼을 찾을 수 있도록 영문 조작 이름을 유지했습니다. 전문 언어 감수는 받지 않았습니다.

Bforartists용 Ghost Tool은 고스트 메시, 모션 경로, 편집 가능한 모션 마커를 표시합니다. 이 4.3.1 안내서는 뷰포트의 직접 조작 도구 모음, 독립적인 Before/Ahead 개수, 길게 눌러 여는 설정, 연속 마커 드래그, 개선된 스냅샷 마커 복원을 다룹니다.

이 안내서는 [Ghost Tool 4.3.1 설치 ZIP](https://github.com/Axleonex/B4Artists_Toolkit/releases/download/ghost-v4.3.1/b4_ghost_tool_v4.3.1.zip)에 대응합니다. 저장소 소스를 갱신해도 설치된 애드온이 자동 갱신되지는 않습니다. 새 ZIP을 설치하고 Bforartists를 다시 시작하세요. 패키지 버전과 체크섬은 [릴리스 노트](../releases/4.3.1/RELEASE-NOTES.md) 및 [패키지 기록](../releases/4.3.1/package-receipt.json)에서 확인할 수 있습니다.

## Ghost Tool 설치와 위치 찾기

`b4_ghost_tool_v4.3.1.zip`을 내려받아 Edit > Preferences > Add-ons > Install from Disk에서 설치합니다. Ghost Tool을 활성화하고, 기존 버전을 교체했다면 Bforartists를 다시 시작합니다. Preferences에 4.3.1이 표시되는지 확인하세요. 이전 ZIP은 원래 버전을 설치합니다.

기본 위치는 3D 뷰포트의 기본 Tool Settings 행에 있는 Top Toolbar입니다. 헤더가 위에 있으면 기본 헤더 바로 아래에 표시되며 기본 헤더 정렬을 따릅니다. Preferences에는 Right Sidebar (N)와 Left Tool Shelf (T)도 있습니다. 예전에 저장한 Top Header 선택은 보이는 도구 모음으로 이전되며, 현재 설정 이름은 Top Toolbar입니다.

기본 도구 및 모드 조작은 계속 사용할 수 있습니다. 좁거나 분할된 뷰에서도 전체 Ghost 도구와 순서를 유지합니다. 마우스 가운데 버튼으로 기본 행을 가로로 끌면 화면 밖의 도구에 접근합니다. 숨겨졌다면 View > Show Ghost Toolbar를 선택하세요. 표시 선택을 유지하려면 평소처럼 환경설정을 저장합니다.

## 빠른 시작: 애니메이션 대상 살펴보기

애니메이션이 있는 오브젝트 또는 포즈 본을 선택하고 첫 번째 고스트 아이콘을 켭니다. Ghosts를 눌러 메시 미리보기를 표시하고 Before와 Ahead를 따로 설정합니다. Wire 또는 Solid로 모양을 선택합니다. Ghosts를 길게 누르면 프레임 간격 또는 키프레임 샘플링과 불투명도, 페이드, In Front를 설정합니다.

Paths를 눌러 모션 궤적을 표시합니다. 경로 대상이 없으면 선택한 애니메이션 대상을 추가할 수 있습니다. 다른 대상에는 Add Selected Path를, 현재 선택을 따라가는 경로에는 Follow Selection을 사용합니다. Markers Display를 켜면 경로 목록에 추가한 경로의 편집 가능한 점이 나타납니다.

Drag를 누르고 3D 뷰포트에서 마커를 골라 움직입니다. 이동을 확정한 뒤 Drag를 다시 시작하지 않고 다음 마커를 고를 수 있습니다. Drag를 다시 누르거나 Escape로 종료합니다. 편집 전에 Drag를 길게 눌러 마커를 놓을 때 애니메이션에 어떤 영향을 줄지 선택합니다.

## 위쪽 도구 모음을 왼쪽부터 읽기

**Ghost Tool:** 첫 번째 고스트 아이콘은 도구 전체를 켜거나 끕니다. 메시 표시용 Ghosts 버튼과는 별개입니다. 끄면 마커와 핸들 편집 모드도 해제됩니다. 길게 누르면 Update Meshes While Scrubbing, Update Markers While Scrubbing, Freeze Updates를 설정합니다.

**Ghosts:** 고스트 메시를 표시하거나 숨깁니다. 옆의 Before와 Ahead 숫자에는 각각 빼기와 더하기 버튼이 있습니다. Wire Ghosts와 Solid Ghosts는 명시적인 스타일 선택기입니다. 메시를 숨겨도 선택한 스타일을 유지하며, 스타일 선택 자체는 표시 스위치가 아닙니다.

**Paths:** 모션 경로를 표시하거나 숨깁니다. 자체 Before/Ahead 숫자 뒤에 Add Selected Path와 Follow Selection이 있습니다. 다른 오브젝트나 본을 선택해도 추가한 대상은 남습니다. Follow Selection은 현재 선택의 미리보기를 추가합니다. 경로 대상으로 등록하는 것과 편집 마커를 고정하는 것은 다릅니다.

**Drag:** 계속 활성 상태를 유지하는 Drag Markers 모드를 시작합니다. **Pin:** 클릭한 마커를 고정하거나 해제하는 선택 동작을 시작합니다. **Markers Display:** Pin 바로 오른쪽의 마름모 버튼으로 경로의 편집 마커를 표시하거나 숨깁니다. 마우스를 올리면 각 도구 이름이 표시됩니다.

**Arc Style:** 한 번 클릭하면 Solid, Speed Colored, Fade가 바로 열립니다. Ghost 모션 호의 스타일이며 메시의 Wire/Solid 선택이 아닙니다. Paths에는 길게 누르기 메뉴 안에 별도의 Line Style이 있습니다. **Spacing Ticks:** 간격 표시를 켜고 끄며, 길게 누르면 Acceleration Indicators를 설정합니다.

**Settings:** 마커 생성, 대상, 범위, 편집, 비교, 물리, 외형 등의 고급 조작을 엽니다. 위쪽 행에는 Generate와 Clear를 독립 아이콘으로 중복 배치하지 않습니다. 두 기능은 고급 조작 안에 남아 있습니다.

## Before와 Ahead 개수 설정

Ghosts 옆에 두 숫자, Paths 옆에 두 숫자가 있습니다. 첫 번째 Before는 현재 프레임 이전의 샘플 수이고, 두 번째 Ahead는 이후의 샘플 수입니다. 하나의 밀도 값이 아니라 서로 독립적인 개수입니다. 직접 입력하거나 위쪽 도구 모음의 해당 빼기/더하기 버튼을 사용하세요. 한쪽을 영으로 두면 그쪽 샘플은 꺼집니다.

개수는 요청할 샘플 수를, 샘플링 설정은 샘플 위치를 결정합니다. 재생 헤드가 20프레임, Ghosts Before가 3, Ahead가 2, 프레임 간격이 2라면 앞쪽 18, 16, 14와 뒤쪽 22, 24를 요청합니다. 실제 결과는 애니메이션과 범위 제한을 따릅니다. 현재 재생 헤드의 포즈는 이 앞뒤 샘플 개수에 포함되지 않습니다.

By Keyframe은 균일한 프레임 대신 대상의 애니메이션 키를 사용하며 간격 설정으로 키를 건너뛸 수 있습니다. Paths 숫자를 편집하면 재생 헤드 주위에 개수로 정하는 창을 선택합니다. 고급 프레임 범위 모드는 Settings에 남아 있고 자체 범위 규칙을 따릅니다.

## 길게 눌러 도구 설정 열기

보통 클릭은 주 동작을 실행합니다. 지원하는 도구 버튼을 길게 누르면 매개변수 메뉴를 엽니다. Arc Style은 예외로, 한 번 클릭하면 세 가지 선택이 즉시 열립니다. Settings도 보통 클릭으로 고급 팝오버를 엽니다.

**Ghosts 길게 누르기:** 프레임 간격 또는 키프레임 샘플링을 선택합니다. 전자는 Every (Frames)를 표시하며 1이면 모든 프레임을 사용합니다. 후자는 사용자 지정 간격을 포함한 Keyframe Interval을 제공합니다. 외형 설정에는 Opacity, In Front, Fade가 있습니다.

**Paths 길게 누르기:** 샘플링과 프레임 또는 키 간격을 선택합니다. Line Style, Frame Numbers, Bezier Handles가 경로 표시를 제어합니다. 곡선 핸들을 살피거나 편집하려면 Bezier Handles를 켭니다.

**Markers Display 길게 누르기:** Motion Paths와 공유하는 샘플링, 키프레임 점, 마커 프레임 번호를 설정합니다. 이 메뉴는 위쪽 도구 모음에 있습니다. 마커만의 세 번째 독립 샘플링 모드는 없으므로, 여기서 변경하면 Paths 샘플링도 바뀝니다.

**Drag 길게 누르기:** 모드에 따라 When Released, Curve Shape 또는 Smooth Neighbours와 Nearby Frame Reach, Falloff를 선택합니다. **Pin 길게 누르기:** 설명을 보거나 Unpin All Markers를 선택합니다. **Follow Selection 길게 누르기:** Highlight Active Path를 조정합니다. **Spacing Ticks 길게 누르기:** Acceleration Indicators를 선택합니다.

## 아래쪽 Timeline 도구 모음 사용

작은 Ghost 조작부는 기본 Timeline 버튼 옆의 같은 행에 있습니다. Timeline 도구 모음 아래에 별도로 만든 두 번째 행이 아닙니다. 4.3.1 문서 갱신은 이 조작부를 다시 설계하지 않습니다.

순서는 전체 켜기/끄기, Ghosts 메시 표시, 앞뒤 메시 개수, Wire와 Solid, Drag Markers, 편집 마커 마름모, Paths 표시, 앞뒤 경로 개수입니다. 각 숫자 쌍은 위쪽과 마찬가지로 이전, 이후 순서입니다.

Timeline의 Ghosts 또는 Paths를 길게 누르면 Frame by Frame, By Keyframe, 간격, 표시 설정을 엽니다. More Ghost Settings는 전체 옵션을 엽니다. 아래 마름모는 직접 토글이며, 별도 길게 누르기 메뉴는 위쪽 Markers Display에 있습니다. 스냅샷은 고급 설정의 Compare에 있으며 아래 조작부 버튼이 아닙니다.

## 여러 마커를 연속으로 드래그하기

Ghost Tool을 켜고 애니메이션 대상의 편집 마커를 표시합니다. Drag를 누르면 선택 대기 상태가 되고, 상태 문구가 3D 뷰포트의 마커를 클릭하라고 안내합니다. 빈 곳을 눌러도 계속 대기하므로 보이는 마커 가까이를 클릭하세요. 이동을 확정해도 다음 편집을 위해 Drag가 유지됩니다. Drag Markers를 시작하는 모든 버튼은 이 모드를 공유합니다.

Drag를 다시 누르거나 Escape로 끕니다. 이동 중 Escape는 그 이동을 취소하고 시작 시점의 곡선과 마커 위치로 복원합니다. 앞서 확정한 이동은 별도 편집이므로 Undo로 되돌립니다. 도구 비활성화, 대상 소실, 파일/히스토리 변경, 애드온 종료도 해당 편집 세션을 종료하거나 취소합니다.

경로 핸들 드래그도 계속 대기하는 모드를 지원합니다. Bezier Handles를 표시하고 핸들 드래그 동작을 시작한 다음 보이는 핸들을 차례로 선택합니다. Shift+G도 계속 사용할 수 있습니다. 드래그 중 Alt는 핸들 정렬 동작을 전환합니다. Escape는 진행 중인 핸들 이동을 취소하고 모드를 끝냅니다.

## 부드러운 편집과 각진 편집 선택

Drag를 길게 눌러 When Released를 확인합니다. Reshape Handles는 키를 추가하지 않고 기존 베지어 핸들을 바꿔 곡선이 옮긴 샘플을 지나게 합니다. Curve Shape의 Free는 자유 조정, Locked는 핸들 각도 보존, Smooth는 구간의 핸들 영향 재분배입니다.

Insert Keyframe은 마커 프레임에 실제 키를 기록합니다. 삽입 뒤 Smooth Neighbours로 이웃 키의 핸들을 부드럽게 만들 수 있습니다. Nearby Frame Reach와 Falloff는 주변 프레임이 모션 조형에 참여하는 방식을 결정합니다.

표시선은 샘플 밀도의 영향도 받습니다. 샘플 간격이 크면 실제 애니메이션이 곡선이어도 표시선이 거칠어집니다. 결과를 살필 때 프레임 간격을 줄이세요. 날카로운 꺾임은 보간, 핸들 또는 편집 모드 때문일 수 있으며, 표시 샘플만 늘려도 애니메이션 곡선 모양 자체가 바뀌지는 않습니다.

## 마커 고정과 경로 대상 관리

Pin을 누르고 보이는 마커를 클릭해 고정 상태를 전환합니다. Pin은 한 번 선택하는 동작이며 지속되는 Drag 토글이 아닙니다. 다른 마커를 고르려면 다시 실행하세요. 하나만이 아니라 여러 마커를 고정할 수 있습니다. 고정 마커는 형태 조정 중 움직이지 않으며, 갱신할 때 대응하는 고정 기록이 보존됩니다. Pin을 길게 눌러 Unpin All Markers로 한꺼번에 해제할 수 있습니다.

경로 대상을 추가하면 오브젝트나 본이 목록에 남지만, 모든 애니메이션 샘플이 고정되지는 않습니다. Follow Selection은 선택 미리보기를 바꾸고 명시적으로 추가한 대상은 유지합니다. Settings의 경로 목록에서 대상을 관리하세요. 이 경로의 편집점에는 Markers Display를 사용하며 Keyframe Dots는 별도 표시 보조입니다.

## 실시간 갱신과 기본 애니메이션 편집

Live Update Markers와 Live Update Skin은 기본적으로 꺼져 있으며 기존 장면은 저장값을 유지합니다. 꺼져 있으면 시간축을 이동해도 마지막으로 갱신한 미리보기를 유지합니다. 주 고스트 아이콘 아래의 갱신 옵션에서 바꾸세요. Freeze Updates도 자동 갱신을 일시 정지합니다.

기본 이동, 회전, 크기 조절, 기즈모 조작 중 Ghost는 애니메이션 프레임을 순회하지 않고 이전 미리보기를 유지합니다. 확정하거나 취소한 뒤 편집이 안정되면 기존 고스트를 갱신합니다. Auto-key는 켜 두어도 됩니다. 끈 경우 포즈를 확정한 후 필요한 키를 삽입하세요. 고급 마커 조작의 Generate는 필요할 때 명시적으로 재생성합니다.

고급 조작에는 Marker Targets, 어니언 스킨 소스, 범위, 세분화, 외형 설정이 남아 있습니다. 캐시된 마커와 스킨의 가시성 설정은 다시 만들지 않고 기존 미리보기를 표시하거나 숨깁니다. Clear All Ghosts는 마커와 어니언 스킨을 삭제하므로 단지 숨기려면 가시성을 사용하세요. 숨겨진 마커는 클릭이나 박스로 선택할 수 없습니다.

## 스냅샷 저장, 비교와 복원

Settings에서 Compare를 엽니다. Save Snapshot 전에 범위를 선택합니다. Active Object / Selected Bones, Selected Path, 선택 마커 채널, 명시적인 장면 범위가 있습니다. 패널의 대상 표시를 확인하세요. 스냅샷은 고정된 샘플과 캡처한 키/핸들을 보관하며 장면에 저장되어 재열기 및 애드온 비활성화/재활성화 후에도 유지됩니다.

Hide/Show는 애니메이션을 바꾸지 않고 스냅샷의 겹쳐 보기를 변경합니다. Save Variant는 출처를 기록한 독립 대안을 만듭니다. 부모를 삭제해도 대안은 보존됩니다. 보관한 스냅샷이 열 개면 불필요한 항목을 지운 뒤 새로 저장하세요. 캡처, 변형본, 바인딩, 표시, 삭제, 복원은 기본 Undo/Redo에 참여합니다.

Restore는 쓰기 전에 장면, 오브젝트, 액션, 슬롯, 본, 채널의 동일성을 검증합니다. 캡처한 범위의 곡선과 마커 기록을 복원하고, 실시간 갱신이 꺼져 있거나 정지되어도 표시를 새로 고칩니다. 무관한 오브젝트나 임의의 Action 모디파이어는 복원하지 않습니다. 샘플만 있던 이전 참조는 곡선을 다시 만들 수 있는 부분에서 적절한 샘플값을 복원합니다.

교체된 대상은 명시적 바인딩이 필요합니다. 공유 액션 슬롯은 거부되므로 먼저 애니메이션을 단일 사용자로 만드세요. Bind to Active Target은 참조마다 원래 오브젝트 하나와 이름 있는 본 채널을 지원합니다. 여러 오브젝트를 가진 가져온 참조는 한 대상에 합쳐지지 않고 표시 가능한 미바인딩 상태로 남습니다. 본 이름 변경은 추적됩니다. 다시 연 뒤에는 채널 동일성으로 곡선을 식별하며, 조작 중 교체된 곡선에는 원래 곡선용 롤백을 쓰지 않습니다.

## 스냅샷 전송과 고급 도구 사용

비교 데이터를 옮기려면 스냅샷을 JSON으로 내보냅니다. 가져오기는 기록을 검증하고 합치며 충돌 ID를 다시 매핑합니다. 지원하지 않는 버전이나 용량 초과는 원자적으로 거부합니다. 가져온 참조와 이전 참조는 표시할 수 있지만 JSON만으로 원본 오브젝트 동일성을 증명할 수 없어 복원에는 명시적 바인딩이 필요합니다. 가져오기가 실패하면 기존의 읽을 수 없는 장면 기록도 보존합니다.

Edit Motion은 이징 프리셋과 사용자 지정 이징 조작을 유지합니다. Draw to Keys는 가장 긴 주석 획을 위치 경로로 바꾸며 교차하는 짧은 선이 키를 지정합니다. 대화상자는 선택한 대상을 유지합니다. Physics Feel, Look, Compare 등의 고급 도구는 Settings 및 대체 사이드바/도구 선반 위치에서도 사용할 수 있습니다.

## 문제 해결과 버전 참고

아무것도 나타나지 않으면 첫 고스트 아이콘, 대상 애니메이션, 해당 표시의 활성화, 영보다 큰 개수를 확인하세요. 편집점이 없으면 대상을 Paths에 추가하고 Markers Display를 켭니다. 더 많은 샘플을 보려면 간격을 줄이거나 키프레임 간격을 바꿔야 할 수 있습니다. 마커 샘플링은 Paths를 따릅니다.

도구 모음이 없으면 Ghost 환경설정에서 Top Toolbar를 선택하고 View > Show Ghost Toolbar를 사용합니다. 분할 뷰에서 잘리면 기본 행을 가로로 스크롤하세요. 왼쪽 선반 폭 설정은 남아 있지만 4.2.11의 전체 폭/배율 검증은 끝나지 않았으므로 모든 관련 문제가 해결되었다고 보장하지 않습니다.

직접 조작 구현은 이 버전/문서 갱신 전에 도구 모음, 편집, 경로, 스냅샷, 시작, 표시 위치, 캐시 표시를 대상으로 한 188개의 백그라운드 점검을 거쳤습니다. 이는 이전에 점검한 구현의 결과입니다. 4.3.1 아카이브는 별도로 ZIP 무결성, 버전 정보, 소스와의 바이트 단위 일치를 확인했으며, 이 패키징 과정에서 기능 테스트를 새로 실행했다고 주장하지 않습니다. [문제 추적 페이지](https://github.com/Axleonex/B4Artists_Toolkit/issues)에 대상, 동작, 실패 단계를 적어 주세요.
