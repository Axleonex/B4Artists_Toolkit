# Ghost Tool 4.2.5 documentation

The 4.2.5 repository test build folds Compare's capture targets and each saved reference's snapshot targets independently, with compact summaries and snapshot actions always visible. It retains 4.2.3's Marker Targets fold and 4.2.2's default-off live updates and authoring pause. Bforartists production-rig validation and owner acceptance remain pending.

[4.2.2 guide](GhostTool_User_Manual.md) | [4.2.2 PDF](GhostTool_User_Manual.pdf) | [4.2.5 Compare folds and checks](compare-targets/verification.md) | [4.2.3 marker fold](marker-targets/verification.md)

The 4.2.2 guides cover the shared tools. The 4.2.5 and 4.2.3 reports describe the newer target folds. Detailed tool help remains available inside the add-on.

Download the [4.2.5 test ZIP](../../releases/b4_ghost_tool_v4.2.5.zip?raw=1), or the published [4.2.2 prerelease ZIP](https://github.com/Axleonex/B4Artists_Toolkit/releases/download/ghost-v4.2.2/b4_ghost_tool_v4.2.2.zip). The 4.2.5 build has not been published on GitHub Releases.
