# Ghost Tool 4.2.9 documentation

The Ghost Tool 4.2.9 candidate adds named toolbar section buttons and a direct Ghosts On switch. It defaults to a visible **Top Toolbar**. Top Header has been removed from display settings; saved Top Header choices migrate automatically. Right Sidebar (N), Left Tool Shelf (T), shared feature popovers, Hide/Show Toolbar recovery and cached marker/skin visibility remain available. Saved sidebar, shelf and toolbar visibility choices are retained.

The exact package passes 89 focused tests/checks in native Bforartists 5.2.0: 54 background tests and 35 native split-view checks. Every Object/Pose viewport keeps the same full toolbar; native horizontal panning reaches overflowing buttons. New splits, UI scale, hide/show and frame/cache preservation pass. Production rigs, keyboard navigation and alternate themes remain unverified. The matching ZIP and PDF are an unpublished 4.2.9 candidate; see the [release notes](releases/4.2.9/RELEASE-NOTES.md).

The guides describe the current interface. Detailed tool help remains available inside the add-on.

Choose **Display Location** in Edit > Preferences > Add-ons > Ghost Tool. Switching reveals the selected region and chooses its Ghost Tool tab when supported. Save preferences normally to retain the choice. Other native panels stay available. A left-shelf choice on a host without Bforartists shelf tabs uses Top Toolbar and shows an explanation in preferences.

Install the [4.2.9 candidate ZIP](../../releases/b4_ghost_tool_v4.2.9.zip?raw=1). Restart Bforartists after installation. Live updates default off; existing scenes retain their saved choices.

The earlier 3.3.0 PDF is retained under [archive/](archive/) for historical reference. It does not describe the current interface.
