# Ghost Tool 4.2.0 documentation

Ghost Tool 4.2.0 is published as a prerelease. Final owner usability acceptance is pending.

[Complete manual](GhostTool_User_Manual.md) | [Complete PDF](GhostTool_User_Manual.pdf)

The 37-page manual describes Ghost Tool 4.2.0: installation, editor locations, prerequisites, workflows, shortcuts, examples, recovery, and the complete command and settings references. Coverage includes 43 source-defined commands, 10 help topics, and 209 property definitions, including internal helpers and stored records.

See the [coverage report](../manuals/README.md) for verification scope and implementation limits. Detailed tool help also remains available inside the add-on.

The earlier 3.3.0 PDF is retained under [archive/](archive/) for historical reference. It does not describe the current interface.

See the [release index](../../releases/VERSIONS.md) for the current download, verification and publication status.
