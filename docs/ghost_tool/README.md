# Ghost Tool 4.2.3 documentation

The 4.2.3 repository test build puts the full bone list in an independently collapsible Marker Targets fold. The rig and bone count, Show Markers action, Options and other tool groups stay accessible when it is closed. It retains 4.2.2's default-off live updates and authoring pause. Bforartists production-rig validation and owner acceptance remain pending.

[4.2.2 guide](GhostTool_User_Manual.md) | [4.2.2 PDF](GhostTool_User_Manual.pdf) | [4.2.3 UI change and checks](marker-targets/verification.md)

The 4.2.2 guides cover the shared tools. The 4.2.3 report describes the new target fold. Detailed tool help remains available inside the add-on.

Download the [4.2.3 test ZIP](../../releases/b4_ghost_tool_v4.2.3.zip?raw=1), or the published [4.2.2 prerelease ZIP](https://github.com/Axleonex/B4Artists_Toolkit/releases/download/ghost-v4.2.2/b4_ghost_tool_v4.2.2.zip). The 4.2.3 build has not been published on GitHub Releases.

The earlier 3.3.0 PDF is retained under [archive/](archive/) for historical reference. It does not describe the current interface.

See the [release index](../../releases/VERSIONS.md) for the current download, verification and publication status.
